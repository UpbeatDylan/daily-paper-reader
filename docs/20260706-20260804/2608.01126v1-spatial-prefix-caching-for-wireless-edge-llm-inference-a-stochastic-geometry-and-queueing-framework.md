## 摘要
前缀缓存重用共享提示前缀的键值（KV）状态，可以大幅减少大型语言模型（LLM）推理的首次令牌时间（TTFT）。然而，在无线边缘网络中，前缀状态分布在地理上分离的GPU节点上。附近的节点提供较短的无线路程，但可能提供很少的重用，而较远的节点可能缓存更长的匹配前缀，但会带来额外的通信和排队延迟。此外，持久前缀和活动请求KV状态竞争同一GPU内存，因此激进缓存会降低推理并发性并形成排队热点。本文针对这种空间通信-缓存-计算权衡发展了一个随机几何与排队论框架。我们用前缀森林表示提示工作负载，并定义一个包含多个可重用前缀的祖先封闭缓存配置文件。边缘GPU节点形成泊松点过程，并独立地按缓存配置文件标记，从而产生解析上可处理的空间层。我们推导了在负载感知关联策略下的配置文件关联概率、条件服务距离分布、令牌级计算卸载比率以及TTFT覆盖概率。一个不动点公式描述了空间关联与多服务器GPU队列之间的耦合，而外部优化在静态内存和稳定性约束下选择缓存配置文件的分布。解析和蒙特卡洛结果非常吻合。结果表明，延迟最优节点不一定是最邻近节点，且由于GPU内存耦合，TTFT在缓存前缀深度上可以是非单调的。

## Abstract
Prefix caching reuses the key--value (KV) states of shared prompt prefixes and can substantially reduce the time to first token (TTFT) of large language model (LLM) inference. In a wireless edge network, however, prefix states are distributed across geographically separated GPU nodes. A nearby node offers a short radio path but may provide little reuse, whereas a more distant node may cache a longer matching prefix but incur additional communication and queueing delay. Moreover, persistent prefixes and active-request KV states compete for the same GPU memory, so aggressive caching can reduce inference concurrency and create queueing hotspots. This paper develops a stochastic-geometry and queueing framework for this spatial communication--caching--computation tradeoff. We represent the prompt workload by a prefix forest and define an ancestor-closed cache profile that may contain multiple reusable prefixes. Edge GPU nodes form a Poisson point process and are independently marked by cache profile, yielding analytically tractable spatial tiers. We derive the profile-association probability, conditional serving-distance distribution, token-level computation-offloading ratio, and TTFT coverage probability under a load-aware association policy. A fixed-point formulation captures the coupling between spatial association and multi-server GPU queues, while an outer optimization selects the cache-profile distribution subject to static-memory and stability constraints. Analytical and Monte Carlo results agree closely. The results show that the latency-optimal node need not be the nearest node, that TTFT can be non-monotonic in cached-prefix depth because of GPU-memory coupling.

- **研究动机**：LLM 推理正越来越多地部署在无线边缘网络中的 GPU 节点上。前缀缓存（prefix caching）通过复用共享提示前缀的键值（KV）状态，可显著降低首次令牌时间（TTFT）。然而边缘网络与云端集群存在本质差异：不同 GPU 节点在地理上分散，**距离近的节点无线路程短但可复用的前缀少，距离远的节点可能缓存了更长的匹配前缀，但引入了额外的通信与排队延迟**。
- **核心矛盾**：持久化的前缀缓存状态与活跃请求的 KV 状态共享同一 GPU 内存。过度激进地缓存前缀可以节省预填充（prefill）计算，但会降低推理并发度，从而增加排队时延，甚至形成热点。
- **研究缺口**：经典的无线缓存理论将缓存对象视为独立文件，缓存命中是二进制的，且不考虑缓存对服务容量（并发度）的影响；而分布式 LLM 服务系统（如 Preble、Mooncake、ShadowServe 等）虽在系统层面实现了前缀复用和调度，却缺乏一个统一的网络级模型来解释空间部署、部分复用、GPU 内存与队列负载之间的交互。
- **核心研究问题**：当候选边缘 GPU 在无线距离、可复用前缀深度、排队延迟和内存受限并发度上同时存在差异时，一个请求应由哪个边缘 GPU 服务？论文将此概括为"空间通信-缓存-计算"三者的联合权衡问题。
- **整体含义**：本文不是提出一个新的缓存系统，而是建立一个**网络级理论框架**，用于回答边缘 GPU 密度规划、GPU 内存划分（持久缓存 vs 活跃请求）、以及缓存感知路由策略等实际规划问题。

## 2. 论文提出的方法论

### 2.1 核心思想

论文将 LLM 前缀缓存建模为一种**空间上的部分计算状态复用**问题，而非传统的二进制文件缓存问题。其方法论包含四个核心组件：

1. **前缀森林与祖先封闭缓存配置**：将提示工作负载表示为前缀森林；每个节点的缓存配置是祖先封闭的子集（存储一个子节点必须存储其全部祖先），因此一个空间标记可以代表多个相关前缀，比"一文件一标记"的经典抽象更通用。
2. **带标记的 PPP 空间模型**：边缘 GPU 节点构成齐次泊松点过程（PPP），每个节点独立地选择一个缓存配置（profile）。经独立标记后，各配置对应的节点形成独立的 PPP 层，使空间分析在解析上可处理。
3. **负载感知关联策略**：请求比较每个配置层最近节点的预测 TTFT 成本（通信时延 + 平均排队时延 + 剩余预填充时延），选择成本最小的配置；关联使用平均等待时间，而覆盖概率分析保留完整的排队时延分布。
4. **不动点求解排队-关联耦合**：关联概率决定各配置层的到达率，到达率决定排队时延，排队时延反过来影响关联概率；通过阻尼迭代求不动点，并在外层对配置分布做优化。

### 2.2 关键技术细节与公式

- **配置文件关联概率（定理 1）**：

  \[
  A_{s,q} = \int_0^\infty 2\pi\lambda_s r \exp\left(-\pi\lambda_s r^2 - \pi\sum_{t\neq s}\lambda_t G_{s,t,q}^2(r)\right) dr
  \]

  其中 \(G_{s,t,q}(r)\) 是竞争配置 t 的守护半径（guard radius），表示配置 s 胜出时配置 t 的最近节点必须满足的最小距离。该公式刻画了由计算节省量驱动的"计算诱导层级偏差"。

- **条件服务距离分布（推论 1）**：联合选择-距离密度除以关联概率，即得给定配置和请求类型下的服务距离条件分布。

- **TTFT 覆盖概率（定理 2）**：

  \[
  P_{\text{cov}}^{\text{TTFT}}(\tau) = \sum_q p_q \sum_s \int_0^{r_{\max}^{s,q}(\tau)} f_{s,q}^{\text{sel}}(r) F_{W_s}(\tau - \xi r^\alpha - T_{s,q}^{\text{pf}}) dr
  \]

  其中 \(F_{W_s}\) 是 Erlang-C 等待时间的 CDF，\(r_{\max}\) 是距离截断半径。这是 LLM 推理版本的"无线覆盖概率"，同时包含空间可用性、部分计算复用和队列可靠性。

- **M/M/c 队列模型**：每个配置层具有并发度 \(c_s = \lfloor(M - B_s)/m_{\text{run}}\rfloor\)，到达率由关联概率加权求和得到，采用 Erlang-C 公式计算等待概率和等待时间分布。

- **不动点迭代**：\(\bar{W}^{(i+1)} = (1-\eta)\bar{W}^{(i)} + \eta Q(A(\bar{W}^{(i)}))\)，实现关联与负载的负反馈闭环。

- **外层优化问题**：最大化 TTFT 覆盖概率，受约束于概率单纯形、平均静态内存预算（\(\sum \pi_s B_s \le \bar{B}\)）、每配置内存可行性（\(B_s < M\)）和队列稳定性（\(\rho_s < 1\)）；采用同步扰动随机逼近（SPSA）进行搜索。

- **缓存配置构建**：从提示轨迹构建基数森林，按"每字节预填充节省"打分（\(\Gamma_v = b_{p_v} \cdot [g(L_v) - g(L_v - \ell_v)] / B_v\)），用贪心扩展或树背包生成有限的候选配置集，并包含一个无缓存/高并发回退配置。

## 6. 论文的主要结论与发现

1. **延迟最优节点不一定是最邻近节点**：远程深前缀节点在预填充节省超过额外通信时延的情况下可被选中（命题 3 的远程前缀选择条件）。计算复用创造了请求相关的空间偏差。
2. **TTFT 随缓存深度非单调**：由于持久缓存占用 GPU 内存、降低并发度，在中等/高负载下过度缓存反而会恶化延迟（图 7）。这是计算状态缓存与存储型内容缓存的本质区别。
3. **队列无感知的路由可能比忽略缓存更差**：前缀感知但队列无感知的路由在低强度下与负载感知路由接近，但高负载下覆盖概率大幅下降（0.63 vs 0.23 at 强度 4），原因是缓存亲和性导致热点形成（图 8）。
4. **最优配置混合随负载变化**：轻/中负载下保留深前缀层有利；高负载下应扩大浅前缀和回退（高并发）层的比例（图 10）。自适应配置混合能避免固定配置的剧降（图 11）。
5. **边缘 GPU 密度不能替代缓存多样性**：仅增加密度不够，最近节点关联的覆盖概率在密度增加时饱和（约 0.52），而配置感知 + 负载感知的方法可升至 0.94（图 12）。
6. **计算卸载比（\(\eta_{\text{off}}\)）作为新指标**：相比二进制文件命中率，\(\eta_{\text{off}}\) 衡量提示计算中实际被避免的比例，更能反映前缀缓存的价值。
7. **设计原则是分层的**：广泛复制浅层前缀、选择性部署深层专用前缀、保留高并发回退容量、按边际端到端延迟节省路由。

## 7. 优点

- **统一建模框架**：首次将前缀森林（层级结构）、部分计算复用（token 级）、空间随机性（PPP）、队列动态（M/M/c）和 GPU 内存竞争纳入一个统一的解析框架；该框架将经典的二进制内容缓存理论推广为"部分计算状态复用的空间理论"。
- **数学可处理性**：独立标记产生独立的配置特定 PPP 层，使关联概率、服务距离和 TTFT 覆盖概率均以闭式或单积分形式表达；固定的服务时延抽象（\(T_{\text{com}}(r) = \xi r^\alpha\)）虽简化但保留了空间权衡的本质。
- **不动点方法**：通过阻尼迭代显式刻画了"关联→负载→排队→再关联"的负反馈回路，揭示了队列无感知路由的崩溃机制。
- **理论-仿真一致性高**：解析结果与 \(2\times10^5\) 蒙特卡洛样本在关联概率上误差 < \(10^{-3}\)，验证了推导的正确性。
- **实用部署架构**：提出三时间尺度架构（慢：痕迹分析与硬件画像；中：配置放置与目录更新；快：逐请求路由），将解析模型映射到可实现的控制系统；式 (54)-(55) 引入鲁棒性边际（\(\psi_x\)）处理遥测过期和估计误差，贴近工程实际。
- **可复现性**：声明提供源代码包（含图生成器、正交例程、不动点求解器和随机种子）。
- **模块化扩展**：通信模型、队列模型、配置生成均可替换/升级而不影响空间推导逻辑，例如式 (58) 给出 SINR 化的通信时延扩展，式 (60) 考虑解聚的 KV 获取开销。

## 8. 不足与局限

- **缺乏真实数据验证**：所有数值结果基于归一化的合成场景，没有使用真实提示轨迹（如 LMSys-Chat、ShareGPT 等）或真实模型/硬件；论文声称的"deployment-oriented follow-up"尚未完成，因此实际增益的大小未知。
- **无算力报告**：未报告 GPU 型号、数量、训练/推理时长等，无法评估实际部署成本。
- **队列模型的近似性**：M/M/c 假设指数服务时间，而实际 LLM 推理使用连续批处理（continuous batching）、分块预填充（chunked prefill）等机制，服务时间并不指数分布；作者承认这是"analytically convenient approximation"，但未定量评估该近似对最终结果的影响。
- **理想化假设较多**：（1）精确前缀匹配假设（不考虑近似匹配或量化影响）；（2）假设所有节点运行同一模型副本；（3）单一模型大小，未考虑异构模型/适配器/隐私域；（4）独立标记假设（实际中协调放置可能更好）；（5）通信时延采用简单的幂律距离模型，忽略衰落、干扰和带宽共享（虽在第 VII-B 节给出扩展方向，但未纳入实验）。
- **与现有系统的关系未实证**：虽然文献综述定位了 Preble、Mooncake、ShadowServe 等系统，但没有移植或对比这些系统的调度策略；框架与这些系统是"互补"的定位，但缺少端到端的实证对比。
- **扩展场景未验证**：第 VII-B 节讨论了解聚 KV 获取、SINR 模型、协调放置、动态流行度、移动性等扩展，但均停留在"可以扩展"的层面，没有对应的数值结果，读者无法判断这些扩展的精度和代价。
- **优化算法的保证有限**：外层使用 SPSA 等导数自由方法，且优化问题是非凸的，无法保证全局最优；论文仅声称算法收敛和稳定。
