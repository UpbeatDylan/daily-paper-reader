## 摘要
大语言模型（LLMs）中上下文窗口长度的增长显著增强了其长上下文能力，但由于键值（KV）缓存，也带来了高昂的内存成本。尽管对KV缓存进行低秩压缩是一个有前景的解决方案，但现有方法面临两难境地：离线方法依赖外部校准数据，而在线方法则需为完整的提示分解与重建承担大量计算。在本文中，我们提出了S$^4$R，它从选择性采样的词元中构建低秩子空间，并在稀疏重建的KV表示上计算注意力。S$^4$R使用感知提示的初始化，从具有代表性的提示子集中构建初始键/值基，从而在校准数据依赖与预填充成本之间进行权衡。由于在每一步解码时完全重建缓存代价极高且会损害吞吐量，我们进一步采用稀疏重建，仅在解码过程中保留信息丰富的位置。在LongBench和RULER上使用Llama和Qwen模型系列进行的大量实验表明，S$^4$R在接近全缓存精度的条件下实现了高达5倍的KV压缩，结合了固定压缩的效率与提示依赖方法的适应性。

## Abstract
The growth of context window lengths in Large Language Models (LLMs) significantly enhances their long-context capabilities but incurs prohibitive memory costs due to the Key-Value (KV) cache. Although low-rank compression of KV cache is a promising remedy, existing methods face a dilemma: offline approaches depend on external calibration data, whereas online approaches incur substantial compute for full-prompt decomposition and reconstruction. In this paper, we propose S$^4$R, which builds low-rank subspaces from selectively sampled tokens and computes attention over a sparsely reconstructed KV representation. S$^4$R uses prompt-aware initialization to build initial key/value bases from a representative prompt subset, trading off calibration-data dependence against prefilling cost. Because fully reconstructing the cache at every decoding step is prohibitively expensive and hurts throughput, we further adopt sparse reconstruction to retain only informative positions during decoding. Extensive experiments on LongBench and RULER with Llama and Qwen model families show that S$^4$R achieves up to 5$\times$ KV compression with near full-cache accuracy, combining the efficiency of fixed compression with the adaptability of prompt-dependent methods.

- 大语言模型（LLM）的上下文窗口从128k扩展到百万级token，显著增强了长文档摘要、检索增强生成（RAG）、自主智能体等能力。
- 随着上下文长度增长，KV缓存的内存开销急剧膨胀，可迅速超过模型参数本身的内存占用，成为LLM推理的核心瓶颈。

### 核心问题
现有低秩KV缓存压缩方法面临一个根本性两难：
- **离线（固定）方法**（如Palu、LoRC、Eigen Attention）：在推理前基于校准数据构建低秩基，解码时高效，但**依赖外部校准数据**，且对压缩比、秩分配、分布偏移敏感。
- **在线（提示依赖）方法**（如ShadowKV、xKV）：在推理时从当前完整提示中估计低秩表示，**适应性强但预填充计算开销大**（尤其对长提示）。

### 论文的核心洞察
- 长提示的主导KV子空间**不必从外部校准集或完整提示中估计**，可以从**精心选择的提示token子集**近似；
- KV缓存条目**不应均匀压缩或重建**：sink token是注意力的稳定全局枢轴，应全精度保留；大多数非sink token可存储为低秩系数，仅在可能对当前解码重要时重建。

### 整体含义
S$^4$R通过"提示感知的采样子空间构建 + 潜空间稀疏重建"的设计，同时获得固定压缩方法的效率和提示依赖方法的适应性，为长上下文LLM推理提供了一条实用的KV缓存压缩路径。

## 二、论文提出的方法论

### 2.1 核心思想
S$^4$R包含两个阶段：
- **预填充阶段**：从提示token的**选择性采样子集**构建键/值低秩子空间，存储非sink token的低秩系数；
- **解码阶段**：在潜空间估计token相关性，稀疏重建局部窗口+全局重要位置的KV向量，仅对此紧凑集合计算精确注意力。

### 2.2 预填充阶段关键步骤

**（1）Sink Token处理**
- 将前$s=4$个token视为sink token，**全精度存储**其pre-RoPE键值表示，不进行压缩；
- 其余token视为非sink token，接受低秩近似。

**（2）混合采样策略**
- 从非sink token中选取代表性子集$T' \ll T$，结合：
  - 早期位置的**均匀采样**（提供全局覆盖）；
  - 最右侧**连续近邻token块**（匹配近期解码分布）；
  - 默认近邻:均匀 = **7:3**。

**（3）Token归一化**
- 采样token在SVD前沿特征维度做归一化：$S_{K/V}[I] \leftarrow \text{normalize}(S_{K/V}[I], \dim=-1)$
- 目的：使子空间捕捉**方向信息**而非被高范数向量主导，提高低秩近似的稳定性。

**（4）截断SVD构建子空间**
$$U_{K/V}, \Sigma_{K/V}, B_{K/V} \leftarrow \text{SVD}_r(S_{K/V}[I])$$
- $B_{K/V} \in \mathbb{R}^{D' \times r}$为前$r$个右奇异向量，作为低秩基；
- 非sink token投影：$C_{K/V} = S_{K/V}B_{K/V}$，得到系数表示。

**（5）初始本地查询窗口**
- 将最近$W$个查询投影到同一子空间：$C_Q = \tilde{Q}B_K$，用于解码时相关性估计。

### 2.3 解码阶段关键步骤

**（1）压缩缓存更新**
- 新token的K/V通过基矩阵投影为系数$c_{K/V}^t = s_{K/V}^t B_{K/V}$，追加到系数缓存；
- 查询系数维护固定大小滑动窗口（FIFO队列）。

**（2）潜空间相关性估计**
- 在低维系数空间计算近似注意力分数：$Z = C_Q(C_K^t)^\top / \sqrt{r}$
- 应用因果掩码后softmax归一化，跨查询窗口平均得到每个缓存token的相关性得分。

**（3）池化与聚合**
- 沿序列维度使用**平均池化或最大池化**（核大小$\kappa=7$），借鉴SnapKV的token聚类思想；
- 对GQA模型沿分组维度使用mean或max聚合。

**（4）稀疏重建与注意力**
- 最终索引集 = **局部窗口**（最近$W$个token，$W=32$）+ **全局Top-k重要位置**；
- 重建：$\hat{K} = C_K^t[\hat{I}](B_K)^\top$，$\hat{V} = C_V^t[\hat{I}](B_V)^\top$；
- 重建的KV与全精度sink token拼接，按原始位置施加RoPE后计算精确注意力。

### 2.4 内存分析
- 全缓存：$M_{\text{full}}(t) = 2(s + L_t)D'$；
- S$^4$R持久缓存：$M_{S^4R}(t) = 2sD' + 2L_tr + GWr + 2D'r$（sink KV + 系数缓存 + 查询窗口 + 键值基）；
- 当$L_t \gg s, r$时，内存比趋近$r/D'$，即长上下文内存由低秩维度主导。

## 六、论文的主要结论与发现

### 6.1 准确率结论
- **LongBench**：在高达5倍KV压缩（目标保留率仅0.2~0.3）下，S$^4$R在Llama-3.2-1B和Qwen3-4B上取得最高平均分（28.09和47.79），在较大模型（Llama-3.1-8B、Qwen2.5-14B）上与xKV接近但保留效率优势；
- **RULER**（2.5倍压缩、128k上下文）：S$^4$R平均分93.61，几乎完全匹配全缓存（93.97）并略超xKV（93.47），优于Palu（82.22）、ShadowKV（89.61）、SnapKV（88.81）和StreamingLLM（48.39）分别11.39、4.00、4.80、45.22分。

### 6.2 效率结论
- 相比xKV，S$^4$R将TTFT从79.90s降至27.65s（降约65%），512-token生成延迟从260.76s降至61.54s（降约76%），输出吞吐从1.96提升至8.32 tokens/s；
- 相比Full KV、Palu、ShadowKV，S$^4$R在无优化实现下仅略慢（61.54s vs 54.89s/57.06s/56.92s），但以较小的计算开销换取了显著更高的压缩下准确率。

### 6.3 消融结论
- **Sink token保留**：全精度保留sink token普遍提升准确率（1B模型提升3.49分），内存开销（$2sD'$）在长上下文中可忽略；
- **Token归一化**：改善跨模型鲁棒性（Qwen2.5-14B上提升6.92分），虽并非对所有模型最优；
- **池化/聚合选择**：影响较小（各组变体差距均<0.67分），方法对超参数不敏感；
- **查询窗口**：$W=16\sim32$最优，过大（64）或过小（1）均降低性能；
- **秩分配**：值侧略偏向更高秩（1:1.5）在部分模型上有益，但非普适；
- **重建比例**：默认$\rho=\eta$比更小的0.15更稳妥。

**理论分析假设较强**：附录 B 的复杂度推导假设了 SVD 和采样成本可忽略、并简化了访存模型；实际中，预填充阶段的 SVD 耗时和内存带宽冲突可能改变优势结论，尤其对于极长上下文。

**对 GQA 的适配相对粗糙**：仅用 mean/max 对分组维度聚合相关性得分，未分析不同头数、不同分组大小下注意力分布的差异，可能损失部分准确率。

**部分超参依赖启发式**：近邻采样与均匀采样的比例（7:3）、窗口大小 $W$、池化核 $\kappa$ 等虽经消融验证，但未实现自适应选择；面对极端分布（如大量重复 token 或高度稀疏注意力的任务）时，固定策略的鲁棒性存疑。

**未提供可复现代码**：论文未开源实现或配置细节，这对于精确复现（尤其是采样随机性、SVD 数值稳定性、RoPE 与重建顺序）构成一定障碍。

## 九、总结与展望

S$^4$R 的核心贡献在于，用“提示内采样子集 + 潜空间稀疏重建”重新定义了低秩 KV 缓存压缩的范式：既抛弃了离线校准数据的依赖（避免分布偏移），也省去了对完整提示的 SVD 分解（避免预填充瓶颈）。通过全精度保留 sink token、对非 sink token 存储低秩系数、并在解码时以极小的计算代价稀疏重建局部窗口和全局重要位置，该方法在 5 倍压缩下仍能逼近甚至匹配全缓存准确率，同时将预填充延迟和输出延迟较提示依赖方法大幅降低。

未来工作可从以下方向推进：
1. **扩展压缩比谱系**：系统评估 4 倍、8 倍甚至更高压缩比下的性能，探索秩分配与重建比例的联合最优策略；
2. **更大模型与更长上下文验证**：在 70B 级模型和超过 128k 的上下文上检验可扩展性；
3. **算子级联合优化**：将 S$^4$R 与 FlashAttention、PagedAttention 等系统融合，实现在真实生产环境中的吞吐增益；
4. **自适应采样与重建**：根据注意力分布动态调整采样比例、窗口大小和池化策略，减少人工超参干预；
5. **理论保障**：为采样子空间近似提供误差界，指导秩和采样数的最优配置。

总体而言，S$^4$R 在准确率、压缩率和效率之间取得了出色的平衡，为长上下文 LLM 推理中的 KV 缓存管理提供了兼具理论优雅和工程价值的新思路。尽管实验覆盖和系统优化仍有提升空间，其方法框架极具推广潜力。
