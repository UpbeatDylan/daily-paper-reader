## 摘要
将长文档反复提供给大语言模型（LLM）进行服务代价高昂：计算量随上下文长度增长，键值（KV）缓存的内存占用也急剧膨胀。压缩 KV（CKV）表示旨在模拟文档的缓存，通常在推理时间之前一次性计算完成。获得 CKV 的方法从减少列数的丢弃机制到基于学习的方法不等。在后一类方法中，Cartridges 已成为一种领先的压缩方法，通过在与文档相关的问答对上进行蒸馏来学习紧凑的 KV 表示。尽管现有评估主要关注 Cartridges 和其他 CKV 能否对与文档相关的上下文内查询产生大致相似的响应，但我们研究一个关键的部署问题：它们能否处理离上下文查询——得益于注意力机制，原生 KV 表示尤其擅长这一点。我们观察到一种根本性的权衡：虽然 Cartridges 在上下文内查询上表现更好，但启发式变体更好地保留了原始 LLM 进行离上下文操作的能力。我们通过它们在响应中避免上下文污染、保留通用知识以及遵循指令的能力来衡量这一点。我们提出 Cartridges++，这是对 Cartridges 的简单修改，以很小或可忽略的代价保留离上下文能力。路由器变体在推理时决定查询是否应使用学到的长上下文记忆，而数据混合变体则将一小部分训练问答分配给参考长文档之外的查询。我们的研究表明，仅根据文档效用评估 CKV 可能会掩盖更广泛模型能力上的显著退化，但这些问题可以通过对 CKV 推理或训练进行良性改动来修复。

## Abstract
Serving long documents to a Large Language Model (LLM) repeatedly is expensive: computations grow with context length, and the memory footprint of the key-value (KV) cache balloons. Compressed KV (CKV) representations aim to mimic the cache of a document and are typically computed once and for all, ahead of inference time. Methods to obtain CKVs range from drop mechanisms that reduce their number of columns, to learned approaches. Among the latter, Cartridges have emerged as a leading compression method, learning compact KV representations through distillation on relevant Q/A pairs. While existing evaluations focus primarily on whether Cartridges and other CKVs yield approximately similar responses to document-related, on-context queries, we investigate the crucial deployment question of whether they can handle off-context queries, something the native KV representation is particularly good at, thanks to the mechanics of attention. We observe a fundamental trade-off: while Cartridges perform better for on-context queries, heuristic-variants preserve better the original LLM's ability to operate off-context. We measure this through their capability to avoid context contamination in their response, retain general knowledge, and follow instructions. We propose Cartridges++, simple modifications to cartridges that retain off-context abilities at small or negligible cost. The router variant decides at inference time whether the query should use the learned long-context memory, while the data-mixing variant allocates a small fraction of training Q/As to queries outside the reference long document. Our study shows that assessing CKVs on document utility alone can mask substantial degradation in broader model capabilities, yet those issues can be fixed with benign changes to CKV inference or training.

# Cartridges++ 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **长上下文复用的成本问题**：LLM 反复服务同一长文档时，计算量随上下文长度增长，KV cache 内存随文档长度线性膨胀，解码成本也随缓存长度上升。
- **压缩 KV（CKV）表示**：为降低长文档复用成本，研究者提出一次性构造紧凑 KV 表示并跨查询复用，包括训练无关的保留状态/驱逐方法，以及基于学习的压缩方法。
- **Cartridges 的定位**：Cartridges 通过学习文档特定的紧凑 KV 状态，在文档相关问答对上进行蒸馏，成为当前领先的 CKV 方法之一，在上下文内（on-context）查询上通常显著优于驱逐方法。
- **被忽视的部署问题**：现有评估主要关注“文档效用”或上下文保真度，即压缩缓存能否近似回答与源文档相关的问题；但真实部署中，用户查询可能完全与已缓存文档无关。
- **核心发现**：原生 KV 表示借助注意力机制，通常能较好地“关闭”无关上下文交互；但学习式 CKV（尤其 Cartridges）会破坏这种能力。Cartridges 虽在上下文内查询更强，却会显著干扰离上下文（off-context）行为，甚至比直接保留完整上下文更严重。
- **论文含义**：仅用文档效用评估 CKV 会掩盖模型通用能力的退化；需要引入“能力保持”（capability preservation）这一互补评价维度，并通过良性改动修复该问题。

## 2. 方法论：核心思想、关键技术细节与算法流程

- **双面形式化**：
  - 全文档缓存记为 \(C(x)\)，压缩缓存 \(C_x\) 长度 \(m \ll L\)，压缩率 \(\rho = m/L\)。
  - 上下文保真度：\(R^+(C_x) = \mathbb{E}_{q\sim Q_x^+} D(p_\theta(\cdot|x,q) \| p_\theta(\cdot|C_x,q))\)。
  - 能力保持：\(R^-(C_x) = \mathbb{E}_{q\sim Q_x^-} D(p_\theta(\cdot|q) \| p_\theta(\cdot|C_x,q))\)。
  - 以全上下文干扰 \(R^-_{\text{full}}\) 为参考，要求压缩缓存的离上下文干扰不应显著超过直接保留完整文档。
- **Cartridges 的单边目标**：其训练仅用文档相关 self-study 问答对进行上下文蒸馏，只监督 \(R^+\)，不包含 \(Q_x^-\) 或无上下文参考，因此 \(R^-\) 未受约束，导致干扰。
- **Cartridges++ 两种互补策略**：
  - **训练时数据混合 \(CD^{++}\)**：
    - 将 self-study 数据 \(D_x\) 与通用离上下文数据 \(D^-\)（Dolci-Instruct-SFT）混合：\(D(\gamma)_x = (1-\gamma)D_x + \gamma D^-\)。
    - \(\gamma\) 控制监督 assistant token 中离上下文数据的比例；离上下文样本使用冻结基座模型无缓存时的教师分布，鼓励 \(p_\theta(\cdot|C_x,q)\) 匹配 \(p_\theta(\cdot|q)\)。
    - \(\gamma=0\) 退化为标准 Cartridges，\(\gamma=1\) 仅用离上下文数据；主实验采用 \(\gamma=0.05\)，并扫描 \(0.01, 0.05, 0.10\) 及完整范围。
  - **推理时相关性路由 \(CR^{++}\)**：
    - 引入路由 \(r_x(q)\in\{0,1\}\)，决定是否使用已训练 Cartridge：
      - \(r_x(q)=1\)：使用 \(p_\theta(y|C_x,q)\)；
      - \(r_x(q)=0\)：移除 Cartridge，使用 \(p_\theta(y|q)\)。
    - 主路由为 kNN 变体：对查询做无 Cartridge 的干净 prefill，取第 18 层 question token 的 mean-pooled、\(\ell_2\) 归一化表示；计算其与参考库中 \(k=10\) 个最近 self-study 查询的平均余弦相似度。
    - 阈值在留出的 Dolci 负样本上使用单侧 conformal calibration，\(\alpha=0.05\)，不接触 TinyMMLU/MMLU-Pro/IFEval。
    - 若低于阈值，直接从干净 prefill 继续生成；否则重新以 Cartridge prefill 后生成。
    - 也评估 MiniLM 等外部编码器，证明路由可不依赖骨干模型表示。
- **轻量提示基线**：尝试插入“仅在相关时使用文档”的指令，但无法可靠恢复无上下文行为，仅作为附录对照。

## 3. 实验设计：数据集、Benchmark 与对比方法

- **长上下文数据集（上下文保真度 / on-context）**：
  - **QASPER-16**：16 篇 NLP 论文合并，约 103,280 tokens，78 个问题，指标为参考答案 log-perplexity，另报生成答案 token F1。

  - **MTOB**：Kalamang–英语翻译任务，约 138,435 tokens，50 个官方测试句，报告 corpus chrF。
  - **QuALITY-20**：20 篇叙事文本，约 4K–7K tokens，357 个多选题，报告准确率；用于检验较短上下文下干扰是否仍存在。
- **能力保持 Benchmark（off-context）**：
  - **通用知识**：TinyMMLU（100 题）与 MMLU-Pro（1,400 题，14 类各 100 题），零样本贪心解码，报告平均准确率 MMLUs。
  - **指令遵循**：IFEval 全部 541 条 prompt，官方严格 prompt-level 通过标准。
  - **上下文干扰**：用 LLM-as-judge 判断通用知识 rationale 是否伪造引用、声称文档提供答案等；主 judge 为 gpt-oss-20b，另用 gpt-oss-120b 与 gemma-3-27b-it 复验。主指标为 `fabricates_quote` 或 `context_answers_question` 的并集比例。
- **模型**：
  - Qwen3-4B 用于 QuALITY-20；
  - Qwen3-4B-Instruct-2507 与 Gemma-4-E4B-it 用于 QASPER-16、LongHealth-10、MTOB；
  - Gemma 的混合注意力架构中，仅对全局注意力槽位压缩，滑动窗口缓存保持不变。
- **对比方法**：
  - 学习式：Cartridges、Attention Matching（AM）、AM + router（AMR）。
  - 驱逐式：H2O、SnapKV、KVzip、PyramidKV、StreamingLLM。
  - 文本空间：预算匹配的模型生成摘要。
  - 参考条件：Full context 与 No context。
  - 压缩率扫描：Qwen 主实验 \(\rho \in [0.001,0.20]\)，部分设置扫描 0.1%–20%。
- **训练与路由数据**：
  - Cartridges 采用 self-study 上下文蒸馏；各数据集 self-study 问答对数量约 13 万至 64 万。
  - Dolci-Instruct-SFT 经清洗、去重、长度过滤后用于数据混合与路由负样本；TinyMMLU/MMLU-Pro/IFEval 不用于拟合或校准。
