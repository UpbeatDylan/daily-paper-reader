## 摘要
提示词特化的多智能体系统允许多个智能体共享一个模型，同时扮演互补角色以解决复杂任务。然而，智能体特定的前缀会改变针对同一共享上下文生成的 KV 缓存，导致每个智能体重复预填充不断增长的上下文，并构建单独的缓存，从而带来高计算和内存开销。选择性重计算可减少这种冗余，但仍保留大量模型执行；而现有的增量校正方法要么仅支持重复出现的上下文关系，要么为动态变化的上下文维护内存密集的在线校正状态。对于首次出现的共享上下文，这些方法还会在智能体工作流之外构建参考缓存，而第一个智能体处的近似校正会影响传递给后续智能体的输出。我们提出 KVCMAS，一种在线 KV 缓存校正框架，它使用紧凑的低秩状态表示跨智能体缓存偏差，并沿智能体工作流无缝串联校正，而无需额外的参考预填充。该设计支持动态变化的共享上下文，同时保留精确的首个智能体缓存。在多种语言与视觉-语言工作负载中，KVCMAS 达到或超过先前 KV 缓存共享方法的准确率，同时在高并发服务下实现最低的 TTFT。在受控服务轨迹下，相较于无 KV 缓存共享的推理，它提供 2.0 倍的 TTFT 加速，并且相对于先前的 KV 缓存校正方法，将峰值 GPU 内存最多减少 3.7 倍。这些结果表明，KVCMAS 是面向提示词特化多智能体服务的一种准确且可扩展的 KV 缓存共享方法。

## Abstract
Prompt-specialized multi-agent systems enable multiple agents to share a model while performing complementary roles to solve complex tasks. However, agent-specific prefixes change the KV cache generated for the same shared context, causing each agent to repeatedly prefill the growing context and construct a separate cache with high computation and memory overhead. Selective recomputation reduces this redundancy but still retains substantial model execution, while existing delta correction methods either support only recurring context relations or maintain memory-intensive online correction states for dynamically changing context. For first seen shared context, these methods also construct a reference cache outside the agent workflow, and an approximate correction at the first agent affects the outputs passed to subsequent agents. We present KVCMAS, an online KV cache correction framework that represents cross-agent cache deviations using compact low-rank states and seamlessly chains corrections along the agent workflow without an additional reference prefill. This design supports dynamically changing shared context while preserving an exact first-agent cache. Across multiple language and vision-language workloads, KVCMAS matches or improves the accuracy of prior KV cache sharing methods while achieving the lowest TTFT under highly concurrent serving. Under controlled serving traces, it provides a 2.0x TTFT speedup over inference without KV cache sharing and reduces peak GPU memory by up to 3.7x relative to a prior KV cache correction method. These results establish KVCMAS as an accurate and scalable KV cache sharing approach for prompt-specialized multi-agent serving.

## 1. 核心问题与整体含义

- **研究背景**：基于提示词特化的多智能体系统（MAS）中，多个智能体共享同一模型权重，但使用不同的角色前缀（PF，如系统提示、胶水提示），并交替处理共享上下文段（PH，如用户查询、工具观察、其他智能体输出）。
- **核心问题**：同一段共享上下文在不同智能体前缀下会生成不同的 KV 缓存，即 \(C_{i,seg} \neq C_{j,seg}\)。因此，每个智能体都需要重复预填充（prefill）不断增长的共享上下文，并维护独立 KV 缓存，造成显著计算与显存开销。
- **现有方法局限**：
  - **选择性重计算**：只重建部分层或 token，未覆盖的缓存偏差仍存在；提高覆盖率会增加模型执行开销。
  - **增量校正**：可避免重计算，但多数方法只支持重复出现的上下文关系，难以处理动态变化上下文。
  - **KVComm 类在线锚池方法**：支持动态上下文，但以全维度存储基缓存和校正状态，显存随共享上下文长度增长。
  - **首次共享上下文问题**：非链式校正需在工作流外额外构建无上下文参考缓存；首个智能体的近似校正误差会作为共享上下文传播到后续智能体，放大整体误差。
- **整体含义**：论文提出 KVCMAS，目标是面向提示词特化多智能体服务，在保持精度的同时降低 TTFT 和显存，实现准确、可扩展的跨智能体 KV 缓存共享。

## 2. 方法论

- **核心思想**：
  - 跨智能体 KV 缓存偏差集中在低维特征空间，可用**紧凑低秩状态**表示。
  - 校正参考应来自工作流中已经产生的源智能体缓存，而非额外构造的无上下文参考缓存，即**链式校正**。
- **低秩在线校正**：
  - 对每个共享上下文槽维护在线锚池，每个锚存储低秩源缓存表示和面向消费智能体的校正。
  - 对矩阵 \(Z \in \{C^{(v)}_{i,seg}, \Delta^{(v)}_{j\leftarrow i,seg}\}\) 做截断 SVD：\(Z \approx U_{Z,r}\Sigma_{Z,r}R_{Z,r}^\top = A_Z B_Z\)。
  - 显存从全维度 \(O(VNLD)\) 降至 \(O(VNr(L+D))\)，其中 \(r\) 为秩，\(V\) 为锚数，\(N\) 为消费智能体数。
- **锚匹配与校正估计**：
  - 用当前源缓存与各锚重建基缓存的相似度计算归一化权重 \(w_v\)。
  - 校正为各锚低秩校正的加权组合：\(\hat{\Delta}_{j\leftarrow i,seg}=\sum_v w_v A_{\Delta,v}B_{\Delta,v}\)。
- **可靠性门控**：
  - 基于锚匹配权重的归一化熵 \(H(g)\) 判断可靠性。
  - 当 \(H(g)\leq \tau\) 时接受校正；否则回退到稠密预填充，产生精确缓存并重置传播误差。
- **链式校正流程**：
  - 第一个智能体进行稠密预填充，得到精确缓存。
  - 对源智能体 \(i\) 到目标智能体 \(j\) 的共享段，先做 key 位置对齐，再匹配锚池并估计校正。
  - 将 \(\hat{\Delta}_{j\leftarrow i,seg}\) 应用到源缓存，物化全维度目标缓存，供普通注意力使用，并作为下一条工作流边的参考。
  - 避免额外参考预填充，并防止首个智能体的校正误差进入后续共享上下文。
- **锚池管理**：
  - 每个共享槽维护进程级锚池，最多 \(V\) 个锚。
  - 稠密回退后计算源缓存与观测校正，并插入低秩因子；被接受的校正不重新插入。
  - 池满时在较旧条目中按最不常使用策略淘汰。

- **超参与门控风险**：
  - 可靠性阈值 \(\tau\) 需按任务调整以匹配目标复用率。
  - 锚池不足或匹配不可靠时回退稠密预填充，可能削弱效率优势。
  - 锚池更新和 SVD 因子分解有额外开销，论文将其计入 E2E 和显存，但未深入分析极端负载下的影响。
- **实验覆盖限制**：
  - 仅使用 Llama-3.1-8B、Qwen2.5-Coder-7B、LLaVA-OneVision-7B 等有限模型。
  - HumanEval 样本仅 161 条，部分结论统计稳定性有限。
  - 主要实验为单 GPU 测量，未展示多 GPU、分布式或生产级集群结果。
- **基线实现偏差**：
  - GraphFlow 排除图调度组件，Kamera 未直接实验
