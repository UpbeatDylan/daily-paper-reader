## 摘要
大型语言模型依赖 KV 缓存来减少长上下文与交互式应用中重复的预填充计算。随着轻量级适配器不断演化，缓存状态反映的是较早版本，因此陈旧复用会扭曲当前模型输出，而完整重算受影响后缀虽可恢复保真度，但代价高昂。我们寻求以最小重算恢复当前适配器行为。现有系统跟踪 token、上下文或稳定适配器身份，但既无法表示来自较早适配器版本的缓存，也无法区分更新传播与行为恢复所需的重算。为弥补这些空白，我们提出 CacheReforge，它将陈旧 KV 缓存表示为逐层混合版本对象。它结合逐层适配器锚点、校准敏感度、累积漂移与可执行重启边界，以选择直接复用、有界重算或完整受影响后缀恢复。我们区分依赖深度与功能重算范围，并使用累积尾部影响来刻画有界恢复何时能够保持当前模型行为。我们在 Qwen2.5-1.5B 与 Qwen2.5-7B 上使用持续 LoRA 更新进行评估，包括 16K HotpotQA 与 2WikiMQA 工作负载。相较于陈旧复用，CacheReforge 将平均 KL 散度降低 92.4%，同时仅重算 5.44% 的层，并将缓存维护时间相较于全新完整预填充减少 93.2%。这些结果表明，版本感知恢复可保持模型保真度与大部分 KV 缓存收益。

## Abstract
Large language models rely on KV caching to reduce repeated prefill computation in long context and interactive applications. As lightweight adapters evolve, cached states reflect earlier versions, so stale reuse distorts current model outputs, while complete affected suffix recomputation restores fidelity at substantial cost. We seek minimal recomputation that recovers current adapter behavior. Existing systems track token, context, or stable adapter identity, but neither represent caches from earlier adapter versions nor distinguish update propagation from the recomputation required for behavioral recovery. To address these gaps, we introduce CacheReforge, which represents stale KV caches as layerwise mixed-version objects. It combines per-layer adapter anchors, calibrated sensitivity, accumulated drift, and executable restart boundaries to select direct reuse, bounded recomputation, or complete affected-suffix recovery. We distinguish dependency depth from the functional recomputation horizon and use cumulative tail influence to characterize when bounded recovery preserves current-model behavior. We evaluate CacheReforge on Qwen2.5-1.5B and Qwen2.5-7B with continual LoRA updates, including 16K HotpotQA and 2WikiMQA workloads. CacheReforge reduces mean KL divergence by 92.4% relative to stale reuse, while recomputing only 5.44% of layers and reducing cache-maintenance time by 93.2% relative to fresh full prefill. These results show that version-aware recovery preserves model fidelity and most KV caching gains.

## 2. 方法论

- **核心思想**：将陈旧 KV 缓存视为“逐层混合版本对象”。每个缓存层记录其生成时的适配器锚点，而不是仅记录 token/上下文身份；适配器更新后，依据逐层漂移和校准敏感度，选择直接复用、有界重算或完整受影响后缀恢复。
- **版本感知缓存表示**：
  - 每层缓存维护适配器锚点 \(\theta^{anchor}_\ell\)，表示该层 K/V 状态由哪个适配器状态产生。
  - 当前适配器为 \(\theta_t\)，层 \(\ell\) 的位移为 \(d_\ell(t)=\|\theta_t-\theta^{anchor}_\ell\|_2\)。
  - 校准敏感度为 \(s_\ell\)，运行时风险为 \(q_\ell(t)=s_\ell d_\ell(t)\)。
- **离线校准**：
  - 对每个部署配置，在独立校准集上测试候选窗口：直接复用、1/2/4/8/16 层、完整可执行后缀。
  - 安全标准：首步 next-token KL ≤ 0.05，top-1 一致率 ≥ 0.99，完整答案任务分数下降 ≤ 0.01。
  - 取第一个安全窗口 \(h^\star_i\)，生成逐层二值标签 \(y_{i,\ell}\)，并据此估计层敏感度 \(s_\ell\)；包含在安全重算范围内且适配器位移小的层获得更高敏感度。
- **运行时风险与范围选择**：
  - 若所有层 \(q_\ell(t)<1\)，直接复用缓存。
  - 否则选择端点 \(b_t=1+\max\{\ell:q_\ell(t)\ge 1\}\)，重算最小可执行连续区间 \([r,b_t)\)。
  - 若 \(b_t=N\)，等价于完整受影响后缀恢复；否则为有界恢复。
  - 只刷新被重算层的 K/V 与适配器锚点；未重算层保留历史锚点，继续累积相对当前适配器的位移。
- **可执行重启边界**：
  - key/value 更新可能在层 \(s\) 直接改变缓存；query/output/MLP 更新最早影响层 \(s+1\)，但若下游受影响，仍需从 \(s\) 重启执行。
  - 系统在原始 prefill 时保留支持重启边界的 hidden state，恢复时从该边界状态出发，在当前适配器下执行 \([r,b_t)\)。
- **理论分析**：
  - 定义尾部影响：\(v_\ell=z^{(\ell)}-z^{(\ell+1)}\)，累计尾部影响 \(T_b=\sum_{\ell=b}^{N-1}\|v_\ell\|_2\)。
  - 得到 KL 上界：\(D_{KL}(p^\star\|p^{(b)})\le \frac14 T_b^2\)。
  - top-1 保持条件：若 \(T_b<\gamma^\star/2\)，则当前 top-1 预测与新鲜重算一致，其中 \(\gamma^\star\) 为 fresh logits 的最大与次大差距。
  - 区分“依赖深度”和“功能重算范围”：依赖可能传播到所有下游层，但输出影响可能提前可忽略；恢复误差不保证随窗口增大单调下降。
