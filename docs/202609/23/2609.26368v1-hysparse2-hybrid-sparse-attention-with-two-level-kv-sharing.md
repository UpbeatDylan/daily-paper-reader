## 摘要
长时程与多轮智能体通常生成短动作，并处理来自工具和环境的长观测。这种不断增长的上下文要求高效的预填充、紧凑的 KV 缓存存储以及准确的长上下文检索。为满足这些需求，我们提出了 HySparse2，一种具有两级 KV 共享的混合稀疏注意力架构。在外层，KV Bridging 采用 YOCO 风格的自解码器与交叉解码器结构，但仅桥接全注意力层。自解码器使用混合滑动窗口注意力（SWA），而交叉解码器使用混合稀疏注意力。交叉解码器中全注意力层的 KV 缓存由自解码器中全注意力层的隐藏状态生成。在内层，HySparse2 保留了 HySparse 的核心 KV Reuse 设计，并做了两点改进。首先，它将块级稀疏性替换为 token 级稀疏性，以实现更细粒度的长上下文检索。其次，它从稀疏层中移除了单独的 SWA 分支，转而强制将近期 token 的滑动窗口纳入稀疏选择。这种两级 KV 共享使所有交叉解码器 KV 缓存均可由自解码器隐藏状态构建。因此，预填充可在自解码器之后退出，跳过所有交叉解码器层。在 80B-A3B MoE 模型上，HySparse2 在长上下文检索和多轮智能体任务上优于 HySparse 和 Hybrid SWA，同时大幅减少预填充计算量和 KV 缓存存储。

## Abstract
Long-horizon and multi-turn agents typically generate short actions and process long observations from tools and environments. This growing context demands efficient prefill, compact KV-cache storage, and accurate long-context retrieval. To meet these demands, we introduce HySparse2, a hybrid sparse attention architecture with two-level KV sharing. At the outer level, KV Bridging adopts a YOCO-style self-decoder and cross-decoder structure, but bridges only full-attention layers. The self-decoder uses hybrid sliding-window attention (SWA), while the cross-decoder uses hybrid sparse attention. The KV caches for full-attention layers in the cross-decoder are generated from the hidden states of full-attention layers in the self-decoder. At the inner level, HySparse2 retains HySparse's core KV Reuse design with two refinements. First, it replaces block-level sparsity with token-level sparsity for finer long-context retrieval. Second, it removes the separate SWA branch from sparse layers and instead forces a sliding window of recent tokens into the sparse selection. This two-level KV sharing allows all cross-decoder KV caches to be constructed from self-decoder hidden states. Prefill can therefore exit after the self-decoder, skipping all cross-decoder layers. On an 80B-A3B MoE model, HySparse2 outperforms HySparse and Hybrid SWA on long-context retrieval and multi-turn agentic tasks, while substantially reducing prefill computation and KV-cache storage.

## 二、方法论：两级 KV 共享的混合稀疏注意力

### 2.1 整体架构
- 沿用 **YOCO 风格**，把骨干网络拆分为**自解码器（self-decoder）**与**交叉解码器（cross-decoder）**。
- **自解码器**：混合 **全注意力（FA）+ 滑动窗口注意力（SWA）**，负责局部建模。
- **交叉解码器**：混合 **全注意力（FA）+ 稀疏注意力（SA）**，负责全局检索。
- 两级共享：外层 **KV Bridging**，内层 **KV Reuse**。

### 2.2 外层：KV Bridging（仅桥接全注意力层）
- 仅在全注意力层之间建立桥接：设自解码器第 *i* 层与交叉解码器第 *j* 层配对，交叉解码器层 *j* 的 K/V 由**自解码器层 *i* 的输入隐藏状态**经各自独立的投影生成，Q 则由本层自身隐藏状态投影：

  $$K^{cross}_j = \text{Proj}^K_j(H^{self}_i),\quad V^{cross}_j = \text{Proj}^V_j(H^{self}_i),\quad Q^{cross}_j = \text{Proj}^Q_j(H^{cross}_j)$$

- 每个交叉解码器 FA 层拥有**独立 K/V 投影**，因此共享同一隐藏状态来源的层仍构造出不同的 KV 缓存；Q 投影独立。
- 支持两个解码器采用**不同的混合比例**，一个自解码器 FA 层可供给多个交叉解码器 FA 层。
- **关键收益**：所有交叉解码器 KV 缓存均可由自解码器隐藏状态构建，**预填充可在自解码器之后退出**，跳过全部交叉解码器层。

### 2.3 内层：KV Reuse（两项改进）
- **改进一：Token 级稀疏选择**
  - 用 **token 级 top-k 选择**替代 HySparse 的块级选择（块大小 64），在全注意力层对单个 token 打分，后续稀疏层直接复用被选中 token 的 KV 条目，在相同注意力预算下分配更精确。
- **改进二：移除独立 SWA 分支，强制局部窗口**
  - 不再保留交叉解码器中的独立 SWA 分支（含独立投影与门控融合），而是**强制把最近 128 个 token 的窗口纳入稀疏选择**，再补足最高分的窗口外 token；两类 token 都从同一份全注意力 KV 缓存中读取，由后续稀疏层复用。
  - **原因**：独立 SWA 分支需要从自身隐藏状态投影构建 KV 后缀，且依赖更早层中不断扩张的隐藏状态、随深度线性增长，形成"级联 SWA 依赖"，迫使交叉解码器处理远长于窗口的后缀，**阻碍预填充早退**。移除后按构造消除该依赖，预填充无需任何交叉解码器计算，同时省去额外投影参数。
- **配置**：token 级选择，128 个强制局部 token + 1,024 个全局 token。

### 2.4 全注意力的作用
- 保留少量全注意力层（质量关键），同时充当**天然的 indexer**：用精确注意力分数为后续稀疏层提供"oracle" token 选择，支持**原生端到端训练**，无需独立 indexer 或辅助蒸馏。
- HySparse2 预填充 KV 构建**只需一个全注意力层**。
- 未来可进一步用轻量 indexer + 稀疏注意力近似保留的 FA 层，或减少 FA 层的 query head 数、增加 SA 层的 head 数。

### 2.5 推理架构
- **预填充–解码分离（PD 分离）**：预填充节点只需部署自解码器 + KV Bridging 投影，49 层模型中仅需前 25 层，预填充节点显存需求近半；交叉解码器的 FA KV 缓存在预填充节点算好后传输给解码节点（投影后 KV 比源隐藏状态更小）。
- **投机解码**：预训练用单层 MTP（条件于自/交叉解码器边界隐藏状态）辅助收敛；后训练可替换为更大的 DFlash 风格 drafter，实现异步起草与验证。

## 六、主要结论与发现

- **质量**：预训练阶段 HySparse2 在通用能力上与两基线**大致相当**（BBH、MMLU-Pro 略强，DROP 略弱），长上下文指标最优：RULER 较 HySparse **+5.88**，NoLiMa **+9.49**，Repo Code PPL 最低（1.1570）。
- **后训练检索**：较 HySparse，平均 **MRCR-v2 +11.30**、**RULER-v2 +19.81** 个百分点；较 Hybrid SWA 分别 **+6.44 / +18.65**。256k 时 RULER-v2 达 **58.45**，HySparse 32.61、Hybrid SWA 35.74。
- **长上下文似然**：AgentPPL 与 LongPPL 在所有评测长度上均低于两基线。
- **效率**：1M token 时，预填充 FLOPs 较 HySparse 减少 **2.92×**、较 Hybrid SWA 减少 **5.02×**；KV 缓存仅 **2.69 GB**（HySparse 6.72 GB，Hybrid SWA 12.09 GB）。
- **消融结论**：
  - Token 级选择在相同预算下显著提升检索与图推理：RULER-v2 +6.57、2-needle MRCR-v2 +8.14、GraphWalks +5.55；
  - 局部信息对稀疏注意力必要（No SWA 明显退化），Forced SWA 与 Gated SWA 竞争力相当，在 RULER/RULER-v2/GraphWalks 上更优，但 GSM8K −5.08、MRCR-v2 −4.99、LongPPL +1.50%，作者认为可接受的取舍；
  - KV Bridging 在 290B-A8B 规模下质量基本无损（MMLU/TriviaQA 略升，RULER 仅差 0.31，LongPPL 由 3.6053 改善至 3.4202，BBH/GSM8K 降约 1 分，DROP 降 3.2 分）；
  - KV Bridging 优于 KV Mirror（RULER 87.65 vs 81.28），原因推测为全注意力层的隐藏状态经全局反向传播获得更稠密的监督，保留更多全局信息。
- **机制解释**：智能体轨迹中推理、工具调用与观测交错，关键 token 常散布于多轮并伴随角色分隔符；块级选择在保留一个关键 token 时被迫为其邻居消耗预算，token 级选择可更精确分配预算。

## 七、优点

- **架构设计巧妙**：把 YOCO 式跨层共享与 HySparse 的层内 KV 复用统一为**两级 KV 共享**，同时解决预填充计算、KV 存储与检索精度三类问题。
- **预填充早退机制**：通过移除交叉解码器独立 SWA 分支，按构造消除级联依赖，使预填充只需运行约一半层（含仅一个 FA 层），PD 分离下预填充节点显存近半。
- **无辅助 indexer**：复用全注意力层作为 oracle 选择器，支持端到端原生训练，避免额外蒸馏目标与模块。
- **Token 级稀疏**：在相同注意力预算下换取更高检索精度，贴合长时程智能体"精确取证"的需求。
- **工程友好**：采用 MQA 提升稀疏核效率；FA/SA 使用 NoPE，长上下文扩展无需调整 RoPE；PD 分离下传输投影后 KV 而非源隐藏状态。
- **实验维度较全**：同时覆盖通用能力、长上下文检索、智能体困惑度与系统效率（FLOPs/KV 缓存），并做了从 80B 到 290B 规模的 KV Bridging 可扩展性验证。

- **内部基准依赖**：AgentPPL、Repo Code PPL、LongPPL 采样等为内部指标，外部难以复现与直接比较。
- **消融范围受限**：消融仅报告预训练（≤32k）结果，未验证 256k 乃至 1M 上下文下的结论稳健性。
- **配置差异混淆**：HySparse2 改用 MQA 而基线为 GQA，head 维度也不同（256/256 vs 192/128），部分效率收益与质量差异无法完全归因于两级 KV 共享本身。
- **缺乏外部对比**：未与 NSA、MoBA 等
