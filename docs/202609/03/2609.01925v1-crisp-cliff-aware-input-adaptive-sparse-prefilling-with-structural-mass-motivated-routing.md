## 摘要
长上下文大型语言模型推理的注意力预填充阶段呈二次方扩展，使得自注意力成为严重的计算瓶颈。传统稀疏注意力方法通过固定模式或离线分析来缓解这一问题，但缺乏适应输入相关注意力结构的灵活性。最近的动态方法通过将注意力头实时路由到稀疏模式来解决这一问题，但依赖于间接路由代理，存在开销以及忽略softmax后质量层次结构的预算分配机制。我们提出CRISP（Cliff-awaRe Input-adaptive Sparse Prefilling），该框架识别并解决了这种动态路由范式中的两个结构性挑战。首先，我们表明路由决策可以直接从代理注意力图的结构中读取。我们用C_struct替换基于Jensen-Shannon散度（JSD）的路由，C_struct是一种结构代理，用于衡量与Vertical-Slash兼容位置的质量，并复现JSD的路由决策，同时消除了池化矩阵乘法和随后的KL散度开销。其次，我们形式化了softmax后的质量悬崖，并从理论上证明，在长上下文下，严格累积覆盖率阈值会累积O(n)的背景噪声。CRISP通过基于噪声底限的汇感知阈值来应对这一问题。在实证中，跨InfiniteBench、RULER和LongBench以及两个模型家族，CRISP总体上是最强的稀疏方法，在检索密集型基准上匹配或超越精确密集注意力，相比基线在检索任务上恢复高达+28.0个百分点，并在512k token下实现高达5.30倍的注意力加速，这主要得益于我们在选择过程中消除O(n)噪声，同时保持结构完整性。

## Abstract
The attention prefilling phase of long-context LLM inference scales quadratically, making self-attention a severe computational bottleneck. Traditional sparse attention methods mitigate this through fixed patterns or offline profiling, but lack the flexibility to adapt to input-dependent attention structure. Recent dynamic methods address this by routing heads to sparse patterns in real-time, but rely on indirect routing proxies with overhead and budget allocation mechanisms that overlook the post-softmax mass hierarchy. We present CRISP (Cliff-awaRe Input-adaptive Sparse Prefilling), which identifies and addresses two structural challenges in this dynamic routing paradigm. First, we show that the routing decision can be read directly off the structure of the proxy attention map. We replace the Jensen-Shannon Divergence (JSD) routing with C_struct, a structural proxy that measures mass at Vertical-Slash compatible positions and reproduces JSD's routing decisions while eliminating both the pooled matmul and subsequent KL divergence overhead. Second, we formalize the post-softmax mass cliff and demonstrate theoretically that strictly cumulative coverage thresholds accumulate O(n) background noise at long contexts. CRISP navigates this via a sink-aware threshold grounded in the noise floor. Empirically, across InfiniteBench, RULER and LongBench on two model families, CRISP is the strongest sparse method overall and matches or exceeds exact dense attention on retrieval-heavy benchmarks, recovering up to +28.0 pp on retrieval tasks over baselines and achieving up to a 5.30x attention speedup at 512k tokens, driven primarily by our O(n) noise elimination during selection while preserving structural integrity.

- **现有方案的不足**：
  - 传统稀疏注意力（如 Sparse Transformer、BigBird、Longformer、MInference）依赖**固定模式**或**离线离线分析**，缺乏对输入相关注意力结构的适应性——无法应对不同输入、不同上下文长度下注意力质量分布的动态变化。
  - 最新动态方法（以 FlexPrefill 为代表）虽能实时将注意力头路由到稀疏模式，但存在两个结构性缺陷：
    1. **路由信号间接且昂贵**：FlexPrefill 用 Jensen-Shannon 散度（JSD）比较"池化后估计"与"按 query 平均"两个分布来间接判断注意力头的集中程度，为此需支付额外的池化 matmul、softmax 和 KL 散度开销；
    2. **预算分配机制忽视质量悬崖**：基于累积覆盖率阈值 γ 的索引选择算法，未考虑 softmax 后注意力质量的"三层次结构"（注意力汇、任务信号、背景噪声），在长上下文下会**系统性累积 O(n) 的背景噪声**。
- **核心洞察**：路由决策可直接从代理注意力图的**结构特征**中读出（集中型注意力头会把质量放在注意力汇和局部最近窗口等结构上可预测的位置），而无需通过分布比较间接推断。

## 2. 方法论

### 2.1 总体框架

CRISP 的稀疏注意力流程分为两步：先用 **C_struct（结构化质量代理）** 做 VS/PE 模式路由，再按路由结果选择不同的索引选择路径（VS 走 sink-aware 阈值，PE 沿用 γ-cumsum）。

### 2.2 C_struct：替代 JSD 的结构化路由代理

**定义**：

C_struct = (1/|Q̂|) · Σᵢ∈Q̂ Σⱼ∈S_anchor Â[i, j]

其中：
- Q̂ 为代表性 query 子集（取最后 b 个 query block 的 token）；
- S_anchor 包含**架构注意力汇**（前 w_sink=128 个 token）和**局部最近窗口**（最后 w_local=128 个 token）；
- Â 是代理注意力矩阵（对 Q̂Kᵀ/√d 做 softmax）。

**关键性质**：
- 低熵（集中）注意力头在现有具备 sink 的架构中，质量主要集中在上述锚定位置——实验测得 top-1 质量块落在 sink/recency 的概率达 91.3%（Llama）和 98.3%（Qwen）；
- C_struct 与 JSD 路由决策的一致性达 94.0%（Llama）和 88.1%（Qwen）；
- 计算开销仅为 O(w_sink + w_local) 的常数时间切片归约，与序列长度 n 无关，完全消除了 FlexPrefill 中 JSD 所需的池化 matmul 和 KL 散度开销。

**路由规则**：C_struct ≥ τ_proxy 则走 VS 路径，否则走 PE 路径。

### 2.3 质量悬崖与 sink-aware 阈值（核心理论贡献）

**质量悬崖定义**：softmax 后注意力质量呈三层次结构——
1. **架构性 sink**（首块 token）可能吸收 >90% 总质量；
2. **任务相关信号块**：中等、高于基线的质量；
3. **背景噪声**：近零质量，单个 token 质量 ε ~ O(1/n)。

**累积阈值 γ 的两个失效模式**：
- **Sink-only collapse（sink 坍缩）**：当 a_sink ≥ γ 时，选择在达到任何任务相关 token 之前就终止，形式上有界但语义信息为零；
- **Residual noise accumulation（噪声累积）**：当 a_sink + a_important < γ 时，算法翻越悬崖进入背景噪声，需收集 N_garbage ≈ γ_residual · n = **O(n)** 个噪声块。

论文证明调 γ 无法解决此问题：提高覆盖率只会更深地进入噪声。γ=0.95→0.97 的实验（表 2）证实了这一预测：有些基准下降、有些微升，效果不一致，且伴随显著延迟惩罚。

**sink-aware 阈值规则**（Algorithm 3）：
1. 将代理注意力图划分为 N_b = ⌈n/B⌉ 个块（B=128）；
2. 始终保留第一块（sink）和最后一块（局部最近），二者与锚定窗口恰好重合；
3. 对剩余 N_b − 2 个块计算背景期望质量：

μ = max(1 − a_first − a_last, 0) / (N_b − 2)

4. **选择条件**：块 j 被选中当且仅当 p_j > α·μ。

α=1.0 时阈值等于背景平均质量，是**免标定的默认值**；随着 sink 质量增长，μ 自动降低，从而保持对信号的敏感度。所选块数由任务复杂度自然涌现（聚焦任务选得少、稠密任务选得多），与 γ 的"覆盖率目标"逻辑根本不同。

## 6. 主要结论与发现

1. **路由层面**：C_struct 以接近 94%（Llama）/ 88%（Qwen）的一致性复现 JSD 的路由决策，同时删除池化 matmul 和 KL 散度开销，且托普-1 质量位于锚位置的比例极高（91.3%/98.3%），验证了"结构质量可直接读取路由决策"的核心断言。
2. **理论层面**：形式化证明严格累积覆盖率阈值在长上下文下必然累积 O(n) 背景噪声，且 γ 调优无法修复（sink-only collapse 与 noise accumulation 是参数性不可修复的结构缺陷）。γ=0.95→0.97 的实验退化/不一致即为该预测的经验证据。
3. **精度层面**：CRISP α=1.0 在 InfiniteBench 上**达到或超过精确密集注意力**（Llama 48.7 vs 48.6；Qwen 28.7 vs 24.0，超额部分来自消除 sink 噪声的更干净信号表示）；在检索任务上最高恢复 +28.0pp（Qwen passkey）；LongBench 上以 +0.85/+1.66pp 超过 FlexPrefill。
4. **效率层面**：512k token 下实现最高 5.30×（α=1.25）乃至 5.40×（α=1.5）注意力加速比；所有 CRISP 配置在 131k 之后超越对应 FlexPrefill 基准，增速差距随上下文长度线性扩大——将 O(n) 定理实证化。
5. **鲁棒性层面**：α 在 [0.75, 1.0] 区间内表现稳定（噪声地板是一个稳定区域而非刀刃），τ_proxy 在 {0.15, 0.2, 0.25} 内产生 <1.2pp 的波动，方法无需逐模型逐任务标定。
6. **架构迁移性**：Qwen3-4B 上重复了相近的结果形态（InfiniteBench 超额 +2.6pp、LongBench 差距最小），暗示机制不限于主实验两个模型。

## 7. 优点

- **理论-实验闭环**：从 softmax 后质量分布的渐近分析（O(n) 噪声）出发做出可检验预测，再以 γ 调优失效实验做精确验证，方法论严谨。
- **免标定默认值**：α=1.0 有"高于背景平均质量即信号"的清晰解释学意义，规避了覆盖率阈值需要经验调参的根本问题。
- **免训练且保精度**：在选定块上计算精确 softmax 注意力，不改架构、不需微调/蒸馏，与线性注意力（Mamba 等）方向正交互补。
- **成本消除具有结构必然性**：C_struct 复用索引选择已计算的 Â，只做常数时间切片归约；VS 路径阈值同样基于已计算的方向分数，除常数因子外"零新增成本"。
- **消融揭示非平凡交互**
