## 摘要
大型语言模型在需要扩展推理的任务上表现出卓越性能，但长思维链使得KV缓存成为严重的内存瓶颈。现有的KV缓存压缩方法共享一种范式：通过某种对每个缓存token未来重要性的估计来评分，并保留得分最高的那些。我们表明，这种选择信号几乎没有任何贡献。随机注意力保留提示词，并在每个注意力头内均匀随机驱逐，不计算任何分数；在四个模型和六个推理任务中，它与最强的先前驱逐器性能相当，同时在vLLM部署中服务吞吐量高出32-43%。受控实验解释了这一点，表明：1）提示词是缓存中脆弱的部分，而选择器之间的大部分差距仅仅在于它们的选择信号是否恰好保留了它；2）推理轨迹通过两个层面的冗余自我保护免受驱逐——在文本层面（模型在推理过程中会重申它仍然需要的内容）和跨注意力头层面（每个头保留自己的轨迹副本）——因此一旦提示词安全，随机抽取就能保留足够的模型仍需要的内容副本，而无需任何分数来选择它们。我们的代码公开于 https://github.com/SalesforceAIResearch/Random-Attention。

## Abstract
Large language models achieve superior performance on tasks that require extended reasoning, but long chains of thought make the KV cache a severe memory bottleneck. Existing KV cache compression methods share one paradigm: score each cached token by some estimate of how much it will matter later, and keep the top-scoring ones. We show that the selection signal contributes almost nothing. Random Attention keeps the prompt and evicts uniformly at random within each attention head, computing no score at all; across four models and six reasoning tasks it matches the strongest prior evictor while serving 32-43% higher throughput than it in vLLM deployment. Controlled experiments explain this by showing that 1) the prompt is the fragile part of the cache, and most of the gap between selectors is just whether their selection signal happened to keep it; 2) the reasoning trace protects itself against eviction with redundancy at two levels, in the text (the model restates what it still needs as it works) and across attention heads (each keeps its own copy of the trace), so once the prompt is safe, a random draw retains enough copies of what the model still needs, and no score is required to pick them. Our code is publicly available at https://github.com/SalesforceAIResearch/Random-Attention.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

**核心思想**
- 将KV缓存内容分为两类：
  - **提示词（prompt）**：只陈述一次、在推理中不会复述，一旦被逐出就无法恢复，是缓存中最脆弱的部分；
  - **推理轨迹/工作状态（working state）**：模型在推理过程中持续重述并复用它仍需要的内容，因此天然冗余，即使随机丢弃一部分也不会造成不可逆的语义损失。
- 保护前者，对后者进行无信号随机逐出即可获得与现有驱逐器相当的精度，且拥有更高的效率。

**方法定义（技术细节）**
- 保留整个prefill（系统提示、聊天模板、问答输入）的前ℓp个位置，永不逐出；
- 对于所有其他缓存位置，赋以独立同分布（i.i.d.）的均匀随机分数；
- 每个KV头独立按该随机分数执行top-K选择，丢弃其余缓存。这意味着不同头保存的内容各不相同，使跨头的冗余最大化。

**形式化表达与算法流程**
- 评分函数为：
  - s_i = +∞（当 i ≤ ℓp，即提示词部分），
  - s_i = u_i ~ Uniform(0,1)（其余位置），且每次都独立地按每个KV头进行抽样。
- Algorithm 1 流程（每次降局触发时的评分；按层执行）：
  1. 生成形状为 (batch, KV头数, 缓存位置数) 的均匀随机分数；
  2. 将前ℓp个位置强制设为+∞（保证保留提示词）；
  3. 执行按KV头独立的top-K（取最高K个位置）得到保留集合。
- 整个过程只调用一次随机数生成和一次topk，没有任何缓存统计量的扫描或计算。

**隐含特性（与已有方法的对比）**
- 虽然不使用年龄等显式信号，但由于每次驱逐都是一次新的随机抽样，位置被保留的概率会随年龄递减（约0.94^n），因此Random Attention事实上充当了一个“软近因窗口”。但它与StreamingLLM式的纯最近窗口不同：保留集合中还存在一条由各头独立抽样形成的“极薄的跨头交错长尾”，这是全无关联的公式基线无法覆盖的关键部分。

## 6. 论文的主要结论与发现

1. **随机注意力在精度上匹配最强的现有驱逐器**。在4个模型与6个推理任务上，Random Attention与TriAttention总体持平；在所对比的60个基线单元中，31个单元显著优于各基线，仅1个单元显著落后（Qwen3-32B上的LiveCodeBench，落后TriAttention约3个点）。
2. **选择信号几乎没有额外收益**。一旦将提示词保护规则统一加到所有方法上（"score alone + prompt"对比），大部分方法之间的差距即消失，方法都会获得与其此前“丢失提示词程度”完全对应的增益（SnapKV最高提升35.2个点，R-KV基本无增益），这表明多数现有差距其实来自提示词是否被意外保留。
3. **提示词是缓存中唯一脆弱的部分**。随机丢弃推理轨迹对结果影响很小；而丢失提示词会造成灾难性精度下降（如纯近因窗口加保护前后相差最高59.7个点）。
4. **推理轨迹通过两级冗余自我保护**：
   - 文本层面：模型在长推理中反复“重述”它仍然需要的内容；
   - 跨注意力头层面：不同头各自保存不同的副本，原始信息只有在所有KV头同时丢失时才真正不可恢复——现实推理中这种全丢失极少出现。
5. **跨头信息并不依赖于“拷贝的形状”**：保留哪些头、以何种块形式存在都不会显著影响召回，唯一的必要条件是至少某个注意力头仍持有某个可用副本。
6. **选择信号真正剩下的唯一优势场景**是“只陈述一次、从未复述、之后很久才需要的孤立事实”。随机驱逐几乎不保留这种“针”；而重要性累积类评分（如R-KV）在此场景表现显著更好。但推理轨迹中很少出现这种孤立事实（模型通常在处理中反复复述其依赖信息）。
7. **效率结论**：在vLLM+PagedAttention部署中，Random Attention比最强基线（TriAttention）贡献32–43%的吞吐提升（1.6–2.7×全注意力的吞吐水平），其直接原因是完全取消了评分扫描，驱逐成本降至纯压缩的开销（每轮~0.3 ms，仅为TriAttention的大约1/5）。

**服务端工程角度的高度（续）**：Random Attention 在实现上几乎没有任何工程成本——无需维护额外统计量、无需校准超参、也无需与推理引擎做复杂状态同步。它只依赖一次均匀随机抽样和 top-k 操作，天然适合分布式与异步解码环境。相比之下，SnapKV/R-KV 需要定期计算查询—键交互或调整惩罚系数，TriAttention 也需要维护位置函数与键范数等变量，这些额外逻辑在长序列、高并发场景下会累积为不可忽略的调度与显存开销。因此，Random Attention 不仅是理论上“最弱的选择信号”，也是部署上“最经济的驱逐策略”，这种工程优势反过来强化了论文的核心论点：如果连如此简单的随机方法都不输给复杂评分器，那么现有评分机制所带来的收益在多数真实推理任务中几乎可以忽略。

---

## 8. 不足与局限性

1. **任务覆盖范围有限**：所有实验都集中在数学（MATH500、AIME、HMMT）、科学（GPQA-D）和代码（LiveCodeBench）六类推理任务上，这些任务共有“模型会进行密集的中间重述与自校验”的特点。对于多轮对话、长文档摘要、信息抽取、开放域问答等未必存在大量重述的任务，随机驱逐可能无法同样安全，结论的外部效度有待考证。
2. **“保护提示词”这一规则具有较强的任务依赖**：提示词在受到保护后不会被随机丢弃，但真实客服或多轮会话中的“历史消息”同样只有一次陈述机会，且可能被模型长期依赖。本文的保护规则简单而粗暴——一律保留固定的前 ℓp 个位置，没有考虑提示词内部是否存在冗余或更早的交互语料，距离一个完整的上下文感知保护策略仍有差距。
3. **“重复即生存”机制无法解释所有推理行为**：论文认为模型通过文本重述和跨头冗余来自我保护，但推理轨迹中并非所有 token 都会被复述。若遇到一次陈述后即被遗忘、又在数千 token 之后才被重新用到的内容——这正是某些算法题中记录中间答案、再在结尾回溯取用的结构——随机驱逐可能产生风险，而论文只在合成“planted-fact”实验中对这种模式做了专门测量，并确认这是评分器唯一尚能取胜的场景。该场景虽在现有基准中不多见，但并不能保证在所有推理任务中都不出现。
4. **显式没有分析时间与内存开销的详细分解**：论文主要报告了单轮压缩耗时和端到端吞吐，但缺少对多层、多头驱逐时随机数生成与 top-k 操作在各硬件环境下的极限分析。调度频率（每 64 步）固定，未讨论自适应触发间隔对结果的影响；不同批次大小、张量并行度下的表现仍未完全展开。
5. **比较协议的“公平”可能是表面的**：所有基线被放在同一 VaSE/KV 引擎上运行，但原论文中各方法内部可能有针对原引擎的微小优化或依赖。论文虽然进行了校准（如 TriAttention 排名一致性、R-KV 精度差），仍然无法完全排除“将方法移植到新引擎时因实现差异而使其表现退化”的可能性。随机方法的优势有一小部分可能来自基线在不同引擎上的表现折扣。
6. **统计功效有限**：部分数据集规模较小（AIME 仅 30+30 题，HMMT 仅 60 题），加上多轮测试导致的非独立样本，使得某些“无显著差异”的结论可能源于统计功效不足，而非真正意义上的等价。论文用 bootstrap 置信区间和符号检验做了缓解，但在小样本极限下仍难以完全排除 II 类错误。

---

## 9. 对领域的影响与研究价值

- **改变了“KV 压缩 = 分数设计”的思考范式**。过去几年大量工作沿着“设计更聪明的分数函数”这一路径推进，本文用随机基线划出了一条“下限”——如果评分器连这个下限都无法击穿，说明问题根本不在于分数函数，而在于缓存中信息生命周期的结构性不对称。后续研究很可能把重心转向“如何识别和保留不可重述但关键的信息”以及“如何在压缩前提高推理轨迹自身的恢复能力”。
- **为“提示词保护”提供了理论依据和可操作的基线**。早在 StreamingLLM、H2O 等工作中便有人提及保留初始 token 的重要性，但从未有工作将其作为范式中的一等公民独立量化。本文明确把提示词保护和驱逐策略拆开，并证明前者是精度上浮的最大来源。这为以后所有 KV 压缩论文提供了一个必须新增的对照实验：如果方法没有排除提示词保护的混淆，其报告增益的真实性就需要打问号。
- **提供了“随机驱逐”这一极简部署方案**。对于要求低成本、高吞吐的对齐服务，Random Attention 可以无需任何调参直接取代现有压缩模块，且可在主流推理框架中几乎零侵入地落地。这对工程社区具有直接价值。
- **但论文并非宣告“评分器无用”**。相反，它精确地划定了评分器仍然有价值的窄区域：当关键信息以孤立事实形式出现、且缺乏跨头冗余和文本重述时，重要性累计型分数（如 R-KV）仍能显著胜出。这为未来继续优化评分器的研究留下了值得深耕的细分方向。

---

## 10. 总结

本论文通过一个思想极简但执行严格的实验——在每个注意力头内随机保留提示词之外的 KV 缓存——颠覆了长推理 KV 驱逐研究中对“选择信号”必要性的默认假设。它证明：在 Qwen3、Phi-4-reasoning 等模型上覆盖数学、科学、代码的众多推理任务中，最先进评分驱动驱逐器相比随机驱逐只有微弱的、不稳定的优势；这一优势几乎全部来自“是否意外保护了提示词”这一规则差异，而非评分本身。同时，推理模型通过输出重述和跨注意力头冗余形成了天然的数据自恢复能力，进一步降低了对精确选择信号的需求。这一发现既是工程部署上的重要简化，也是未来 KV 缓存压缩研究范式转向的明确信号：与其继续追逐更复杂的打分函数，不如系统地理解提示词的脆弱性、推理轨迹的冗余结构，以及它们在不同任务与架构下的边界条件。
