## 摘要
大型语言模型（LLM）是有效的重排序器，但逐点重排序在不同查询间重复处理同一文档，导致大量冗余的文档侧计算。我们提出\textbf{DoPR}，一种压缩文档前缀框架，将离线文档处理与在线重排序解耦。DoPR首先选择与查询无关的文档表示，并将其转换为压缩文档前缀状态，这些状态在离线时预计算，并在文档被检索到时复用。在线重排序期间，模型仅处理查询和评分标记，通过存储的前缀状态提供文档信息，从而对每个查询-文档对进行评分。这种设计通过文档侧压缩和跨查询前缀状态复用降低了在线成本。在TREC DL、BEIR和BRIGHT上使用Qwen3模型（从0.6B到8B）的实验表明，DoPR实现了高达8.0倍的在线文档侧内存减少和高达8.04倍的延迟加速，同时保留了匹配的全文档重排序器平均NDCG@10的\textbf{97.1%-99.5%}。

## Abstract
Large language models (LLMs) are effective rerankers, but pointwise reranking repeatedly processes the same document across different queries, causing substantial redundant document-side computation. We propose \textbf{DoPR}, a compressed document prefix framework that decouples offline document processing from online reranking. DoPR first selects query-independent document representations and converts them into compressed document prefix states, which are precomputed offline and reused whenever the document is retrieved. During online reranking, the model scores each query-document pair by processing only the query and scoring token, with document information supplied by the stored prefix states. This design reduces online cost through both document-side compression and cross-query prefix-state reuse. Experiments on TREC DL, BEIR, and BRIGHT with Qwen3 models from $0.6$B to $8$B show that DoPR achieves up to 8.0$\times$ online document-side memory reduction and up to 8.04$\times$ latency speedup, while retaining \textbf{97.1\%-99.5\%} of the average NDCG@10 of matched full-document rerankers.

# DoPR: 用于高效 LLM 重排序的可复用压缩文档前缀

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：点式（pointwise）LLM 重排序器在处理不同查询时，会反复对同一文档进行完整的编码和计算，导致大量**冗余的文档侧（document-side）计算**。在真实检索系统中，同一文档往往会被许多不同查询反复检索到，这种重复处理成为部署 LLM 重排序器时在延迟和内存方面的主要瓶颈。
- **现有方法的不足**：
  - 提示压缩、令牌剪枝等方法虽然能降低单次推理实例的成本，但其压缩结果通常与特定查询或提示绑定，仍然需要对同一文档在不同查询下重新处理。
  - 可复用的文档侧表示方法（如 ColBERT 的后期交互、预计算词项表示等）虽然能预计算文档信息，但通常用于检索阶段匹配或专用交互函数，而非直接作为 LLM 重排序器的内部状态复用。
- **研究问题**：是否可以在点式 LLM 重排序内部实现文档侧计算的可复用性，从而从根本上消除跨查询的冗余文档处理？
- **核心贡献**：提出 DoPR 框架，将可复用的文档侧计算从在线重排序中解耦出来——文档在离线阶段被处理为**压缩前缀状态（compressed prefix states）** 并存储复用，在线阶段仅需处理查询和评分标记，大幅降低在线开销。

## 2. 论文提出的方法论

### 核心思想

DoPR 的核心思路是将文档表示为少量"压缩文档表示"并将其转换为**压缩文档前缀状态**，使得文档侧计算可以**离线执行一次**，并在不同查询之间反复复用。

整体框架分为三个阶段：

1. **训练阶段（Training Phase）**：端到端训练文档表示选择与相关性评分
2. **离线压缩阶段（Offline Compression）**：在部署时离线预计算并存储压缩文档前缀
3. **在线重排序阶段（Online Reranking）**：仅处理查询和评分令牌，复用存储的前缀状态

### 关键技术细节

**（1）基于注意力的关键令牌选择（Attention-based Key Token Selection）**

- 对文档 $d = \{d_1, d_2, ..., d_n\}$ 进行独立编码，获取最终层令牌状态 $H_d \in \mathbb{R}^{n \times d_h}$
- 利用最终层自注意力矩阵（跨注意力头取平均）作为显著性信号
- 对每个令牌 $d_i$ 计算显著性分数 $u_i$——取其注意力列向量中 top-p 值的均值
- 根据显著性分数排序，选择 top-$K_{\text{train}}$ 个文档令牌的隐藏状态作为压缩文档表示 $C_d$
- 该选择方式**无需额外的可训练选择器**，是一种轻量级方案

**（2）结构化注意力掩码（Structured Attention Mask）**

- 训练输入序列为 $x = [d; C_d; q; t_{\text{score}}]$
- 施加结构化注意力掩码：原始文档令牌被独立编码（不能看到查询）；查询和评分令牌**只能通过 $C_d$** 访问文档信息
- 这使得 $C_d$ 成为训练中唯一的文档到查询信息通路，保证训练与部署场景的一致性

**（3）训练目标**

- 使用交叉熵形式的 RankNet 成对损失（pairwise RankNet loss）：
$$\mathcal{L}_{\text{RankNet}} = \log(1 + \exp(-(s(q, d^+) - s(q, d^-))))$$
- 梯度通过评分令牌、查询表示交互和选中文档令牌状态进行反向传播，使得所选文档表示为**排序任务**而非通用重建进行优化

**（4）离线压缩与在线推理**

- 部署时，对每个文档执行文档专用前向传播，确定 top-$K_{\text{infer}}$ 个显著位置并提取表示，将其作为文档前缀输入重排序器，得到的多层 KV 状态被存储为压缩文档前缀状态
- $K_{\text{infer}}$ 可独立于 $K_{\text{train}}$ 设置，允许部署时进行质量-成本权衡
- 在线重排序时，仅传输查询和评分令牌，文档信息完全由存储的前缀状态提供
- 文档预算从 $n$ 个令牌缩减为 $K_{\text{infer}}$（默认 8 倍压缩率，保留 12.5% 的文档令牌）

## 6. 论文的主要结论与发现

1. **有效性保留**：在 TREC DL 和 BEIR 上，DoPR 保留匹配的 Qwen3-Rerank 平均 NDCG@10 的 97.1%（0.6B）、99.3%（4B）和 99.5%（8B）；在 BRIGHT 上保留 98.6%、99.1%、98.8%。
2. **效率提升**：实现最高 8.0 倍的在线文档侧内存减少和最高 8.04 倍的延迟加速；在更长文档的数据集（如 Covid）上加速效果更显著；在 Touche/News/Robust（2048 token 文档）上最高可达 18.96 倍加速。
3. **大模型更耐受压缩瓶颈**：模型规模增大时，前缀瓶颈带来的质量损失明显减小。
4. **摊销收益**：文档复用次数越多，DoPR 的总成本优势越明显；在长文档场景下离线成本被更快速摊销。
5. **推理预算可调**：$K_{\text{infer}}$ 无需重训即可调整，在实际部署中能灵活权衡质量与成本。
6. **注意力引导选择有效**：相比 First-K、Uniform-K、Random-K 等替代方案，基于注意力的 Top-K 令牌选择在相同预算下取得最佳效果。
7. **跨架构有效**：DoPR 在 Llama-3.2-1B 上保留 97.48% 的平均 NDCG@10，说明其不依赖特定模型架构。

## 7. 优点

1. **问题定位准确**：精准识别了 pointwise LLM 重排序中"同一文档跨查询重复编码"的核心冗余，并通过前缀状态的跨查询复用从机制上消除了这一瓶颈。
2. **方法简洁高效**：无需额外引入可训练选择器，注意力信号是"轻量且免参数"的显著性指标，不会增加模型复杂度。
3. **训练-部署一致性设计**：通过结构化注意力掩码确保训练时文档信息仅能通过压缩表示到达查询，使模型在训练阶段就适应部署时的信息瓶颈，这一设计巧妙且必要。
4. **双路径效率收益**：同时从"文档侧压缩"（单次推理成本降低）和"跨查询前缀复用"（多次推理共享成本）两个维度提升效率。
5. **推理预算灵活**：$K_{\text{infer}}$ 可独立于 $K_{\text{train}}$ 调节，且无须重新训练，对实际工程部署友好。
6. **实验验证全面**：在多个基准、多个模型规模上进行了系统评估，并包含了消融、跨模型族验证和效率分析。

## 8. 不足与局限

1. **依赖文档复用场景**：DoPR 的效率优势来自文档压缩与跨查询前缀复用的结合。若文档集变更频繁或文档很少被多次检索到，则复用收益有限，主要收益仅来自压缩。
2. **离线处理与存储开销**：大规模部署需要预处理整个文档集合并存储压缩前缀，增加了索引和存储开销。需要额外的存储成本（所有文档的前缀 KV 状态）。
3. **小模型性能下降更明显**：0.6B 模型在 Touche（91.9%）、Signal（94.2%）、Robust（93.8%）等数据集上的保留率相对较低，说明小模型对信息瓶颈更为敏感，适用范围受限。
4. **部分推理密集型子集性能波动大**：在 BRIGHT 中部分子集的保留率存在剧烈波动（如 0.6B 时 Pony 为 147.6%，Susteanability 为 79.8%），任务层面的差异性明显，固定前缀预算可能不足以应对需要分散证据或细粒度匹配的任务。
5. **未知的领域拓展边界**：实验集中于英文文本；多语言、多模态或代码检索等其他类型任务的有效性仍有待验证。
6. **评测范围和训练时间报告不足**：BRIGHT 未与最新推理检索方法进行系统比较；且文中未明确报告训练总步数 / 训练时长，也不清楚评估集合在训练过程中的使用方式。
