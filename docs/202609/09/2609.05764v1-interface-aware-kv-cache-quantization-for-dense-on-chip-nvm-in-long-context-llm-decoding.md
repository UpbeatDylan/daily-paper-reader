## 摘要
键值（KV）缓存是长上下文大语言模型（LLM）解码中的主要内存瓶颈：每一步都要完整读取它，因此解码受限于内存带宽。将量化后的KV缓存保存在密集的片上非易失性存储器（NVM）中，可以消除片外传输。然而，现有的KV量化方法是为GPU风格的内存系统设计的：KIVI附加了每组元数据，使存储的KV缓存增加约25%；KVQuant保留了密集阵列无法原位容纳的稀疏全精度离群值。本文研究了当KV缓存驻留在具有固定范围转换器的NVM中时这些结构所带来的开销，并设计了一种与该接口匹配的量化方案。该架构将量化后的KV缓存存储在密集的片上NVM中，仅使用一个小型静态模拟交叉开关用于固定旋转，并将注意力计算保留在片上的数字逻辑中。随机旋转和每向量归一化使每个坐标具有相同的范围，因此一个固定的键码本和一个固定的值码本，分别由相应张量类型的所有token共享，即可服务于整个KV缓存。码本阈值被一次性编程为读取转换器的参考电平，从而无需对每个token进行转换器重新配置即可实现固定范围数字化。反量化是一个十六项查找和一次范数乘法；唯一的每向量元数据是一个标量，约占3%。在3B到14B的模型和32k token的上下文中，四比特KV缓存在模拟实际设备级别的存储和交叉开关噪声下保持了准确性。KIVI和KVQuant在软件中仍然更准确；我们格式的优势在于内存接口：与映射到相同NVM的两种方法相比，KV读取能量降低3.1-3.6倍，元数据开销比KIVI低8倍。其贡献在于与NVM内存接口协同设计的KV量化，而非新的精度记录。

## Abstract
The key-value (KV) cache is the dominant memory bottleneck in long-context large language model (LLM) decoding: every step reads it entirely, so decoding is memory-bandwidth bound. Holding a quantized KV cache in dense on-chip non-volatile memory (NVM) removes the off-chip transfer. Existing KV quantization methods, however, were designed for GPU-style memory systems: KIVI attaches per-group metadata, adding about 25% to the stored KV cache; KVQuant keeps sparse full-precision outliers that a dense array cannot hold in place. This paper examines what these structures cost when the KV cache resides in NVM behind fixed-range converters, and designs a quantization scheme matched to that interface. The architecture stores the quantized KV cache in dense on-chip NVM, uses a small static analog crossbar only for the fixed rotation, and keeps attention in on-chip digital logic. A randomized rotation and per-vector normalization give every coordinate the same range, so one fixed codebook for keys and one for values, each shared across all tokens of the corresponding tensor type, serve the entire KV cache. The codebook thresholds are programmed once as the read converter's reference levels, enabling fixed-range digitization with no per-token converter reconfiguration. Dequantization is a sixteen-entry lookup and one norm multiply; the only per-vector metadata is one scalar, about 3%. Across models from 3B to 14B and contexts to 32k tokens, the four-bit KV cache maintains accuracy under storage and crossbar noise simulated at realistic device levels. KIVI and KVQuant remain more accurate in software; the advantage of our format lies at the memory interface: 3.1-3.6x lower KV read energy than both mapped to the same NVM, and 8x lower metadata overhead than KIVI. The contribution is a KV quantization co-designed with the NVM memory interface rather than a new accuracy record.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：在长上下文大语言模型（LLM）的自回归解码中，**KV缓存（Key-Value Cache）** 是内存带宽的主要瓶颈。每一步解码都需要完整读取KV缓存，尤其是当序列长度增长时，这部分数据访问开销呈线性增长，导致解码过程受限于内存带宽而非计算吞吐。
- **现有方案的局限**：人们常使用量化来减小KV缓存。现有SOTA方法如 **KIVI** 和 **KVQuant** 是为GPU风格的内存系统设计的，它们引入了在密集NVM阵列中难以高效实现的结构。
  - **KIVI**：为每组坐标附加全精度缩放因子和零点，**元数据开销约为25%**，相当于每个坐标多了一个有效位。
  - **KVQuant**：保留稀疏的**全精度离群值**，导致存储不规则，需要独立内存并每次读取时进行聚集（gather）操作，这在密集的NVM阵列上无法原位实现。
- **核心矛盾**：将KV缓存放入密集的**片上非易失性存储器（NVM）**（如RRAM）可以消除片外传输并实现高密度存储，但NVM接口（固定范围的模数转换器）与GPU量产化方法中依赖“动态元数据”和“稀疏结构”的设计存在严重的不匹配。
- **本文目标**：设计一种**与NVM内存接口协同设计**（Interface-Aware）的KV量化方案，以保证量化格式能在密集、固定范围的NVM阵列上高效、准确地运行。

### 2. 方法论（核心思想与技术细节）

本研究提出了一套量化与数据路径设计，核心思想是**通过统一的数学变换和固定的码本，消除对动态元数据与稀疏结构的依赖**。

- **总体数据路径**：如图2所示，新的键/值向量先经过一个静态的**模拟旋转交叉开关**（Hadamard变换），随后进行**每向量归一化（per-vector normalization)**。接着，归一化向量的每个坐标被映射为**码本索引**，只有这些索引被写入NVM阵列，每个向量的归一化标量（范数）则存储在SRAM中。读取时，通过转换器恢复索引，再经过**查找表和一次乘法**反量化，注意力计算全程在数字逻辑中进行。
- **关键技术细节**：
  - **随机旋转 (Randomized Rotation)**：利用**随机Hadamard矩阵 H** 旋转向量，以抑制离群值并将能量均匀分布到所有坐标。由于H是正交的，注意力内积在旋转后保持不变：`qTk = (Hq)T (Hk)`。同时，旋转放置在RoPE之后，并将反旋转 (H^T) 离线折叠进输出投影（`W′_O = W_O H^T`），确保解码时无需每token执行逆变换。这为固定量化范围创造了条件。
  - **每向量归一化 (Per-vector Normalization)**：每个旋转后的向量被归一化为单位长度 `x̃ = Hx / ||Hx||`，其长度用一个标量范数r记录。这使得所有坐标的取值范围严格限定在 [-1, 1]，从而共用同一个码本。
  - **固定共享码本 (Fixed Shared Codebooks)**：量化坐标值使用一个固定码本 C（一组电平与决策阈值），所有token（键或值）共用一个码本。阈值通过Lloyd-Max算法（迭代求取量化误差最小的电平和阈值）优化后，一次性编程为读取转换器的参考电平，实现无需逐token重新配置的固定范围数字化。
    - **键码本**：基于理论推导的近似高斯分布，采用**数据无关的分析码本**，无需任何校准数据。
    - **值码本**：由于值Tails更重（超值峰度约2.25），采用一次性的**离线校准**拟合码本。
  - **硬件实现**：
    - 旋转交叉开关是**静态写入一次的模拟阵列**，其噪声是固定且有界的，不会在每次token间重新注入。
    - KV缓存存储的是**写入一次的索引**，而非模拟量，提高了对存储噪声的鲁棒性。
    - 唯一的每向量元数据是一个标量（fp16），约占存储总量的3%，保存在数字SRAM中。
- **模型特定处理 (Qwen2.5)**：针对Qwen2.5注意力投影带偏置（β）的问题，采用**预先减去偏置、反量化时再加回**（`k̂ = Q(W_k z) + β`）的方式，将该静态偏置作为常量处理，避免了必须依赖每token零点的问题。

- **核心发现**：现有KV缓存量化器（如KIVI的25%元数据、KVQuant的稀疏高精度离群值）在为GPU设计的硬件架构上运行平稳，但在密集NVM阵列上会转化为巨大的容量开销、SRAM面积、重构复杂度和读取能耗。KVQuant一旦失去稀疏离群点结构，在NVM上的检索精度大幅下降。
