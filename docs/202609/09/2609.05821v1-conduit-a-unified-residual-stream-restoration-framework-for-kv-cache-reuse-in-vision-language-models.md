## 摘要
视觉语言模型（VLM）通常回答关于反复出现的视觉内容的新问题，此时重用键值（KV）缓存可以避免重新编码昂贵的视觉前缀。然而，当相同视觉内容在改变的前缀下出现时，精确前缀重用会失效。选择性重计算可以在较小的视觉令牌预算下恢复质量，但前提是刷新正确的过时令牌。原始注意力选择可能会将预算浪费在具有较小值范数代理分数的高注意力令牌以及与查询无关的图像上。为解决这些失效模式，我们提出CONDUIT，一种无需训练的刷新策略，将单图像和多图像重用统一为残差流恢复。基于范数加权注意力，CONDUIT使用缓存的键查询注意力和一个可访问的输出前缓存值范数代理对缓存的视觉令牌进行排序，然后在一次全局选择前应用经验性的图像级相关性放大。对于单图像情况，系数为1，该规则退化为图像内令牌选择。该方法保留模型架构和权重，仅在推理时增加一次查询条件得分传递。在10%刷新预算下，CONDUIT在三个VLM骨干网络上实现了相应全预填充五数据集平均值的97.0%-99.5%，并在平均性能上领先于预算限制方法；在MMLongBench-Doc延迟子集上，它使用了全预填充FLOPs的13.5%，并实现了2.99倍的首令牌时间加速。

## Abstract
Vision-language models (VLMs) often answer new questions about recurring visual content, where reusing the key-value (KV) cache can avoid re-encoding expensive visual prefixes. Exact-prefix reuse, however, fails when the same visual content appears under a changed prefix. Selective recomputation can recover quality under a small visual-token budget, but only when the right stale tokens are refreshed. Raw-attention selection can waste budget on high-attention tokens with small value-norm proxy scores and on query-irrelevant images. To address these failure modes, we propose CONDUIT, a training-free refresh policy that unifies single- and multi-image reuse as residual-stream restoration. Building on norm-weighted attention, CONDUIT ranks cached visual tokens using cached-key query attention and an accessible pre-output cached-value-norm proxy, then applies empirical image-level relevance amplification before one global selection. With one image, the coefficient is one and the rule reduces to intra-image token selection. The method preserves model architecture and weights, adding only a single query-conditioned scoring pass at inference. At a 10% refresh budget, CONDUIT achieves 97.0-99.5% of the corresponding full-prefill five-dataset average across three VLM backbones and leads budgeted methods on average; on the MMLongBench-Doc latency subset, it uses 13.5% of full-prefill FLOPs and achieves a 2.99x time-to-first-token speedup.

## 1. 论文的核心问题与整体含义

- **背景**：在实际应用中，视觉语言模型（VLM）会反复面对相同视觉内容的不同问题（如多轮对话、文档问答、RAG、Agent 循环等）。每轮重新编码视觉前缀（prefill）的开销昂贵，因此启用 KV 缓存复用是降低推理成本的关键路径。
- **核心问题**：当视觉内容在“改变后的查询前缀”下重现时，精确前缀复用失效，因为缓存的视觉 K/V 在因果上下文中已经“陈旧”。选择性重计算（只刷新少量视觉 token）虽可恢复质量，但**关键在于选择哪些 token 刷新**，而非刷新数量本身。
- **已有方法的失效模式**：
  - 原始注意力分数高的 token 未必对残差流有大的写入贡献（高注意力 ≠ 大值范数写入），容易浪费预算；
  - 多图像提示中，注意力在混合视觉前缀上归一化，可能将预算分配给与当前查询无关但视觉显著的分心图像。
- **整体含义**：论文主张将“缓存复用 + 有预算刷新”统一为一种**残差流恢复**问题：哪些陈旧视觉状态最可能扰动当前查询下的共享残差通道，就优先修复这些 token。这一视角同时统一了单图像与多图像的重用策略。

## 2. 提出的方法论

- **核心思想**：基于残差流视角，把选择性重计算视为“恢复残差通道中最可能被陈旧视觉写入破坏的部分”。区分两个被原始注意力混淆的量：
  - 查询对 token 的**读取强度**（cached-key query attention）；
  - 该 token 潜在的**写入规模**（pre-output cached value norm）。
- **关键技术与公式**：
  - 局部一阶残差模型：刷新集合 T 后，残留误差近似为被保留下来的陈旧 token 写入位移的加权和：
    `Δh_q(T) ≈ Σ_{t∉T} α^c_{q,t}(Ṽ*_t − Ṽ^c_t)`
  - 经对角近似，得到不可直接计算的“oracle”排序分数：`o_t = ᾱ_t‖ξ_t‖`，其中 ᾱ_t 是 RMS 聚合的缓存键注意力，ξ_t 是陈旧位移。
  - 由于 ξ_t 不可观测，CONDUIT 用**可访问的输出前缓存值范数 `‖V^c_t‖` 作为写入规模代理**，得到 token 级吞吐分数：
    `s_t = (1/|L|) Σ_ℓ ( (1/|Q|H) Σ_{q,h} α^c_{q,t,ℓ,h} ) · ‖V^{c,(ℓ)}_t‖`
    （实际实现平均所有层、所有查询位置和注意力头）
  - **图像级相关度放大**：对每张图计算其平均缓存键注意力 g_j，并定义放大系数：
    `c_j = (1−λ) + λ·(g_j / ḡ)`，默认 λ=1。
  - **复合选择分数**：`ŝ_t = s_t · c_{π(t)}`，然后用**一次全局 Top-k** 选出要重计算的视觉 token 集。
- **单图像退化**：当 K=1 时，g_j=ḡ，系数 c_j=1，方法自然退化为纯粹的单图像内 token 级选择——无需单独的启发式。
- **无需训练、保持架构**：仅一次查询条件得分前向，不引入可学习参数，不改变模型权重或结构。缓存值范数可在缓存构建时预计算，避免在线读取值张量。

- 在 r=0.10 的刷新预算下，CONDUIT 在三个骨干的五数据集上达到**全预填充平均质量的 97.0%–99.5%**，领先所有预算受限方法约 1.7 分（平均优于 ProphetKV）。
- 零刷新缓存复用相比全预填充平均损失 8.1 分，而 CONDUIT 平均仅损失 1.0 分。
- 在 r=0.05 预算下，CONDUIT 在 15 个数据集-骨干单元中仍排名第一 13 次。
- 在 K=1 单图像场景，CONDUIT 退化为图像内吞吐量选择，5% 刷新即接近全预填充。
- 延迟方面：在 MMLongBench-Doc 延迟子集上，CONDUIT 用约 13.5% 的全预填充 FLOPs，取得 2.99× TTFT 加速（0.519s→0.174s，平均 3 骨干和 4k/8k/16k）。16k 下得分/延迟等与 ProphetKV 接近但得分更高 1.20 分。

- 诊断实验表明缓存值范数排名跨上下文具有高稳定性（Spearman 0.99+），查询注意力这一相对排序与投影误差高度相关（0.79–0.89），支撑了选择规则的有效性。

## 7. 优点

- **统一性很强**：将单图像复用归约为多图像统一的残差流恢复框架的特殊情况（K=1 极限），避免了维护两套方法。
- **理论动机明确**：从一阶残差误差出发，将“读取强度”与“写入规模”解耦，建立平方根对角风险排序代理，并证明全局 Top-k 对该代理是最优的。
- **无需训练、零架构改动**：实际只需一个查询条件得分前向，工程集成成本低，保持模型权重和结构不变。
- **可操作性良好**：缓存值范数是 query-independent 的，可在缓存构建时以每 token 每层一个标量存储，避免在线读取值张量；打分流程线性于视觉 token 数量，图像级步骤为 O(K)。
- **实验控制严谨**：统一缓存物化协议、固定默认超参数、多随机种子报告、与多个 SOTA 缓存复用方法在同一环境下公平对比。
- **诊断丰富**：除端到端指标外，还提供了代理排名相关性、缓存范数稳定性、token 重叠、跨图像重加权、证据页预算等分析，增强方法可解释性。

## 8. 不足与局限

- **场景覆盖有限**：仅评估静态图像和文档的 shifted-prefix 复用；视频、流式观测、长期 Agent 工作流等动态场景未实验。论文也在 Limitations 中承认并指出需要额外机制。
- **单图像场景收益空间小**：K=1 时零刷新已经接近全预填充，CONDUIT 在该场景增益有限，实验中的分数提升不显著。
- **延迟测量不够全面**：使用纳米级 vllm 派生引擎，batch size=1，不覆盖连续批处理的生产服务器；TTFT 只算在线路径，未算缓存构建时间（虽然论文明确排除了该成本）。
- **缓存值范数只是启发式代理**：选择器未显式建模 key/query 状态引起的注意力漂移项（∆α），在某些上下文下存在不可预测的误差（论文通过失败审计承认约 4/23 案例与此有关）。
- **存储成本未消除**：方法只降低重复预填充算力，仍保留视觉 K/V 的存储开销；当可复用视觉前缀相对周围文本较短时收益较小。
- **主观成分存在**：图像级放大系数 λ 是经验设定（默认 1），虽做了敏感性分析，且无逐数据集调整，但理论上缺少更严格的最优性证明；
- **部分诊断使用较小样本**：例如失败审计仅 23 个样本，代理排名诊断基于 64 个提示等，统计功效有限。
