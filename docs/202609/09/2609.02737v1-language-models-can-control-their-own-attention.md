## 摘要
语言模型将大部分注意力集中在上下文的很小一部分上，然而它们读取整个KV缓存以找到少数关键标记。如果用户在100万token的对话中询问之前的细节，全局注意力层必须扫描整个上下文才能生成回复的每个token。一种常见方法通过轻量级代理分数预先选择相关标记来降低此成本，但这种外部评分仍然每步产生O(N)的复杂度。我们采取一种内在方法，源于一个简单的问题：模型本身是否已经知道上下文的哪些部分是相关的？为此，我们引入了声明式注意力（DA），这是一种协议，引导模型在其思维链中声明需要关注的位置，将生成过程划分为三种模式：<global>（完整上下文）、<focus>（特定区域）和<local>（仅最近输出）。推理引擎像解析工具调用一样解析这些声明，并跳过大部分KV缓存读取。在15个长上下文任务的零样本评估中，DA在现成模型（Gemma-4-31B、Qwen-3.6-27B）上显著减少了解码期间的总关注token数量（分别减少52.0%和31.1%），同时精度仅适度下降（1.27个百分点和2.75个百分点），且下降幅度随模型规模增大而减小。DA开辟了稀疏注意力的新维度，在基于训练的方法下具有进一步潜力，未来工作可以探索。

## Abstract
Language models spend most of their attention on a small fraction of context, yet they read the entire KV cache to find the few tokens that matter. If the user asks about a previous detail in a 1M-token conversation, global attention layers must scan the full context to generate each token of the reply. A prominent approach mitigates this cost by pre-selecting relevant tokens via lightweight proxy scores, but this extrinsic scoring still incurs O(N) per step. We take an intrinsic approach motivated by the simple question: wouldn't the model already know which parts of the context are relevant? To this end, we introduce Declarative Attention (DA), a protocol that elicits the model to declare where it needs to attend within its chain-of-thought, partitioning generation into three modes: <global> (full context), <focus> (a specific region), and <local> (recent output only). The inference engine parses these declarations like tool calls and skips most of the KV cache read. Under zero-shot evaluation across 15 long-context tasks, DA on off-the-shelf models (Gemma-4-31B, Qwen-3.6-27B) significantly reduces total attended tokens during decoding (52.0%, 31.1%) with modest accuracy drops (1.27pp, 2.75pp) that shrink with model scale. DA unlocks a new axis of sparse attention, with further potential under training-based methods that future work can explore.

## 1. 论文的核心问题与整体含义

- **研究背景**：
  - 长上下文解码的核心瓶颈在于 KV cache 读取：即便模型真实的注意力只集中在一小部分 token 上，每个解码时刻都必须扫描整个 KV cache 以定位相关 token，导致每步 O(N) 的显存读取开销。
  - 在 1M-token 上下文中，KV cache 的读取带宽需求可比肩模型激活参数的加载成本。
- **现有方案及其局限**：
  - 基于静态启发式（如 recency、注意力集中度）的剪枝：无法预测未来的 query 需要哪些 token，长上下文性能退化。
  - 基于轻量级扫描的 query-aware 方法（如 Quest、DeepSeek Sparse Attention）：每步仍需扫描整个上下文的代理索引，复杂度依然是 O(N)，只是常数变小；其中很多方法还依赖训练。
- **核心研究问题**：既然模型自己可能"知道"哪些上下文是相关的，能否让模型**主动声明、自由控制自己的注意力范围**，以此消除每步 O(N) 的选择成本？
- **整体含义**：论文主张把注意力选择从"模型内部激活中推断出的隐性模式"变为"模型用可读文本明确说明的显式协议"，为长上下文推理提供了一条可解释、与架构正交的新维度。

## 2. 方法论：Declarative Attention（DA）

- **核心思想**：让模型在思维链（chain-of-thought）中输出可解析的标签，声明当前推理步骤所关注的上下文范围；推理引擎像解析工具调用一样处理这些标签，动态构造注意力掩码，只让模型声明的 KV 块可见。
- **三种注意力模式**：
  1. **\<global\>（全局模式）**：关注全部上下文块（magic chunks）；用于浏览全文、定位下一个要聚焦的区域。
  2. **\<focus magic_chunks="K"\>（聚焦模式）**：只关注指定的一个/多个上下文块；用于从特定区域中抽取逐字信息。
  3. **\<local\>（局部模式）**：不关注任何上下文块，只关注问题、指令和模型已生成的回复；用于整合已抽取内容并推理。
- **上下文组织形式**：
  - 将长上下文分割为约 2K-token 的可寻址片段，称为 "magic chunks"，分割边界优先落在语义自然边界上（段落 → 句子 → 从句 → 词）。
  - 片段以**模拟工具调用记录（tool-use transcript）**的形式呈现，借助模型在后训练阶段熟悉的消息边界来提升片段追踪能力——不需要实际执行任何工具。
- **解码时干预**：
  - DA 状态机监听输出流，在解析到开标签时切换模式，在闭标签时回到默认的全局模式。
  - 掩码按 vLLM 的 KV 块粒度对齐（block-aligned），保证不丢弃任何被声明的 token，同时可与 FlashAttention 等现有内核直接兼容。
  - 实现方式为修改 vLLM 的 attention metadata builder 中的 block table，无需改动内核或调度器。
- **适用范围与开销**：只作用于全局注意力层；滑动窗口注意力与线性注意力层不受影响。协议会**增加解码步数**，但**降低每步的注意力成本**，净收益取决于部署场景。

## 6. 主要结论与发现

- **成本显著下降**：在主模型上，Gemma-4-31B 解码期间每响应的平均 attended tokens 减少 **52.0%**；Qwen-3.6-27B 减少 **31.1%**，多数效率来自注意力掩码而非生成更短文本。
- **准确率只轻微损失**：Gemma-4-31B 平均下降 **1.27 pp**（87.01→85.74%）；Qwen-3.6-27B 下降 **2.75 pp**（85.31→82.56%）。
- **掩码是效率来源**：相对同提示的 DA-no-mask 消融，DA 将 attended tokens 削减 71.1%（Gemma）和 46.5%（Qwen），而分块提示本身几乎是无损的。
- **强模型更好用**：相对准确率随骨干模型增大单调提高（Gemma 族从 29% 到 99% 的 vanilla 保持率；Qwen 族从 64% 到 97%）。
- **节省随上下文长度增加而增长**：短上下文中 DA 比 vanilla 少约 1M tokens，在最长 bin 中少约 21M tokens。
- **理论墙钟加速**：在 B200 上、roofline 估算，DA 可将解码墙钟时间降至 vanilla 的 **0.71×（Gemma-4-31B）**与 **0.77×（Qwen-3.6-27B）**。
- **模式分布**：约 73% 的生成 token 落在便宜的 focus/local 模式，单 token 注意力最多可节省 76–99%；global 模式虽只占少数 token，但贡献了超过 80% 的实际注意力使用。

## 7. 优点与亮点

- **零样本、免训练即可工作**：一条提示在同一套分割协议下可通用到 15 种任务与两个模型家族，无需参数更新，因此结果可作为未来训练方法的"下限"。
- **省略了选择器开销**：注意力选择由模型输出流中读取，无需显式代理索引扫描，解析 focus 标签是 O(1)。
- **可解释/可读性**：模型声明其注意力计划，且这些声明是真实控制注意力掩码的 token；既可用于效率优化，也可用于模型审计或可监督性。
- **与现有系统集成成本低**：掩码只是 block table 修改，不改变内核，兼容 FlashAttention，并可自然与投机解码、KV offloading 和检索增强等正交技术叠加。
- **积极且诚实的消融设计**：将提示格式效应与掩码效应清晰分离。
- **全局与局部代价的清晰建模**：兼顾了混合架构中 SWA/GDN 等局部机制的固定开销，分析严谨。
- **明确讨论失败案例**：识别了证据被切割破坏、输出规模随文档增长两类系统性问题，并提出修复方向。

## 8. 不足与局限

- **准确率仍需付出代价**：Qwen 上 2.75pp 的下降不可以忽略，多片段任务下降更大（3.59pp 类别平均）。
- **并非全部任务有效**：存在 6 个失败案例源（如大规模统计计数、结构化表格分割、逐段生成型任务），只靠零样本协议无法解决。论文将其归因于"分割对语义结构的破坏"与"长输出在全注意力下生成"，其中一部分可由 map-reduce 之类的模式简单修复，另一部分则要求训练。
- **生成 token 变多**：DAC / DA_no-mask 两者的解码步数都膨胀了 15–35%，在注意力较低的场景下会导致非零开销。在一些 Qwen 任务里，addressed tokens 甚至超过 vanilla。
- **目前只支持非 thinking 模式**：把模型放到 thinking traces 里会破坏协议执行；未来如果需要将注意力节省扩展到长推理 traces，则需要更新协议的呈现方式。
- **"全局模式"的导航成本**：在零样本提示下，global 模式在超长上下文里占比可升至约 55%（Qwen），这正是真正的 O(N) 步骤，因此边际收益有限。
- **合成分段非自然**：固定长文评测天然是人为分割的；agentic（多工具/多轮对话）场景可能是最自然的应用，但文中尚无真实 agentic 评测。
- **缺乏训练型基准对比**：未与经过专门稀疏注意力训练的后训练模型的端到端表现作对比，这也意味着零样本协议的收益上限仍不清楚。
- **效率分析是理论估算**：用的是 roofline 模拟而非实际测量端到端延迟；块对齐 32-token 粒度在 Kernel 读取量上的额外损失没有显式建模。
