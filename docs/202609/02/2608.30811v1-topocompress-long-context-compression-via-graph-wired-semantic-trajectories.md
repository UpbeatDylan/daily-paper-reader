## 摘要
长上下文压缩对于降低大型语言模型推理的成本和延迟至关重要。然而，现有方法可能割裂重要证据，需要额外的训练或对齐，并且其有效压缩往往依赖于目标模型。我们提出了TopoCompress，一种无需训练且模型无关的框架，通过选择连贯的语义片段来压缩长上下文。TopoCompress首先使用稠密和词汇级查询相关性以及语义加速度对每个片段进行评分。然后，它构建一个基于语义相似性和顺序邻接性连接片段的混合图，并在图上传播查询引导的相关性分数。在五个长上下文任务——HotpotQA、2WikiMQA、MuSiQue、Qasper和MultiFieldQA-en——中，TopoCompress始终优于强压缩基线。值得注意的是，TopoCompress在压缩预算小4倍的情况下实现了与最强基线相当的性能，并且压缩时间比最快基线快1.41倍。

## Abstract
Long-context compression is essential for reducing the cost and latency of large language model inference. However, existing methods can fragment important evidence, require additional training or alignment, and often depend on the target model for effective compression. We introduce TopoCompress, a training-free and model-agnostic framework that compresses long contexts by selecting coherent semantic spans. TopoCompress first scores each span using dense and lexical query relevance together with semantic acceleration. It then constructs a hybrid graph that connects spans based on semantic similarity and sequential adjacency, and propagates the query-guided relevance scores over the graph. Across five long-context tasks-HotpotQA, 2WikiMQA, MuSiQue, Qasper, and MultiFieldQA-en-TopoCompress consistently outperforms strong compression baselines. Notably, TopoCompress achieves performance comparable to the strongest baseline while using a 4x smaller compression budget, and provides a 1.41x smaller compression time over the fastest baseline.

### 1. 核心问题与整体含义（研究动机与背景）
长上下文是当前大模型（LLM）推理面临的核心矛盾：一方面更长的上下文有助于解决复杂推理任务，另一方面内存开销大、推理成本高，且上下文过长时模型对“中段证据”的关注度显著下降。论文指出，现有上下文压缩方法：

- 多采用token级剪枝（如LLMLingua、LongLLMLingua），容易将实体、短语或句法单位截断，导致关键证据被破坏；
- 依赖额外的压缩器模型（小型语言模型MS）进行困惑度评分，与目标模型之间存在分布偏差；
- 多数方法需额外指令微调或数据蒸馏，使压缩器与特定目标模型深度绑定，无法实现免训练、模型无关的部署；
- 只对token独立打分，忽略了证据间的关联性——这在多跳问答中尤其致命，因为许多中间线索单独看与问题相关性低，却是证据链的必经环节。

因此，论文提出一个关键转变：**应把“上下文压缩”重新表述为“图上的证据选择与相关度传播”问题**，而非“token级剪枝”问题；由此引入**TopoCompress**——一个训练免费、模型无关的压缩框架。其整体含义在于：通过分段化的结构化表征，在保留信息完整性的同时兼顾压缩质量和速度，为长上下文推理压缩提供了一条不需要训练与模型对齐的新范式。

### 2. 方法论：核心思想、关键技术细节与算法流程
**TopoCompress** 的处理流程可分为五个核心环节：

- **语义跨度（Semantic Span）构建**  
  将长上下文按句子或自然段落拆分为连续语义单元u_i（而非按token切分），避免语言边界被切断。

- **稠密+词法双重查询相关性评分**  
  采用冻结编码器bge-m3（M3-Embedding）获得稠密向量e_i和词法权重w。  
  - 稠密相关度 r_i = max(0, cos(e_i, e_q))；  
  - 词法相关度 ℓ_i = Σ w^q_t·w^{u_i}_t 匹配查询与片段间共同token的权重积；  
  - 合并得到查询对齐分 g_i = μ·r̂_i + (1−μ)·ℓ̂_i。

- **语义加速度（Semantic Acceleration）**  
  对同一文档内每个内部跨度计算二阶差分：a_i = 2e_i − e_{i−1} − e_{i+1}，得到变化剧烈程度κ_i，再乘以查询对齐分形成初始分数 s_i = (1 + λκ̂_i)·g_i——只强化“本身相关且处于语义转折点”的片段。

- **混合图构建与相关度传播**  
  以每个Span为节点，构造两类边：
  - 语义边（embedding近邻，基于稠密相似度）；
  - 序贯边（同一文档内相邻片段）；
  - 合并为 W = αW_sem + βW_seq，经度矩阵行归一后得转移矩阵P；
  - 执行个性化PageRank式传播：s^{(m+1)} = (1−η)s + ηPᵀs^{(m)}，直至收敛。
  
  这一设计的关键动机是：某个Span即便与查询直接相关性不高，只要它与高相关节点在语义或上下文上相连，就能通过传播获得较高分数，从而“恢复中间证据”并串联完整证据链。

- **冗余感知贪心选择（Redundancy-Aware Selection）**  
  在选择阶段，TopoCompress引入去重惩罚项：不单纯按传播分排序，而是在每一步选择传播分扣减与已选节点最高相似度的结果，避免重复信息填入受限预算。同时，选出的Span最终按原文档顺序重排，保持语言与推理连贯性。

论文同时提供了一种 **控制器变体（Controller-guided variant）**：压缩进行一半时，用LLM判断现有证据是否已经充分，若不足则生成一个中间追问子问题作为新的查询来重新指导选择，最多调用两次控制器，以控制API开销。

### 7. 方法优点
- **“免训练、免对齐、模型无关”的定位**：直接绕过上游压缩模型与目标模型之间需要蒸馏/微调对齐的痛点，适配未知或闭源模型时更加容易部署；
- **保留证据链的结构性设计**：分层为“片段→图→传播→冗余厌恶选择”，方法论叙事完整，说服力较强；
- **融入多源信号**：稠密+词法+加速度+图结构将语义的直接匹配、精确匹配和上下文过渡性质很好地融合，是一种理念清晰的组合学习到其组合不要求训练的优点；
- **追求非冗余信息的全局筛选**：在预算严重受限时，多数贪心算法只会堆积单点得分最高的信息，TopoCompress以相似惩罚避免信息重复，对高信噪比下的预算利用率更好；
- **工程性强**：压缩时间明显更短，对当前RAG-LLM管道是实用、可落地的改进；
- **实验充分**：跨3个模型、5类任务、三种预算、4条基线和多个消融，验证了泛化性与鲁棒性。

### 8. 不足与局限
- **任务覆盖面偏窄**：所有评估均集中于LongBench的QA类任务，若任务变为“根据文档做摘要、推理、生成结构化抽取”等，证据连通性与图传播的效用未必仍一样突出，尚未见可推广的零样本评测证据；
- **长文本结构依赖**：方法核心是把文档分割为Span并依赖段落间的相似性与顺序性构图；在对话流、混合模态数据或非规范文本（例如日志、程序源码混排）上的稳健性未验证；
- **缺少真正的“上下文窗口硬极值”验证**：LongBench各任务平均输入长度在3619–11214词之间，未触及真正的“百万级 token”高长上下文场景；
