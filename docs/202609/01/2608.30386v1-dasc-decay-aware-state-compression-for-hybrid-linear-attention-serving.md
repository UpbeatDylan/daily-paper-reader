## 摘要
混合线性注意力架构最近已扩展到大型开放权重模型，在显著减少键/值（KV）缓存增长的同时，提供与全注意力相当的质量。然而，它们的原地循环状态更新使缓存管理复杂化：前缀重用需要状态检查点与全注意力KV并存，而完整存储状态检查点会增加内存压力，导致更多驱逐和重复预填充。通过分析Gated DeltaNet (GDN)和Kimi Delta Attention (KDA)的衰减结构，我们发现不同的头和通道在不同的时间尺度上保留前缀信息，我们称之为“保留视界”。这种差异表明持久状态检查点中具有显著的压缩潜力。基于这一观察，我们引入了“衰减感知状态压缩”（DASC），它从模型权重中推断保留视界，选择长视界状态单元，并将它们打包成不规则的状态检查点布局。为了高效集成到张量并行推理引擎中，DASC进一步在TP秩之间平衡压缩后的状态检查点。在重用时，DASC要么对省略的单元进行零填充，要么以额外的计算成本从有界后缀中刷新它们。在Kimi-Linear上的检索和端到端推理基准测试中，保守的DASC配置保持接近完整缓存，同时将KDA循环状态检查点压缩了2.63倍。在固定的状态检查点内存预算下，由此产生的容量增益将平均首令牌时间（TTFT）降低了42.6%，并将输入吞吐量提高了68.4%。在较大的压缩比下，后缀刷新恢复了大量因更激进省略而损失的准确性，但代价是额外的重放计算。带有GDN的Qwen表现出类似的质量-效率趋势，表明DASC从逐通道的KDA扩展到逐头的GDN。

## Abstract
Hybrid linear-attention architectures have recently scaled to large open-weight models, offering quality competitive with full attention while substantially reducing key/value (KV) cache growth. However, their in-place recurrent-state updates complicate cache management: prefix reuse requires state checkpoints alongside full-attention KV, while storing state checkpoints in full increases memory pressure, leading to more evictions and repeated prefill. By analyzing the decay structure of Gated DeltaNet (GDN) and Kimi Delta Attention (KDA), we find that different heads and channels retain prefix information over markedly different timescales, which we term \emph{retention horizons}. This variation suggests substantial compression potential in persistent state checkpoints. Building on this observation, we introduce \emph{Decay-Aware State Compression} (DASC), which derives retention horizons from model weights, selects long-horizon state units, and packs them into a ragged state checkpoint layout. To integrate efficiently with tensor-parallel inference engines, DASC furtherly balances compressed state checkpoints across TP ranks. On reuse, DASC either zero-fills omitted units or refreshes them from a bounded suffix with additional compute cost. Across retrieval and end-to-end reasoning benchmarks on Kimi-Linear, conservative DASC configurations remain close to full caching while compressing KDA recurrent state checkpoints by $2.63\times$. Under fixed state checkpoint memory budgets, the resulting capacity gains reduce mean Time to First Token (TTFT) by 42.6\% and improve input throughput by 68.4\%. At larger compression ratio, suffix refresh recovers much of the accuracy lost to more aggressive omission, at the cost of additional replay computation. Qwen with GDN exhibits a similar quality--efficiency trend, showing that DASC extends from channel-wise KDA to head-wise GDN.

## 一、论文的核心问题与整体含义

### 研究背景
- 混合线性注意力架构（如 Qwen3.8、Kimi K3 等万/千亿参数模型）已在显著减少 KV 缓存增长的同时提供接近全注意力的模型质量。
- 这类架构在**全注意力层之间交错插入线性注意力层**，后者以固定大小的循环状态（recurrent state）总结前缀信息。
- 循环状态是**原地更新**的，不能像全注意力 KV 那样保留任意前缀边界，因此前缀缓存必须额外存储**定期的状态检查点（state checkpoint）**。

### 核心问题
1. **状态检查点占用显存过大**：每个检查点包含所有线性注意力层的大规模状态矩阵，频繁检查点会耗尽 HBM。
2. **稀疏检查点导致重计算**：减少检查点频率会增加前缀命中后的重放（replay）或重复预填充（prefill）成本。
3. **关键矛盾**：在状态检查点上，哪些状态单元必须保留、哪些可以省略？此前缺乏系统性的答案。

### 关键发现
- 通过分析 Gated DeltaNet（GDN）和 Kimi Delta Attention（KDA）的衰减结构，发现**不同头/通道以显著不同的时间尺度（保留视界，retention horizon）保留前缀信息**。
- 该差异可仅从模型权重导出，无需输入数据，为构建**输入无关**的静态压缩策略提供了依据。

### 整体思路（DASC）
- 从模型权重推导保留视界 → 选择长视界单元保留、短视界单元省略 → 将保留单元打包为不规则状态检查点 → 跨张量并行（TP）秩平衡 → 前缀命中时零填充或后缀刷新恢复省略单元。

## 二、方法论：核心思想、关键技术细节

### 2.1 核心思想
- **保留视界（Retention Horizon）**：一个状态单元将信息保留"多久"（多少 token 后衰减到阈值以下），由模型权重直接导出，输入无关。
- **选择与压缩**：保留长视界单元（global），省略短视界单元（local），据此构建静态选择掩码，离线生成一次，复用所有检查点。
- **两种恢复策略**：
  - **DASC-NR（默认）**：省略单元直接零填充，不增加计算。
  - **DASC-WR**：在缓存命中时，从有界后缀重放计算以刷新省略单元，换取精度恢复，代价是额外计算。

### 2.2 关键技术细节

**1. 衰减公式与静态保留视界**

KDA 的循环状态更新公式：

$$S_t = S_{t-1}\,\mathrm{Diag}(\alpha_t)\left(I - \beta_t k_t k_t^\top\right) + \beta_t v_t k_t^\top$$

GDN 的 log-decay 参数化：

$$g = -\exp(A_{\log})\,\mathrm{softplus}(a + d_t^{bias})$$

静态保留视界定义为衰减因子降至 \\(\epsilon\\) 所需 token 数：

$$H_s = \frac{\ln \epsilon}{g}$$

实验中取 \\(\epsilon = 10^{-3}\\)，输入门控 logit 固定为 \\(a=-0.3\\)（故意偏保守，多保留单元）。

**2. 选择粒度**
- **GDN**：按 **head** 选择（每个 head 一个衰减值）。
- **KDA**：按 **(head, channel)** 选择（每个 key 通道一个衰减值），比 head 级粒度细得多。
- 阈值：\\(H_s(u) > W_{max}\\) 则保留为 global，否则省略为 local。

**3. 存储格式**
- **Padded 布局**：所有层按最大保留数分配，简单但浪费（KDA 层间不均衡时浪费严重）。
- **Ragged 布局**（DASC 采用）：每层只分配自身保留单元数，层间紧凑拼接，压缩率更高。
- 压缩比公式：
  - 时间状态：\\(C_{rag}^{temp} = \frac{\sum_l n_l}{\sum_l r_l}\\)
  - 完整检查点：\\(C_{rag}^{ckpt} = \frac{B_{dense}^{temp}+B_{conv}}{B_{rag}^{temp}+B_{conv}}\\)

**4. TP 均衡放置**
- 选择后的状态在各 TP 秩之间可能极不均衡，最重秩决定可驻留检查点数。
- 两阶段均衡：
  1. **模型加载时**：置换线性注意力 head 包以均衡计算分布（精确重索引，无额外通信）。
  2. **检查点存储时**：将整个 TP 组视为共享存储池，通过 variable-split all-to-all 重新分配打包状态单元，通信仅在 STORE/LOAD 时发生。

**5. 后缀刷新窗口**
- 对每个省略单元，窗口取 \\(W_u = \mathrm{clamp}(\mathrm{next\_pow2}(H_s(u)), 4, W_{max})\\)。
- 全局重放窗口 \\(W_{replay} = \max_u W_u\\)，是有界的（不超过 \\(W_{max}\\)）。

## 六、主要结论与发现

### 核心结论
1. **循环状态检查点存在大量可压缩冗余**：在单键检索任务上，移除全部循环状态检查点对精度影响 ≤1 个百分点，而移除全注意力 KV 则完全失败。
2. **保留视界是有效的选择信号**：权重导出的静态视界与观测经验视界的 Spearman 中位相关达 0.801（GDN）和 0.856（KDA），与状态/读出幅值的相关也显著为正。
3. **保守配置下质量几乎无损**：Wmax=16 时 RULER 聚合分数与 dense 差距 ≤0.01；端到端任务差距 ≤1.3 个百分点。
4. **巨大压缩收益**：KDA 在 TP 均衡下实现 2.63×（Wmax=16）至 28.04×（Wmax=512）状态检查点压缩；GDN 因 head 级粒度较粗，为 1.10–2.48×。
5. **服务性能显著提升**：KDA 在匹配 HBM 下平均 TTFT 降低 42.6%（568→326 ms），输入吞吐提升 68.4%（33.25→55.98k tokens/s）；GDN 趋势类似。
6. **后缀刷新可恢复精度**：Wmax=128 时 DASC-WR 比 DASC-NR 提升 0.8–7.4 个百分点；Wmax=512 时仍比 dense 低 0.31 点但保留 25.4% TTFT 优势。
7. **DASC 与量化正交**：Wmax=16 选择 + INT8 存储可达 8.11× 容量，精度与 dense 基本持平。
8. **TP 均衡带来显著额外收益**：KDA 压缩比从不均衡的 2.22× 提升至 2.63×（Wmax=16）。

## 七、优点

### 方法论亮点
1. **输入无关的静态选择信号**：直接从模型权重推导保留视界，无需校准数据或在线 profiling，工程上极实用。
2. **粒度匹配架构**：KDA 按 channel、GDN 按 head 选择，与衰减参数化粒度精确对齐。
3. **Ragged 存储设计**：避免 padded 布局的"最宽层决定所有层"浪费，并在层间不均衡时获得大幅额外压缩。
4. **两阶段 TP 均衡**：既消除最重秩瓶颈，又保持计算局部性（通信仅限 STORE/LOAD），是实际系统落地的关键工程贡献。
5. **NR/WR 策略解耦**：默认零填充零开销，可选后缀刷新换取精度，给系统提供灵活的操作点。
6. **正交组合**：与 INT8 量化叠加进一步压缩，说明方法不替代而是补充已有手段。

### 实验设计亮点
1. **缓存干预实验**：通过零化不同缓存组件清晰分离"KV 缓存"与"循环状态检查点"各自的贡献。
2. **严格 warm/replay 协议**：固定槽位数、控制驱逐、保证命中率下限、逐问题配对，统计严谨。
3. **Random 对照**：相同压缩率下比较选择策略，有效证明收益来自衰减感知而非单纯容量增加。
4. **跨工作负载 trade-off 分析**：将重放精度与匹配 HBM TTFT 配对展示（Figure 3i），给出实用的系统操作指南。

## 八、不足与局限

### 覆盖范围局限
1. **仅覆盖混合线性注意力架构**：未验证纯线性注意力（如 Mamba 类）或状态空间模型的可迁移性——这些模型中不存在并行的全注意力 KV 作为"安全网"，省略循环状态单元的风险可能更高。
2. **TP 度仅测试 8**：更大 TP 度（如 16/32）下的通信开销、均衡性变化未验证。
3. **仅测试两个模型**：KDA 一个、GDN 一个，结论的外部有效性有待更多架构验证。

### 偏差风险
1. **静态视界是启发式**：与活性度量（状态幅值、读出贡献）相关仅为中等（0.4–0.6），选择并非最优重要性排序，存在次优风险。
2. **静态视界依赖 \\(a=-0.3\\) 这个人工设定**：不同模型/后续训练可能需重新调参。
3. **省略单元在简单任务上冗余，在复杂任务上重要**：论文在简单单键检索上发现大量冗余，但多键、聚合、推理任务上压缩损失显著更大（如 KDA 在 Wmax=1024 时 MK1 从 1.00 降至 0.82），表明压缩机会具有明显的**任务依赖性**，通用安全压缩比难以预先确定。

### 应用限制
1. **DASC-WR 有额外计算成本**：固定槽位实验中 Wmax=512 时每次命中刷新成本高达 ~483 ms，吞吐敏感场景需谨慎选择。
2. **KDA 的 113 列不可分 head 会导致 TP 均衡无法完全消除远程所有权**，Wmax=512 时 all-to-all 通信与长后缀刷新部分抵消容量收益。
3. **GDN 的 head 级粒度收益有限**（最多 2.48× 压缩），论文也承认需要更细粒度的压缩机制。
4. **未考虑 decode 阶段吞吐与延迟**：TTFT/输入吞吐之外的服务质量指标（如 TPOT、端到端生成延迟）未评估。
