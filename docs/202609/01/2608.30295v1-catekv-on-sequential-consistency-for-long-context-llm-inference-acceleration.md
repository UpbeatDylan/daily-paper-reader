## 摘要
大型语言模型（LLMs）在处理长上下文任务方面表现出了强大的能力，但由于大量的内存需求和推理延迟，处理如此长的上下文仍然具有挑战性。在这项工作中，我们发现某些注意力头在其注意力模式中表现出序列一致性，这可以通过基于变异系数的算法持续识别。受这一观察的启发，我们提出了CateKV，一种混合KV缓存方法，它为一致性头仅保留关键令牌信息，从而减少KV缓存大小和计算开销，同时为自适应头保留大部分KV对以确保高精度。我们展示了我们算法的独特特性及其与现有加速方法的扩展。在长上下文基准上的全面评估表明，在保持与全注意力相当的准确性的同时，CateKV最多可将内存使用量降低至原来的1/2.72，解码速度提升至原来的2.18倍，并可在批处理场景中将吞吐量提升至原来的3.96倍。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长上下文 LLM 推理面临巨大的显存开销和推理延迟问题。主流自回归 LLM 需要存储并检索完整的 Key-Value（KV）缓存，随着上下文长度从 1K 扩展到 1M tokens，KV 缓存所需内存呈线性增长，推理延迟显著上升（例如 Llama-3-8B 在上下文从 1K 扩展到 1M 时，延迟增加超 3000 倍）。因此，如何在保持生成质量的前提下减少 KV 缓存内存占用、加速解码过程是亟待解决的关键问题。
- **现有方案及其局限**：
  - **KV 驱逐（Eviction）方法**（如 StreamingLLM、SnapKV、PyramidKV）：系统性丢弃部分 KV 对以减少内存，但容易丢失关键信息，造成明显精度下降。
  - **KV 检索（Retrieval）方法**（如 Quest、ShadowKV）：保留完整缓存并动态检索关键 token，避免信息丢失，但无法缓解高内存占用问题，限制批处理规模。
  - **逐头分类方法**（如 DuoAttention、RazorAttention）：根据检索头/流式头等模式对注意力头分类，但这些方法仅关注单一阶段的头部特征，未充分利用预填充（pre-filling）阶段的经验来指导解码阶段。
- **本文的核心洞见**：作者发现**某些注意力头的注意力模式在预填充和解码阶段之间呈现“序列一致性”（sequential consistency）**，即这些头始终聚焦于固定的一组关键 token；而另一些头则呈现动态、广泛的注意力分布（自适应头）。基于这一观察，可以利用预填充阶段观测到的关键 token 来指导解码阶段的 KV 缓存压缩。

## 2. 论文提出的方法论

### 2.1 核心思想
- **CateKV 是一种混合 KV 缓存方法**，通过将注意力头划分为两类来差异化地管理缓存：
  - **一致性头（Consistent Heads）**：注意力模式在预填充与解码阶段序列一致，只需保留少量关键 token 的 KV 对（约 1.56% 的 KV 对），即可维持其注意力功能。
  - **自适应头（Adaptive Heads）**：注意力分布动态变化，需要保留大部分 KV 对（按保留比例 η）以保证语义信息的完整获取。
- 在预填充阶段通过观察窗口识别关键 token 和头部类型，在解码阶段据此执行差异化缓存策略，兼顾精度与效率。

### 2.2 技术细节

#### 观察矩阵构造
- 在预填充阶段设置大小为 L_obs 的观察窗口（取输入末尾若干 query token），并暂时排除初始 token（L_init）和最近 token（L_rec），得到观察矩阵：
  ```
  A = softmax(Q[-L_obs:] · K[L_init:-L_rec]^T / √d)
  ```
  其中 A ∈ R^(L_obs × (n − L_rec − L_init))，反映观察窗口内各 query 对前序上下文中各 token 的注意力分布。

#### 变异系数（CV）评分
- 为衡量注意力的一致性与集中程度，先对观察矩阵 A 进行**二值化**：
  ```
  B = I(A ≥ Quantile_k(A) × α)
  ```
- 然后计算频率向量 C，统计每个 token 在 L_obs 个 query 下被标记为关键 token 的次数：
  ```
  C = Σ_i B_i ∈ R^(n − L_rec − L_init)
  ```
- 基于 C 计算变异系数得分：
  ```
  score = √( (1/m) Σ_i (C_i − μ(C))² ) / μ(C)
  ```
  一致性头的得分较高（频率向量集中、变异大 = 注意力高度聚焦于少数 token），自适应头得分较低。

#### 头部类型判定
- 在每个 sample 下得到所有层的得分矩阵 S ∈ R^(l×h)，通过阈值 Γ(r)（r 为自适应头比例）将头划分为一致头与自适应头。
- **关键发现：头部类型可静态确定**——同一头在不同输入样本上呈现高度一致的模式，可通过参考数据集统计每个头被识别为一致头的频率，从而确定模型级别的固定头类型，避免每次推理动态识别带来的开销。

#### 缓存与解码策略（见 Algorithm 1）
- **一致性头**：将频率向量分块（chunk size=8），取块最大值的 top-b 作为索引，仅缓存这些关键 KV 对（稀疏预算如 2048）。
- **自适应头**：类似地按保留比例 η（如 1.0）保留大多数 KV 对，并支持与检索式方法（如 Quest、ShadowKV）无缝集成，通过 query-aware 检索进一步精简计算。
- **GQA 模型**：观察矩阵取同组各头 A 的平均值。

#### 理论分析
- 论文给出了基于 Rademacher 复杂度的泛化界（Lemma 1）和 token 保留精度的下界（Theorem 1），指出影响最坏情况保留精度的三个关键因素：**打分排序的有效性（λ）**、**保留预算的动态控制**、以及 **CV 分类的精度（P_head）**。
