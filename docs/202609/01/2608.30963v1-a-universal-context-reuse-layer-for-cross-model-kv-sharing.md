## 摘要
现代大语言模型（LLM）服务系统日益运行在重复或共享的上下文之上，然而即便另一个模型已经处理过相同的输入，每个模型通常仍会执行自己的预填充计算。现有的KV缓存复用机制在单一模型内大幅减少了冗余计算，但通常假设缓存的生产者和消费者是同一模型。我们研究跨模型KV共享，即将源模型产生的KV状态转换为可由不同目标模型（包括在规模、架构、注意力配置、分词器及模型家族上存在差异的模型）消费的表示。我们在家族内和跨家族两种设置下评估了该方法。对于Qwen2.5-7B→Qwen2.5-1.5B，经翻译的KV状态将LongBench2准确率从27.59%提升至34.48%，相比原生1.5B基线提升了6.89个百分点，同时相比原生目标预填充降低了交接成本。对于跨家族的Qwen2.5-1.5B→Gemma-2-2B设置，KV交接在4K上下文长度下将目标端预填充成本最多降低67.05%，同时解码困惑度保持接近原生模型基线。在更具异质性的Llama3.1-70B→Qwen2.5-7B设置中，跨家族交接实现了44.0%的准确率，而原生Qwen2.5-7B推理为45.7%，同时将实测延迟从899ms降低至138ms。这些结果提供了初步证据，表明KV状态可充当可迁移的计算表示，而非严格局限于模型自身的缓存，并促使上下文移动性成为一种系统抽象，用于减少异构LLM及多智能体推理工作流中的冗余预填充。

## Abstract
Modern large language model (LLM) serving systems increasingly operate over repeated or shared context, yet each model typically performs its own prefill computation even when another model has already processed the same input. Existing KV-cache reuse mechanisms substantially reduce redundant computation within a single model, but generally assume that the producer and consumer of a cache are identical. We study \emph{cross-model KV sharing}, which translates the KV state produced by a source model into a representation that can be consumed by a different target model, including models that differ in scale, architecture, attention configuration, tokenizer, and model family. We evaluate the approach in both within-family and cross-family settings. For Qwen2.5-7B $\rightarrow$ Qwen2.5-1.5B, translated KV states improve LongBench2 accuracy from 27.59\% to 34.48\%, a gain of 6.89 percentage points over the native 1.5B baseline, while reducing handoff cost relative to native target prefill. For the cross-family Qwen2.5-1.5B $\rightarrow$ Gemma-2-2B setting, KV handoff reduces target-side prefill cost by up to 67.05\% at 4K context length while maintaining decoding perplexity close to native-model baselines. In a more heterogeneous Llama3.1-70B $\rightarrow$ Qwen2.5-7B setting, cross-family handoff achieves 44.0\% accuracy compared with 45.7\% for native Qwen2.5-7B inference, while reducing measured latency from 899ms to 138ms. These results provide initial evidence that KV states can serve as transferable computational representations rather than strictly model-local caches, and motivate \emph{context mobility} as a systems abstraction for reducing redundant prefill across heterogeneous LLM and multi-agent inference workflows.

## 1. 核心问题与整体含义（研究动机和背景）

- 现代 LLM 服务系统越来越多地运行在重复或共享的上下文上（如多模型路由、级联系统、多智能体协作），但不同模型处理相同输入时通常各自独立执行 prefill，产生大量冗余计算。
- 现有 KV 缓存复用技术（如 prefix caching、CacheBlend、KVCOMM 等）主要假设缓存的生产者和消费者是同一模型，或仅适用于高度架构对齐的模型变体，无法在模型规模、架构、注意力配置、分词器、模型家族不同的情况下直接复用。
- 本文提出 **跨模型 KV 共享（Cross-Model KV Sharing）**，研究如何将源模型产生的 KV 状态翻译为目标模型可消费的表示，从而避免目标模型重复执行完整 prefill。
- 核心系统原则：**如果多个模型操作相同上下文，理解该上下文所用的计算工作不应由每个模型独立重复执行**。论文将 KV 状态视为可迁移的计算表示（而非严格模型本地缓存），并引入“上下文移动性”（context mobility）作为系统抽象，旨在促进异构 LLM 和多智能体推理工作流的效率提升。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：通过一个“通用上下文复用层”将源模型 KV 状态转换为目标模型可用的 KV 状态。形式化表示为：
  \[
  \widehat{KV}_B(C) = T_{A \to B}\left(KV_A(C)\right)
  \]
  其中 \(T_{A\to B}\) 是从源模型表示空间到目标模型表示空间的变换。
- **翻译目标**：
  - 学习目标是最小化翻译状态与目标模型原生 prefill 状态之间的距离：
    \[
    L_{KV} = D\left(T_\theta(KV_A(C)), \; KV_B(C)\right)
    \]
  - 但作者指出，原始 KV 距离并非唯一甚至最重要的目标；更应关注下游任务行为（如输出 logits、注意力模式、任务准确率），因为翻译状态不必精确复现原生 KV，只需提供足够的上下文信息以支持目标模型继续推理。
- **翻译机制**：可以跨单个层、层组、KV 头、共享中间表示、压缩 KV 表示或低维潜在适配器进行操作；需要在翻译保真度、运行时开销、内存占用和可扩展性之间取得平衡。
- **交接协议**：
  1. 源模型对提示完成 prefill，生成原生 KV 缓存。
  2. 学习到的传输模块将缓存映射到目标模型的 KV 表示空间。
  3. 冻结的目标模型直接基于翻译后的状态进行解码，不再独立 prefill 完整提示。
- **效率条件**：当 \(C_{trans} + C_{overhead} < C_{prefill}\) 且翻译状态满足质量要求时，跨模型复用是有利的；否则可回退到原生 prefill。

## 6. 主要结论与发现

- **家族内：Qwen2.5-7B → Qwen2.5-1.5B**
  - 翻译 KV 状态使 1.5B 目标准确率从 27.59% 提升至 34.48%（+6.89 个百分点），恢复了 1.5B 与 7B 原生推理之间准确率差距的 38.1%。

  - 交接延迟仅 34.5ms（8K–16K）和 53.8ms（16K–32K），相比 1.5B 原生 prefill 降低 4.6× 和 5.4×，相对 7B prefill 降低 14.5× 和 16.7×。

- **跨家族（相近规模）：Qwen2.5-1.5B → Gemma-2-2B**
  - 延迟降低随提示长度增加：128 令牌降低 45.25%，1K 降低 59.90%，4K 降低 67.04%。

- **跨家族（大-小）：Llama3.1-70B → Qwen2.5-7B**
  - 交接准确率 44.0%，与 Llama3.1-70B 原生准确率持平，仅比 Qwen2.5-7B 原生准确率 45.7% 低 1.7 个百分点（保留 96.3% 的目标原生准确率）。
  - 交接延迟 138ms，相比 Qwen2.5-7B 原生 prefill（899ms）快 6.5×，相比 Llama3.1-70B 原生 prefill（7,328ms）快 53.1×。

- **方法通用**：不对源/目标模型的架构、规模、分词器做强假设，支持家族内和跨家族场景，形式化框架清晰。
- **实验结果具有说服力**：

- **可能的风险与偏差**：
  - 翻译模块对训练提示分布可能过拟合，在不同任务类型或领域上泛化性未知。
  - 跨模型 KV 翻译可能导致翻译后状态携带源模型的系统性偏差，进而影响目标模型输出质量，论文未讨论这种“偏差迁移”问题。
  - 长上下文下准确率下降，说明当前翻译机制在长距离依赖上的建模能力有限。

> **总体评价**：论文提出了一个具有前瞻性和工程价值的概念——“跨模型 KV 共享/上下文移动性”，并给出了初步可行的实现方案和实验证据。但作为一篇前沿研究，其实验范围、资源透明度和与现有方法的对比仍有待加强。未来工作需要在更大规模、更多样化的架构与任务上验证方法的泛化能力，并对翻译层训练成本和系统集成开销进行更细致的剖析。
