## 摘要
长上下文推理的瓶颈在于键值（KV）缓存的内存占用，尤其是在资源预算紧张的小型模型上。现有的KV缓存驱逐方法使用模型的注意力分布对词元进行评分，或在无注意力变体中使用每个键与全局参考点的距离。通过受控的留一探针，我们发现注意力大小与词元对答案的因果贡献无关（Spearman ρ=-0.004），这对主流驱逐方法的前提提出了挑战。我们引入TwinKV，一种无需训练、无需注意力的冗余信号，用于检测词元的键在上下文其他位置是否存在近重复。TwinKV并非取代现有策略，而是作为一种可组合的修复通道：给定策略的固定保留集，它识别出没有留存重复的已驱逐词元（称为“孤儿”）以及信息在其他位置重复的保留词元（称为“冗余供体”），然后交换它们，同时保留原始预算和评分规则。我们将TwinKV与四种最近的驱逐策略组合，在LongBench、LooGLE、RULER以及一个短上下文MMLU-Pro无伤害对照上，以0.3、0.5、0.7的压缩比进行了评估。在Qwen3-4B上，TwinKV对两种策略的大多数配置都有改进，对第三种策略接近持平，而对第四种已接近性能上限的自适应基线仅对少数配置有帮助；在三种未达上限的策略中，最宽松比率下的增益最小。然而，在Llama-3.2-1B的RULER上，第四种策略在每个评估单元中都有改进，因为其Alone得分还有很大的提升空间。更广泛地说，与Qwen3-4B相比，Llama-3.2-1B在LongBench上的平均增益较小，但在LongBench和LooGLE上改进单元的比例更高，并在RULER上取得了明确的胜利。我们还发现，少样本分类示例是一种任务结构，TwinKV在两种模型上均无帮助。

## Abstract
Long-context inference is bottlenecked by the memory footprint of the key-value (KV) cache, especially for small models under tight resource budgets. Existing KV cache eviction methods score tokens using the model's attention distribution or, in attention-free variants, each key's distance from a global reference point. Using a controlled leave-one-out probe, we find that attention magnitude is unrelated to a token's causal contribution to the answer (Spearman $ρ=-0.004$), challenging the premise behind dominant eviction methods. We introduce TwinKV, a training-free, attention-free redundancy signal that detects whether a token's key has a near-duplicate elsewhere in context. Rather than replacing existing policies, TwinKV acts as a composable repair pass: given a policy's fixed retained set, it identifies evicted tokens with no surviving duplicate (\emph{orphans}) and retained tokens whose information is duplicated elsewhere (\emph{redundant donors}), then swaps them while preserving the original budget and scoring rule. We compose TwinKV with four recent eviction policies across LongBench, LooGLE, RULER, and a short-context MMLU-Pro no-harm control at compression ratios ${0.3,0.5,0.7}$. On Qwen3-4B, TwinKV improves a majority of configurations for two policies, is near-even for a third, and helps only a minority for a fourth adaptive baseline already near a performance ceiling; gains across the three non-ceiling policies are smallest at the loosest ratio. On RULER with Llama-3.2-1B, however, that fourth policy improves in every evaluated cell because its Alone score leaves substantial room to improve. More broadly, Llama-3.2-1B shows a smaller average LongBench gain but a higher fraction of improved cells on LongBench and LooGLE than Qwen3-4B, plus a clean RULER win. We also identify few-shot classification exemplars as a task structure where TwinKV does not help on either model.

## 2. 方法论

### 2.1 核心思想
TwinKV 基于一个结构性直觉：**一个token的信息能否在驱逐后仍然存活，取决于上下文中是否存在其等价副本**。被重复、改写或呼应多次的事实可以失去一个副本而无损；只出现一次的事实一旦被驱逐便永久丢失。这一准则不依赖模型的注意力信号，而是纯粹从上下文的内容结构出发。

### 2.2 冗余打分（核心公式）
- 对每个注意力头，设键向量矩阵为 K，归一化后计算成对余弦相似度矩阵：

  **sim(i, j) = k̂ᵢᵀ k̂ⱼ**

- token j 是 token i 的"孪生"，当且仅当 sim(i,j) > τ 且 |i−j| > w（局部窗口w=32排除相邻token的平滑语义漂移）。
- 冗余计数：

  **rᵢ = Σⱼ 1[sim(i,j) > τ]，其中 |i−j| > w**

- 最终得分取负归一化冗余数：

  **sᵢ = −rᵢ / n**

  得分越高代表越不冗余，越应保留。
- 两个固定保护区始终保留：前导 sink tokens（默认4个）和后置 recent window（默认64个）。

### 2.3 可组合修复机制
给定任意现有策略的保留集 S₀，TwinKV 定义：
- **孤儿 token**：被驱逐（i ∉ S₀）且 bᵢ(S₀) < τ——即保留集中没有其等价副本，信息真正丢失。
- **冗余供体 token**：被保留（j ∈ S₀，非保护区）且 bⱼ(S₀) ≥ τ——即已有重复占据其他槽位，保留它是浪费。
- 按严重程度排序（孤儿按 bᵢ 升序，供体按 bⱼ 降序），交换 m = min(|孤儿|, |供体|) 对最严重者。修复后集合满足 **|S₁| = |S₀| = K**（预算精确不变），且包装策略自身的评分规则完全不受影响。

### 2.4 位置编码适应性
对于采用非均匀逐维旋转调度的架构（如 LongRoPE），原始后RoPE键相似度会混杂内容冗余与位置相关的旋转项。论文推导出旋转不变形式的替代信号，可证明地对任意旋转调度不变。

### 2.5 复杂度
计算相似度矩阵为 O(n²d)（每头每层），与模型自身注意力计算的复杂度同阶，是额外的prefill开销。论文承认这是真实成本，并指出修复专用实现可将复杂度降至 O(nKd)。

## 6. 主要结论与发现

1. **注意力与因果贡献无关**：留一探针显示注意力大小与token的真实边际效用统计不相关（ρ = −0.004），挑战注意力驱动驱逐方法的理论前提。

2. **修复通道在多数配置上有效**：在 Qwen3-4B 上，组成修复通道后：
   - StreamingLLM：LongBench上每个压缩比均有改善（最高 +5.27 @ 0.3），最多64%单元有效；
   - PyramidKV：57%单元有效，RULER上增益巨大（平均 +21.86）；
   - SnapKV：41%单元接近持平；
   - ExpectedAttention：仅16%单元有效，因已近性能上限。

3. **模型依赖性强**：Llama-3.2-1B 在 LongBench 上平均增益较小（+0.17 vs +0.46），但正单元比例更高（54.4% vs 41.7%）；在RULER上，ExpectedAttention在所有9个单元均获改进（平均 +4.66），形成跨模型族的干净反转。

4. **趋势**：三个未达上限策略的平均改进在最宽松压缩比（0.3）时最小；注意力驱动的策略在预算趋紧时退化最快，结构差距的修复价值随之增大。

5. **TREC 失败模式**：少样本分类示例（TREC）上所有策略严重退化（如 ExpectedAttention 64.50→23.00），原因是模板回声产生假孪生——这是质量问题（错误的正向配对）而非数量问题。诊断扫描表明，加宽局部窗口（w=64-128）和提高阈值可将负交互转为正（StreamingLLM 从 −23.3 转为 +1.7）。

6. **MMLU-Pro 无伤害检查不成立**：ExpectedAttention 在所有比率上均有损失，短上下文、低冗余场景中修复通道的收益空间有限。

## 7. 优点

- **训练无关、注意力无关**：不需要任何训练、模型内部信号或任务相关的校准，仅从上下文键向量本身计算，便于部署。
- **可组合性设计新意足**：不同于一般"另一个独立策略"的定位，将信号设计为修复通道，保持原始预算和评分规则不变，可插拔地增强任何现有策略，避免链式压缩的预算乘积效应。
- **结构信号的理论动机清晰**：从"信息是否可恢复"的视角定义驱逐性，跳出了对模型内部注意力分布的依赖，基于内容本身的冗余结构。
- **实验透明度高**：如实报告失败场景（TREC、ExpectedAttention负收益），给出全部实际得分（而非只报增量），对阈值/窗口的机制解释有定向诊断支撑。
- **架构自适应性**：为 LongRoPE 等非均匀旋转调度提供了旋转不变的替代形式，增强了跨架构适用性。
- **高效的理论保证**：修复通道保持预算精确不变（|S₁|=|S₀|），且已有策略的评分规则不被触碰，具有清晰的组合语义。

## 8. 不足与局限

- **TREC失败暴露真实缺陷**：在少样本分类模板结构上有系统性负收益——这是少数有明确机制诊断的失败案例，说明孪生检测会把模板回声误认为信息冗余，无法区分语义重复与模板相似。虽然窗口/阈值调整可修复，但论文不做逐任务调整，这意味着该方法对某些特定任务结构（如密集样板文本、few-shot exemplars）可能没有增益甚至有害。
- **复杂度负担**：O(n²d) 的相似度矩阵计算是真正的额外prefill开销，且修复通道实现得比必要成本更重（在完整矩阵上取最大值而非只计算对保留集的相似度）；论文虽提出了 O(nKd) 的改进方向，但未实现和验证。
- **期望效果的临界条件尚不清晰**：ExpectedAttention在Qwen上是负收益、在Llama上是正收益，说明方法收益高度依赖包装策略已离上限的"余量"，但论文没有提供定量预测该余量大小的准则或先验。
- **短上下文和宽松压缩比场景收益有限**：MMLU-Pro上几乎每个基线都有损失；0.3 压缩比（最宽松）时平均改进最小，说明在少冗余、低压缩时可利用的结构差距不足，修复通道的适用域不清晰。
- **跨模型需重校准**：τ 需要针对不同模型手动重校准（Qwen3 0.85、Llama-3.2 0.90），论文声称是文档化的单次重校准而非逐任务调整，但本质上依赖对底层键分布的知识。
- **实验细节不完整**：未提及 GPU 规格、运行时间、能耗等资源细节；RULER 使用 5% dev-slice 降低了统计功效；未在更大模型（如 8B-70B）或 MoE 架构上验证，外部效度有限。
