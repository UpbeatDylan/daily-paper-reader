## 摘要
使用强化学习训练长上下文 LLM 策略时，需要在更新后的策略下重新评估成组的采样响应，这是一种更新阶段的注意力工作负载，与预训练显著不同：每个组共享一个长提示，并扇出为多个响应分支。标准上下文并行（CP）将每个提示—响应对展平为线性序列，因此相同的提示键值（KV）状态会在每个响应分支上被重新计算——或在网络中反复轮转。我们提出 AugTree，一种围绕该回放阶段构建的 CP 执行方案。AugTree 将回放分为两个阶段：提示预填充阶段，计算一次共享的提示 KV 状态；响应回放阶段，在一组有界的回放通道上调度独立的响应分支。回放阶段实例化两种通信语义，由轻量级在线规划器在 GPU 调度前枚举 CP 度、调度方案和放置方案来选择：当响应占主导时，在响应本地通道内轮转 KV 分片；当提示占主导时，将响应查询移动到固定的提示 KV 持有者，并进行部分 softmax 归约。共享提示状态保持完全可微——响应损失会反向传播到其中，累积的提示梯度沿原始预填充图传播——因此 AugTree 保持精确的训练语义，而不是执行分离的、推理式 KV 缓存。在四个真实后训练工作负载和最多 64 个加速器上，AugTree 相比动态 CP 将平均训练阶段步长时间加速 1.18×（最高 2.23×），相比带提示复用的 Megatron ring CP 基线加速 2.63×，相比不带复用的基线加速 7.08×。

## Abstract
Training long-context LLM policies with RL requires re-evaluating groups of sampled responses under the updated policy, an update-stage attention workload that differs sharply from pre-training: each group shares one long prompt that fans out into multiple response branches. Standard context parallelism (CP) flattens each prompt--response pair into a linear sequence, so the same prompt key--value (KV) states are recomputed---or repeatedly rotated through the network---once per response branch. We present \textbf{AugTree}, a CP execution scheme built around this replay stage. AugTree separates the replay into two phases: a prompt-prefill phase that computes the shared prompt KV state once, and a response-replay phase that schedules the independent response branches over a bounded set of replay lanes. The replay phase instantiates two communication semantics, chosen by a lightweight online planner that enumerates CP degrees, schedules, and placements before GPU dispatch: rotating KV shards within response-local lanes when responses dominate, and moving response queries to stationary prompt-KV owners with a partial-softmax reduction when prompts dominate. The shared prompt state remains fully differentiable---response losses backpropagate into it and the accumulated prompt gradients propagate through the original prefill graph---so AugTree preserves exact training semantics rather than performing detached, inference-style KV caching. On four real post-training workloads and up to 64 accelerators, AugTree improves average training-stage step time by 1.18$\times$ over dynamic CP (up to 2.23$\times$), 2.63$\times$ over a Megatron ring CP baseline with prompt reuse, and 7.08$\times$ over the baseline without reuse.
