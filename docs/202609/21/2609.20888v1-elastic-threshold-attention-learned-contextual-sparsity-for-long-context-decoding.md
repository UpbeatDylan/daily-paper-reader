## 摘要
大规模 KV 缓存会在长上下文解码期间造成严重的内存带宽瓶颈。稀疏注意力方法通过选择性加载来缓解这一问题，但这会带来代价：僵化的启发式规则会丢弃必要的上下文，导致质量下降。我们提出 \textbf{弹性阈值注意力（Elastic Threshold Attention, ETA）}，这是一种端到端可训练架构，能在不牺牲稠密模型质量的情况下实现硬件加速的解码速度。ETA 直接从查询表示中预测动态的、上下文相关的阈值，使模型能够将类稠密上下文分配给困难的检索或推理步骤，同时剪除常规 token。为了在不发生表示坍缩的情况下从头学习这一策略，ETA 在训练期间 \emph{以乘法方式抑制}低于阈值的 logits 使其趋近于零，而不是将其删除。针对这种平滑的均匀注意力下限进行训练，提供了一个分布式概率库，\textbf{使初始 token 上的局部注意力汇消失}。它还使模型能够在推理时硬剪枝无信息量的 KV 块，并吸收由粗粒度 GPU 块选择一并纳入的偶然 token。因此，一个 1.45B 的预训练 ETA 模型在语言建模、常识推理和长上下文针检索任务上，在 $\approx 85\%$ 的训练稀疏度和 $\approx 38\%$ 的活跃解码密度下，可与稠密注意力相媲美。在推理时，我们在 Triton 中实现了一个自定义解码内核，它使用缓存的几何-概率边界以 $O(1)$ 时间筛选 KV 块，在长度达 512K token 的序列上，相较于 FlashAttention-2 带来最高 $2.5\times$ 的墙钟解码加速。最后，我们面向特定领域部署提出了一种离线校准算法，该算法冻结每个注意力头的常量阈值以消除预测器开销，从而额外减少 $27\%$ 的注意力计算量。

## Abstract
Massive KV caches can cause severe memory-bandwidth bottlenecks during long-context decoding. Sparse attention methods mitigate this via selective loading, but that comes at a cost: rigid heuristics drop necessary context, leading to quality degradation. We introduce \textbf{Elastic Threshold Attention (ETA)}, an end-to-end trainable architecture that achieves hardware-accelerated decoding speed without sacrificing dense model quality. ETA predicts dynamic, contextual thresholds directly from query representations, allowing the model to allocate dense-like context to difficult retrieval or reasoning steps while pruning routine tokens. To learn this policy from scratch without representation collapse, ETA \emph{multiplicatively suppresses} sub-threshold logits toward zero during training rather than deleting them. Training against this smooth uniform attention floor provides a distributed probability reservoir that \textbf{causes localized attention sinks on initial tokens to disappear}. It also enables the model to hard-prune uninformative KV blocks at inference time and absorb incidental tokens co-admitted by coarse GPU block selection. As a result, a 1.45B pretrained ETA model rivals dense attention across language modeling, commonsense reasoning, and long-context needle retrieval at $\approx 85\%$ training sparsity and $\approx 38\%$ active decode density. At inference time, we implement a custom decode kernel in Triton that screens KV blocks in $O(1)$ time using cached geometric-probabilistic bounds, delivering up to $2.5\times$ wall-clock decode speedups over FlashAttention-2 on sequences up to 512K tokens. Finally, we introduce an offline calibration algorithm for domain-specific deployments that freezes per-head constant thresholds to eliminate predictor overhead, cutting attention compute by an additional $27\%$.

## 1. 核心问题与研究动机

- **背景瓶颈**：长上下文自回归解码是严格的**内存带宽受限**操作——每生成一个 token 都需将整个 KV Cache 从 HBM 搬到片上 SRAM，序列越长、batch 越大，带宽越饱和，服务吞吐与成本严重受限。Prefill 是计算受限（Θ(T²d) FLOPs），Decode 是访存受限。
- **现有方法的取舍困境**：
  - **后验启发式剪枝/固定窗口**（H2O、StreamingLLM、SWA、BigBird）：与训练解耦、输入无关的固定 token 预算。当查询需要广域综合或长程检索时，固定预算"饿死"注意力头，造成严重推理退化与检索崩溃。
  - **可训练稀疏架构**（NSA、SeerAttention）：需要多分支路由或训练期硬 top-k 剪枝，架构改动大、调参复杂；更关键的是训练时把未选中的 logits 直接置为 −∞，导致学到的注意力分布脆弱，且 GPU 块级过度纳入（over-inclusion）会不可预测地改变 softmax 分母。
- **整体含义**：论文主张应把"稀疏决策"变成**模型自己学出来的、随查询动态变化的策略**，并且用"抑制"而非"删除"来处理被剪掉的 token，从而同时拿到**稠密质量 + 硬件加速**。

## 2. 方法论

### 2.1 核心思想
- ETA 是一个**端到端可训练的稀疏注意力**：每层加一个线性投影（参数开销 < 0.1%），把 post-RoPE 的查询表示映射为**逐头动态标量阈值** τ，让每个 token 按自身语义难度决定注意力预算。
- 关键创新：训练时对低于阈值的 logits 做**乘法抑制**（而非加性硬删除至 −∞），在尾部形成**均匀注意力下限（uniform attention floor）**。

### 2.2 关键技术细节
- **阈值预测**：τ_t = q̄_t W_τ + b_τ，其中 q̄_t 为该层所有头 post-RoPE 查询的拼接（保留旋转位置信息，且让层内各头协同分配预算）。
- **Start-dense 初始化**：W_τ = 0，b_τ = −8.0，训练初期 100% key 通过掩码，实现稠密→稀疏的平滑过渡。
- **可微掩码与尾部抑制**：包含概率 m = σ(β·(S − τ))，温度 β 从 1.0 线性退火到 5.0；被掩码后的分数为 S ⊙ m，即把子阈值正分往下拉、负分往上抬，向 0 收缩（双侧收缩）。因 exp(0)=1，所有被抑制 key 收敛到相同未归一化权重，形成平坦尾部（归一化尾部熵从 0.790 升到 0.916，max/mean 权重比从 15.6 降到 2.03）。
- **稀疏正则**：L_sparsity = λ · mean(m)，对 τ 提供直接梯度；λ 采用三阶段调度（750 步为 0 → 线性升至 5e-4 → 降到 2.5e-5 保持）。
- **训练核**：自定义融合 Triton kernel，将打分、阈值评估、乘法门控、online softmax、正则归约全部在 SRAM 完成，不物化 T×T 矩阵；FLOPs、HBM 占用、I/O 复杂度与 FlashAttention-2 完全一致（O(T²d)、O(Td)、O(T²d²M⁻¹)）。
- **推理块稀疏流程**：
  - KV Cache 按块（b）划分，缓存**对偶概率-几何块索引**：块质心 μ_B、逐坐标方差 σ²_B、最大范数 M_B。
  - 对偶筛选分数 = min(⟨q, μ_B⟩ + z·σ_S(q,B), ‖q‖·M_B)/√d_h，用 Cantelli 单边不等式 + Cauchy-Schwarz 几何上界，**O(1) 时间**判定块是否显著；低于有效阈值 τ̃ = τ − a 的块跳过 HBM 读取。
  - **GQA-aware 分组执行**：以 KV 头为单位加载组内并集块，单次 HBM 传输服务组内多个查询头。
  - **Top-1 Rescue**：若激进阈值把 chunk 0 所有块剪光，无条件加载得分最高块，保证数值稳定。
  - 分块 + 两阶段 online-softmax 归约，提高 SM 占用率。
- **离线校准（面向固定领域部署）**：构建 1/t 加权的分数直方图，用二分法为每个头求解与训练密度匹配的**静态常量阈值 c_ℓh**，消除预测器开销。

## 6. 主要结论与发现

- **质量平价**：1.45B ETA 在 ≈85% 训练稀疏度、≈38% 活跃解码密度下，PPL 与稠密注意力基本持平（FineWeb 14.83 vs 14.70；C4 18.99 vs 18.96；WikiText-2 27.77 vs 26.89），显著优于同密度启发式方法。
- **推理不降反升**：ARC-Easy 44.5% vs 44.0%，HellaSwag 40.0% vs 36.0%，存在"注意力去噪"效应。
- **长上下文检索**：L=8192 时稠密模型检索崩溃（0.0%），ETA 保留 22.2%，并能**动态把活跃密度从 30.1% 扩展到 69.3%**；H2O/StreamingLLM/SWA 在 L>2048 后全部归零。
- **注意力汇消失**：初始 token 上的概率质量从稠密模型的 >50% 降到 <2%，不再需要显式"钉住" sink token。
- **自主层特化**：Layer 0 保留 ≈96% 密度做广域聚合，Layer 7 压缩到 <8%，深层回升至 35–48%。
- **墙钟加速**：16.0% union 密度下 B≥64 时稳定取得 2.01–2.36×，粗块（b=128）最高 2.50×；但 51.2% union 档位在 B=32 时反而慢 0.72–0.81×。
- **校准收益**：静态阈值在分布内 PPL 略优（91.60 vs 91.96）且密度更低（22.4% vs 24.14%）；在长度外推时抑制密度膨胀（44.77% → 32.83%），**额外省 27% 注意力计算且无 PPL 损失**。
- **机制解释**：乘法掩码把尾部变成均匀概率库，硬剪块只是均匀缩放 softmax 分母，不改变显著 key 的相对次序（log-odds 不变性 + 残差流 Scos=0.9691、logits 余弦 0.9959、top-1 一致 80.29%）。

## 7. 优点

- **方法极简且可插拔**：单层单线性投影（<0.1% 参数），保留单分支标准 Transformer 执行路径，不需要 NSA 式的多分支重构。
- **"抑制而非删除"的机制洞察深刻**：用乘法收缩构造均匀注意力下限，一举解决三个问题——训练稳定性、注意力汇、以及推理期块级过度纳入的鲁棒性；并给出了 log-odds 不变性与尾部熵的量化证据。
- **算法-硬件协同设计扎实**：O(1) 对偶概率-几何筛选、GQA 组并集加载（实测 union 仅膨胀 1.49× 而非 3×，保住 49.23% I/O 节省）、Top-1 Rescue、分块两阶段归约、1.6% 元数据开销。
- **消融体系完整且诚实**：不仅做了正向验证，还系统对比了加性 vs 乘法、动态 vs 静态、不同块粒度在"固定 per-head 密度"与"固定 HBM union 带宽"两种口径下的差异（揭示 b=64 在同带宽下反而多给每头 +9.5% 上下文、PPL 改善 8.8 点）。
- **可解释性分析加分**：R² 探针证明 67.3% 阈值方差无法被表面统计量解释，ANOVA 显示 70% 方差来自文档内部，说明是细粒度 token 级预算调制而非文档级开关。
