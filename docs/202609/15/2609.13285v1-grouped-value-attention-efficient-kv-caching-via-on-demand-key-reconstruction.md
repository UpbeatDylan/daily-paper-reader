## 摘要
KV 缓存是 Transformer 解码的主要瓶颈：其内存占用和缓存读取流量随序列长度增长。分组查询注意力（GQA）通过共享键值头降低了这一成本，但仍需在每一步存储键和值。我们提出分组值注意力（GVA），它存储分组值，并通过学习到的线性映射重建内容键。在推理时，该映射可被吸收到查询中，从而无需在预期的解码路径中具体化内容键。一个小的共享解耦 RoPE 通道通过单独缓存的位置键保留位置信息。对于所研究的配置，相对于匹配的 GQA，这种表示将持久缓存标量减少约 45-47%。在 3.5 亿参数规模、使用 300 亿个 FineWeb-Edu token 的情况下，16 维位置变体在五个任务上达到 44.18 的平均准确率，而 GQA 为 44.36，MLA 为 43.88。这些结果表明，在更紧凑的缓存表示下，基准准确率接近 GQA。为了将这种紧凑表示转化为更快的自回归推理，我们开发了定制解码内核，目前正在评估其端到端推理性能，并计划很快开源发布。

## Abstract
The KV cache is a primary bottleneck for Transformer decoding: its memory footprint and cache-read traffic grow with sequence length. Grouped-query attention (GQA) reduces this cost by sharing key-value heads, but still stores both a key and a value at every step. We introduce Grouped Value Attention (GVA), which stores grouped values and reconstructs content keys with a learned linear map. At inference, the map can be absorbed into the query, eliminating the need to materialize content keys in the intended decode path. A small shared decoupled RoPE channel retains positional information through a separately cached positional key. For the configurations studied, this representation reduces persistent cache scalars by approximately 45-47% relative to matched GQA. At the 350M-parameter scale with 30B FineWeb-Edu tokens, the 16-dimensional positional variant reaches 44.18 average accuracy across five tasks, compared with 44.36 for GQA and 43.88 for MLA. These results demonstrate near-GQA benchmark accuracy with a more compact cache representation. To translate this compact representation into faster autoregressive inference, we have developed custom decoding kernels and are currently evaluating their end-to-end inference performance with an open-source release planned soon.

# 《Grouped Value Attention: Efficient KV Caching via On-Demand Key Reconstruction》论文总结

## 1. 核心问题与研究动机

- **背景瓶颈**：自回归解码中 KV 缓存随上下文长度线性增长，成为长上下文服务的显存容量与带宽主导成本。每步解码需反复读取缓存，常受内存带宽限制。
- **已有方案的不足**：
  - **GQA** 通过跨 query 头共享键值头降低成本，但每步仍需同时写入 key 和 value 两条流，缓存为 `2·T·G·d_h`。
  - **MLA**（DeepSeek）将 key/value 压缩为联合低秩隐向量，缓存更小，但需额外投影、解码路径更复杂。
- **核心假设**：内容键可由值推导——二者编码同一底层内容信息，因此无需独立的内容键缓存。GVA 据此只持久化分组 value，按需重建 key。

## 2. 方法论

### 2.1 核心思想：Value-only 缓存 + 线性重建
- 基于 GQA 分组：H 个 query 头共享 G 个 value 头。
- 每个 query 头用一张映射 `M_h ∈ R^{d_h × d_n}` 从对应组值重建内容键：
  - `K_h = V_{g(h)} M_h`，`g(h)` 为 query 头 h 所属 value 组。
- **关键动机**：GQA 中同组内所有 query 头共享同一 key，GVA 通过每头独立的映射恢复 head-specific 的键多样性，且缓存流数仍为 G。

### 2.2 解码期吸收（Absorption）
- 因 `M_h` 推理时固定，内容键无需物化：
  - `q_h k_{j,h}^⊤ = q_h (v_{j,g(h)} M_h)^⊤ = (q_h M_h^⊤) v_{j,g(h)}^⊤ = q̃_h v_{j,g(h)}^⊤`
  - 其中 `q̃_h = q_h M_h^⊤` 每 token 只算一次；内容注意力直接读取 value 缓存，不生成临时键张量。该恒等式是精确的。

### 2.3 解耦 RoPE
- 标准 RoPE 使旋转依赖缓存位置，位于 `q_t` 与 `M^⊤` 之间，破坏吸收。
- 采用 DeepSeek MLA 式解耦策略：将 query/key 拆为
  - **未旋转内容切片**（宽 `d_n`）：`k_j,nope = v_{j,g(h)} M_h`
  - **旋转位置切片**（宽 `d_r`）：`k_j,rope = (x_j W_r) R_j^⊤`，跨头共享，仅需 `d_r` 标量/token
- 得分：`q k_j^⊤ = q_nope (k_j,nope)^⊤ + q_rope (k_j,rope)^⊤`，首项仍可吸收，次项用已旋转的共享位置键，无学习参数夹在两次旋转之间，相对位置得以保持。

### 2.4 缓存规模与初始化
- `N_GQA = 2T·G·d_h`；`N_GVA = T·G·d_h + T·d_r`；比值 `= 1/2 + d_r/(2G·d_h)`，对所用宽度约为 45–47% 节省。
- **尺度匹配初始化**：因 `K = V M` 是"投影的投影"，默认初始化使 K 的尺度远低于 Q，导致注意力接近均匀、早期训练浪费在纠正失配上。故令 `σ_M = σ_Q / (σ_V √d_in)`，使 K 初始 RMS 与 Q 匹配（可选配合 query RMSNorm）。
- **算法流程（Algorithm 1，单步解码）**：算 `q_t` 并拆分 → 算 `v_t` → 追加到分组 V 缓存 → 算并追加共享 `k_t^rope` → 对每个 query 头：旋转 q_rope、吸收得 `q̃_t,h`、算注意力分数、softmax 后加权求和。

## 6. 主要结论与发现

- **Shared KV（`K = V`）失败**：缓存恰好减半，但损失始终高于 GQA，单一向量无法同时承担打分与检索两种角色。
- **重建键 + 尺度匹配可接近 GQA**：scale-matched + Q-norm 达到 **44.41**，略高于 GQA 的 **44.36**；默认无 Q-norm 版为 43.77，仍接近 MLA 的 43.88。
- **解耦 RoPE 是推荐服务方案**：`d_r = 16` 时平均 **44.35**（仅低于 GQA 0.01 个百分点），`d_r = 24` 时为 44.29；作者视 `d_r = 16` 为更优工作点。
- **缓存收益**：相对匹配 GQA，解耦 RoPE 版持久缓存标量减少约 **47%（d_r=16）/ 45%（d_r=24）**；无位置切片时理想化为 50%。
- **尺度匹配主要改善早期损失**，而非稳定提升最终平均精度。
- **结论定性**：是"接近 GQA 质量 + 更紧凑缓存"，而非质量取胜；系统层面的加速/显存收益尚未验证。

## 7. 优点

- **思路新颖且简洁**：提出"值即持久内容状态、键按需重建"的表示范式，区别于 MLA 的联合隐向量压缩，保留了直接 value 路径，无额外 latent 投影。
- **数学上精确的吸收技巧**：`q̃_h = q_h M_h^⊤` 使内容键在解码路径中完全不物化，理论保证严格。
- **解耦 RoPE 设计巧妙**：仅用 `d_r` 个共享维度解决位置编码与吸收的冲突，代价极小。
- **恢复头间键多样性**：每头一张映射，在不增加缓存流数的前提下突破 GQA 组内键共享限制，且参数成本与序列长度无关。
- **学术诚实度高**：明确标注 Shared KV 为失败方案、反复强调"表示层计数≠实测显存节省"、承认未测系统性能与统计显著性。
- **与 GQA/MLA 的对比框架清晰**：用统一记号给出各方法缓存标量公式，便于横向理解。
