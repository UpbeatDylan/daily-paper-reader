## 摘要
Top-$K$稀疏注意力仅关注少量键值（KV）条目，从而降低了Softmax和值聚合的成本。然而，识别该子集仍需对当前查询与完整KV缓存进行评分，并执行全局Top-$K$选择，这使得选择器的成本随上下文长度线性增长，限制了稀疏注意力在长上下文解码中的实际效率。本文提出ReTopK，一种无需训练的方法，通过复用历史检索决策来加速动态Top-$K$注意力。ReTopK基于以下观察：相似查询往往关注重叠的支持集，且部分重叠的支持集仍能保留大部分精确Top-$K$注意力的质量。对于每个注意力头，它维护一个有界的查询-支持对历史缓存，为每个新查询检索最相似的缓存查询，将其存储的支持集与近期窗口合并，并仅使用精确的当前查询分数对生成的紧凑候选集进行重新排序。当复用不可靠时，基于相似性的回退机制会调用全历史精确Top-$K$，而定期的精确刷新则限制缓存漂移。ReTopK保留完整的KV缓存，仅复用选中的索引，而非历史分数、注意力权重或输出。在16K--128K上下文中，ReTopK在评估的近似方法中取得了最低的PG19困惑度以及最高的NIAH和LongBench分数。在128K且$K=512$时，ReTopK相比精确Top-$K$仅增加0.50\%的困惑度，同时将注意力计算加速了$3.07\times$。

## Abstract
Top-$K$ sparse attention reduces the cost of Softmax and value aggregation by attending to only a small subset of key--value (KV) entries. However, identifying this subset still requires scoring the current query against the full KV cache and performing global Top-$K$ selection, leaving selector cost linear in context length and limiting the practical efficiency of sparse attention for long-context decoding. In this paper, we introduce ReTopK, a training-free method that accelerates dynamic Top-$K$ attention by reusing historical retrieval decisions. ReTopK builds on the observation that similar queries often attend to overlapping supports and that partially overlapping supports can still preserve most of the Exact Top-$K$ attention mass. For each attention head, it maintains a bounded cache of historical query--support pairs, retrieves the most similar cached queries for each new query, unions their stored supports with a recent window, and reranks only the resulting compact candidate set using exact current-query scores. A similarity-based fallback invokes full-history Exact Top-$K$ when reuse is unreliable, while periodic exact refreshes limit cache drift. ReTopK retains the complete KV cache and reuses only selected indices, rather than historical scores, attention weights, or outputs. Across 16K--128K contexts, ReTopK achieves the lowest PG19 perplexity and the highest NIAH and LongBench scores among the evaluated approximate methods. At 128K with $K=512$, ReTopK incurs only a 0.50\% perplexity increase over Exact Top-$K$ while accelerating attention computation by $3.07\times$.

- 大型语言模型（LLM）在长上下文解码时，注意力计算成本随 KV cache 长度线性增长。
- 现有 Top-K 稀疏注意力虽然只对 K 个最高分键值做 Softmax 和值聚合，但**识别这 K 个条目仍需对完整 KV cache 做全量 QK 打分和全局 Top-K 选择**。
- 论文通过实验指出，精确 Top-K 注意力中“索引发现”成本占主导（在 128K 上下文时高达 95.6%），因此稀疏化注意力聚合本身不够，必须同时降低索引发现开销。
- 核心研究问题：**能否在不扫描完整历史 KV cache 的前提下，动态恢复查询特定的注意力支持集？**
- ReTopK 给出肯定回答：利用“相似查询往往具有重叠的 Top-K 支持集”这一观察，通过复用历史检索决策来避免每步全量搜索，同时保留完整 KV cache，兼顾效率与质量。

## 2. 方法论

- **核心思想：Recall-Before-Rerank（先召回，再重排序）**
  - 维护有界的历史查询-支持（query–support）缓存，不直接复用历史分数/权重/输出，只复用选中的索引。
  - 新查询到来时，先与缓存中少量历史查询比较相似度，召回最相似的 R 个查询及其支持集。
  - 将召回支持集与近期窗口取并集，构成紧凑候选集。
  - 仅对候选集使用当前查询的精确 QK 分数进行 Top-K 重排序，得到最终支持集。
  - 当缓存查询相似度不足时回退到精确全历史 Top-K；并定期执行精确刷新以避免缓存漂移。

- **关键公式**
  - 精确 Top-K 支持集：\( S_t = \text{TopK}_{i \in \{1,...,L_t\}} (q_t^\top k_i / \sqrt{d}, K) \)
  - 查询相似度：\( \rho_{t,c} = \bar{q}_t^\top \bar{q}_c \)，其中 \( \bar{q} \) 是归一化查询向量
  - 召回集：\( R_t = \text{TopR}_{c \in \{1,...,|B_t|\}} (\rho_{t,c}, R) \)
  - 候选集：\( A_t = \text{Unique}(\bigcup_{c \in R_t} \hat{S}_c \cup \mathcal{L}_t) \)，其中 \( \mathcal{L}_t \) 为最近 W 个 token 窗口
  - 重排序：\( \hat{S}_t = \text{TopK}_{i \in A_t} (\hat{e}_{t,i}, K) \)
  - 路径选择：
    - 定期刷新：每隔 \(T_r\) 步执行精确 Top-K；
    - 相似性回退：当最大缓存相似度 \( \rho_t^{\max} < \tau \) 时执行精确 Top-K；
    - 否则走复用路径。

- **复杂度优势**
  - 精确 Top-K 选择器代价为 \(O(L_t d)\)（全量打分+全局选择）。
  - ReTopK 复用步代价为 \(O(Cd + RK + M_t d)\)，其中 \(M_t \le RK + W \ll L_t\)，与上下文长度无关。
  - 保留完整 KV cache，额外元数据开销为 \(O(Cd + CK)\)。

- **实现**
  - 采用融合 GPU kernel：缓存匹配、Top-R 召回、候选去重/排序、索引化 QK 打分、候选 Top-K 选择、稀疏 Softmax-值聚合、缓存更新等阶段逐步融合优化。

## 6. 主要结论与发现

- Top-K 稀疏注意力的主要瓶颈在于全量索引发现，而非稀疏聚合。
- 相似查询间 Top-K 支持集重叠，通过多相似查询支持集取并集，可以覆盖大部分精确支持集且保留绝大多数注意力质量。
- ReTopK 在 16K–128K 上下文上：
  - PG19 困惑度在所有近似方法中最低；
  - NIAH 和 LongBench 分数最高（τ=0.90 配置甚至超过精确 Top-K 的 LongBench 分数）；
  - 默认配置在 128K、K=512 下相对精确 Top-K 加速 **3.07×**，困惑度仅增加 **0.50%**。
- 跨模型实验（Llama-3.1-8B、Qwen2.5-14B）显示无需调参即可获得 1.26×~2.66× 加速，PPL 变化在 -0.46% 到 +2.76% 之间，说明方法具有良好泛化性。
- 支持保真度分析显示：即使对所有 head 统计，平均保留 92.4% 精确 Top-K 注意力质量、97.4% head 输出余弦相似度，且质量随缓存查询相似度增加而提高，支撑了相似性回退机制的有效性。
- 长时稳定性实验中，8K 延续下 PPL 误差保持在 2% 以内，自回归 KL 稳定，无后期误差爆炸。
