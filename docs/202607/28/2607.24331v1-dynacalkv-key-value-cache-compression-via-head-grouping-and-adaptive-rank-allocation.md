## 摘要
随着大语言模型(LLM)推理阶段需要处理长上下文窗口，键值(KV)缓存最初看似解决了这一挑战，但随着上下文窗口不断增长，它最终成为一个显著瓶颈。近年来，低秩压缩被研究为一种在保持模型性能的同时减少KV缓存内存的有效方法。然而，只有少数现有方法区别对待键缓存和值缓存，尽管它们的作用不同。此外，这些方法通常采用固定的注意力头分组，可能无法充分利用注意力头之间的结构相似性。本文提出了一种改进的低秩KV缓存压缩框架。对于键缓存，我们基于中心核对齐(CKA)相似性动态分组注意力头，并在参数预算下自适应分配秩预算。对于值缓存，我们采用与ReCalKV相同的方法，通过离线校准优化低秩分解以提高重建质量。在三个经过指令微调的LLM上的实验结果表明，我们的方法在保持竞争性准确性的同时，减少了键缓存的参数数量。我们进一步观察到，所提出的策略对于多头注意力(MHA)模型特别有效，而对于分组查询注意力(GQA)模型则应更保守地应用，尤其是在长上下文场景中。

## Abstract
As the inference phase of Large Language Models (LLMs) requires handling long context windows, the Key-Value (KV) cache initially appears to address this challenge but eventually becomes a significant bottleneck as the context window continues to grow. Low-rank compression has recently been studied as an effective approach to reduce KV cache memory while maintaining model performance. However, only a few existing methods treat the Key and Value caches differently, despite their distinct roles. Moreover, these methods typically employ fixed attention-head grouping, which may not fully exploit the structural similarity among attention heads. In this paper, we propose an improved low-rank KV cache compression framework. For the Key cache, we dynamically group attention heads based on Centered Kernel Alignment (CKA) similarity and allocate the rank budget adaptively under a parameter budget. For the Value cache, we adopt the same approach as ReCalKV, refining the low-rank decomposition through offline calibration to improve reconstruction quality. Experimental results on three instruction-tuned LLMs show that our method reduces the number of Key cache parameters while maintaining competitive accuracy. We further observe that the proposed strategy is particularly effective for Multi-Head Attention (MHA) models, whereas it should be applied more conservatively to Grouped-Query Attention (GQA) models, especially in long-context settings.

## 1. 论文的核心问题与整体含义（研究动机和背景）

大语言模型（LLM）在推理阶段需要处理长上下文窗口，虽然Key-Value（KV）缓存通过存储先前生成token的注意力表示避免了重复计算，但随着上下文增长，KV缓存的内存消耗成为线性增长的瓶颈。现有的低秩压缩方法虽然有效，但存在两个主要问题：一是大多未区分Key缓存和Value缓存的角色差异（Key主要作为索引，Value包含完整信息）；二是采用固定的注意力头分组（如固定每组4个头），未能充分利用头之间的结构相似性。本文提出DynaCalKV框架，通过动态分组和自适应秩分配，在保持模型性能的同时减少KV缓存的内存占用，并特别关注不同注意力架构（MHA vs. GQA）下的适用性差异。

## 2. 方法论

### 核心思想
- **Key缓存**：基于CKA（Centered Kernel Alignment）相似性度量，将注意力头动态聚类成组，然后根据每组的重要性（用奇异值能量表示）自适应分配秩预算，并在参数预算约束下通过贪心调整优化秩。
- **Value缓存**：沿用ReCalKV的方法，对整个投影矩阵进行低秩分解，然后通过离线校准（在标定数据上最小化重建误差）优化分解因子。

### 关键技术细节
- **CKA相似性**：用于度量不同注意力头之间的表示相似性，数值在0~1之间，值越大表示头越相似。
- **动态分组**：将头分组视为聚类问题，聚类数量K通过最小化一个目标函数选择：重建误差 + λ × (未使用的秩预算惩罚)。λ=1。
- **自适应秩分配**：初始化时每个组的秩与该组的奇异值能量成正比（`ri = round(r * energy_i / energy_total)`），然后执行贪心调整：每次选择“减少一个秩导致的能量损失/该组头比例”最小的组，降低该组秩，直到满足参数预算约束（P(i) ri α_i ≤ 4r/h）。
- **参数预算**：保证总参数数不超过ReCalKV（固定分组大小为4）的参数数。
- **Value压缩**：对原投影矩阵W(v)做SVD获得Lv和Rv，然后利用标定数据X通过闭式解交替优化Lv和Rv，最小化‖LvRvX - W(v)X‖²_F。

### 算法流程（Key压缩）
1. 输入投影矩阵W(k)、相似性矩阵S、秩预算r、候选聚类数K集合。
2. 对于每个K：使用层次聚类将头分成K组；按能量初始化各组的秩；贪心调整满足参数约束；对每组做低秩分解；计算目标函数（重建误差+λ×未使用秩）。
3. 选择使目标函数最小的K，返回对应的低秩因子。

## 6. 论文的主要结论与发现

1. **参数减少**：DynaCalKV相比ReCalKV显著减少了Key缓存参数：Llama-3.2-1B减少18.23%，Qwen1.5-1.8B减少16.00%，SmolLM2-1.7B减少65.23%。减少幅度取决于head维度（高维头更难合并，减少较小）和总层数。
2. **零样本准确率**：在常见知识任务上（PIQA、ARC-e）DynaCalKV优于ReCalKV（平均增益0.87%、2.44%）；在复杂推理任务上略有下降（0.28%~3.00%）；SmolLM2平均增益+0.44%。
3. **长上下文性能**：
   - 对MHA模型（Qwen1.5-1.8B）影响很小，平均仅下降1.02%，甚至在一些摘要任务上略有提升。
   - 对GQA模型（Llama-3.2-1B）造成大幅下降（平均-8.03分），尤其在检索密集型任务（TriviaQA -18.96，TREC -12.50）和摘要任务上。
4. **架构依赖性**：DynaCalKV特别适合标准多头注意力（MHA）模型；对于已使用分组查询注意力（GQA）的模型，在长上下文中应保守应用。

## 7. 优点

- **区分Key/Value角色**：针对Key和Value采用不同策略（Key动态分组+自适应秩，Value整体低秩+离线校准），比统一处理更合理。
- **动态分组**：基于CKA相似性进行聚类，避免了固定分组带来的局限性，能够自适应捕捉头部结构相似性。
- **参数预算可控**：通过贪心调整保证参数数不超过ReCalKV，同时优先保留重要组的秩。
- **零额外推理开销**：所有压缩计算在离线阶段完成，推理时与ReCalKV相同。
- **实验分析细致**：对参数减少的原因（head维度、集群结构）进行了可视化分析，并揭示了架构差异对方法有效性的影响，具有实践指导意义。
