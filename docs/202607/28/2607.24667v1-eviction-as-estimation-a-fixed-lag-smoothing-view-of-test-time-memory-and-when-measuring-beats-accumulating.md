## 摘要
一个具有有限工作记忆的语言模型必须反复决定哪些存储项要保留。每种已部署的方法在项到达时就做出决定，要么基于过去（StreamingLLM, H2O），要么基于对未来的猜测（SnapKV）。我们将这一选择重新表述为对隐藏信号（某个项是否会被重用）的估计问题，将现有方法置于一个轴上，即提交延迟$H$：在线过滤器和学习预测器在$H=0$时提交，而Belady的离线最优解则是在整个未来已知时。介于两者之间的缺失机制，即固定滞后平滑，会等待有限步数，观察正确的近期预测所关注的项，然后才提交。这种测量（已证明的效用）将Belady的不可观察的未来请求转化为我们可以从模型本身读取的信息。我们将其实例化为一个无训练策略RMM，它是H2O的严格泛化，当测量均匀时退化为H2O。在受控设置中，重用是内生的且时间上分离，已证明的效用识别使用的记忆远优于累积注意力，小有限记忆的行为类似于更大的记忆。但在独立的第三方基准测试中，在NVIDIA的KVPress框架内运行，针对其自身的SnapKV、H2O和StreamingLLM实现，优势基本消失：RMM在单轮问答中与H2O相当，在流式多轮设置中输给H2O和SnapKV。原因很简单：在自然文本上，模型对大多数标记是正确的，因此用正确性加权注意力几乎不改变它，除非重用是尖锐且内生的，而标准基准测试并未对此进行测试。我们的贡献是框架以及测量何时胜于累积的诚实地图，而非新的最先进技术。

## Abstract
A language model with a bounded working memory must repeatedly decide which stored items to keep. Every deployed method decides the moment an item arrives, from the past (StreamingLLM, H2O) or from a guess about the future (SnapKV). We recast the choice as an estimation problem on a hidden signal, whether an item will be reused, placing existing methods on one axis, the commit lag $H$: online filters and learned predictors commit at $H=0$, while Belady's offline optimum sits where the whole future is known. The missing regime in between, fixed-lag smoothing, waits a bounded number of steps, observes which items a correct near-future prediction attended to, and only then commits. This measurement, demonstrated utility, turns Belady's unobservable future request into something we read off the model itself. We instantiate it as a training-free policy, RMM, a strict generalization of H2O that reduces to it exactly when the measurement is uniform. In controlled settings where reuse is endogenous and separated in time, demonstrated utility identifies used memory far better than accumulated attention, and a small bounded memory behaves like a much larger one. But on independent third-party benchmarks, run inside NVIDIA's KVPress harness against its own SnapKV, H2O, and StreamingLLM implementations, the advantage mostly disappears: RMM is on par with H2O for single-turn question answering and loses to both H2O and SnapKV in a streaming multi-turn setting. The cause is simple: on natural text the model is correct about most tokens, so weighting attention by correctness barely changes it, and demonstrated utility collapses onto accumulated attention unless reuse is sharp and endogenous, which standard benchmarks do not exercise. Our contribution is the framework and an honest map of when measuring beats accumulating, not a new state of the art.

## 2. 方法论：核心思想、关键技术细节、算法流程

### 核心思想
- 将缓存逐出看作对**隐藏信号（项是否会被重用）**的估计。不同方法在估计所依据的信息上不同：
  - 在线过滤器：依赖过去和现在的信息（累积注意力、最近等）。
  - 学习预测器：依赖对未来需求的猜测。
  - **固定滞后平滑（本文）**：等待一个有限步 \(H\)，观测**正确的近未来预测**实际使用了哪些缓存项（即“演示效用”），再提交决策。
  - Belady离线最优：需要已知未来全部请求序列。

### 关键技术细节
- **演示效用（Demonstrated Utility, DU）**：对缓存项 \(k\)，在滞后窗口 \(H\) 内，来自正确近未来预测位置的注意力总和：
  \[
  DU_H(k) = \sum_{t' \in (t_k, t_k+H]} \mathbb{1}[\text{prediction at } t' \text{ correct}] \cdot a(t' \to k)
  \]
  其中 \(a(t' \to k)\) 是位置 \(t'\) 对项 \(k\) 的注意力，正确性通过教师强制（teacher forcing）检查预测的下一个token与实际是否一致。该信号无标签、自监督。
- 与H2O的关系：H2O 的总注意力为 \(\sum_{t'} a(t' \to k)\)。演示效用相同求和但每个项乘以该位置预测是否正确的指示函数。因此，当每个预测都被视为正确时，DU等于H2O。RMM与H2O的唯一区别就是正确性加权。

### 算法流程（RMM）
1. **提交延迟**：每个到达的项先进入一个大小为 \(H\) 的临时缓冲区，可以在此期间被读取。
2. **测量**：当项在缓冲区停留足够长（达到年龄 \(H\)）后，计算其演示效用（使用已观测到的最近 \(H\) 步的注意力和正确性）。
3. **提交决策**：如果该演示效用排名高于已提交缓存中最弱的项，则提交（永久保留）；否则驱除。
4. **总容量**：永久缓存 \(K\) + 临时缓冲区 \(H\)，总开销 \(K+H\)。
5. **无训练**：在冻结模型上，直接从注意力和正确性计算DU，直接应用于KV缓存。

### 小模型理论
- 论文给出了一个最小模型来说明机制：\(N\) 个项，其中 \(U\) 个有用（有信号请求在延迟 \(d_i \le H\) 内），其余无用；目标是在远时间 \(T\) 时的召回率。结论：固定滞后平滑器（RMM）达到Belady最优召回率 \(min(1, K/U)\)；任何在线策略（必须到达即决策）由于缺乏信息，召回率仅为 \(K/N\)；学习预测器精度 \(p\) 介于两者之间。仿真验证了这一排序。

## 6. 主要结论与发现

- **框架价值**：将KV缓存逐出重新定义为估计问题，引入提交延迟 \(H\) 作为新轴，统一了现有方法和Belady。这是论文最持久的贡献。
- **演示效用作为Belady桥梁**：提出了可观测的、无标签的信号“演示效用”，在已知近未来（通过教师强制）下，使Belady的不可观测请求变为可测量。
- **RMM策略**：严格泛化H2O，在控制实验中当重用是内生且分离时，测量远优于累积；但在独立基准测试中：
  - **单轮预填充**：RMM与H2O统计上不可区分，相对SnapKV和StreamingLLM在激进压缩下有改善。
  - **流式多轮（设计目标场景）**：RMM输给H2O和SnapKV。
- **原因分析**：正确性权重接近均匀（模型对大多数token正确，~0.85-0.90），因此演示效用与累积注意力几乎相同。只有当正确性有选择且局部化时（即重用事件），RMM才与H2O区别开来。标准基准不包含这种尖锐内生的重用模式。
- **总体评价**：论文贡献是框架和诚实地绘制了“测量何时胜于累积”的地图，而不是提出新的SOTA。RMM在当前基准下是H2O级别的，并未超越。

## 7. 优点

1. **理论创新**：将逐出问题抽象为估计问题，引入固定滞后平滑视角，统一了社区中看似不同的方法，提供了清晰的分类（表1）。
2. **Belady桥梁**：用模型自身的注意力和正确性构造了“演示效用”信号，使得Belady的最优替换策略在神经网络记忆中变得可能（尽管依赖教师强制）。
3. **训练无关性**：RMM无需训练，可直接插入现有KV缓存框架，替换H2O或SnapKV作为评分器。
4. **诚实性**：论文明确报告负面结果，不炒作受控实验的优势，给出独立基准的公正比较，并深入分析了为什么优势消失。这种科学透明度值得赞赏。
5. **泛化关系**：RMM严格泛化H2O，在无需正确性信息时自动退化为H2O，确保了安全性。
6. **受控实验设计**：清晰展示了机制成立的条件（内生的、时间分离的重用），有助于理解方法适用的场景。
