## 摘要
我们利用数组数学（MoA）推导了四种用于Transformer注意力的内存最优推理构件，每个构件都直接来自前向传递的指称范式（DNF），其中查询行索引固定为当前解码步骤。这些构件包括：(1) 单查询解码DNF，其中ψ-归约在代数上消除了K^T缓冲区，实现了(d_k + n d_k + n d_v + d_v)×4字节的动态随机存取存储器（DRAM）流量，数值验证误差上限为2×10^{-7}；(2) 一个C/OpenACC图形处理单元（GPU）内核，具有操作范式（ONF）步长算术和硬件合并的内存访问，验证误差无穷范数为0（精确IEEE-754浮点算术）；(3) 通过MoA拼接操作实现的多步KV缓存，每步追加复杂度为O(d_k+d_v)；(4) 通过ψ-选择推导的分组查询注意力（GQA）和多查询注意力（MQA），实现了KV流量减少h_q/h_{kv}。所有程序均通过PyTorch的scaled_dot_product_attention验证。

## Abstract
We derive four memory-optimal inference artifacts for transformer attention using the Mathematics of Arrays (MoA), each following directly from the forward-pass Denotational Normal Form (DNF) of with the query-row index fixed to the current decode step. The artifacts are: (1)~a single-query decode DNF in which the $ψ$-reduction eliminates the $K^\top$ buffer algebraically, achieving $(d_k + nd_k+ nd_v+ d_v)\times4\,{B}$ Dynamic Random Access Memory (DRAM) traffic result numerically verified to $\|{err}\|_\leq2\times10^{-7}$; (2)~a C/OpenACC Graphics Processing Unit (GPU) kernel with Operational Normal Form (ONF) stride arithmetic and hardware-coalesced memory access, verified to $\|\mathrm{err}\|_\infty=0$ (exact IEEE-754 floating-point arithmetic); (3)~a multi-step KV-cache with $O(d_k+d_v)$ per-step append via MoA concatenation $\#$; and (4)~Grouped-Query Attention (GQA) and Multi-Query Attention (MQA) derived via $ψ$-selection, achieving a proven $\frac {h_q} { h_{kv} }$ reduction in KV traffic. All programs are verified against PyTorch scaled_dot_product_attention.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：Transformer 模型在自回归解码阶段，注意力计算需要频繁读取完整的 KV 缓存（Key-Value Cache），导致内存访问成为主要性能瓶颈。传统方法（如 PyTorch 实现）在公式中隐式包含 K^T 缓冲区，导致不必要的 DRAM 流量，且缺乏理论上的内存最小性证明。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：利用 MoA 的 ψ-归约（ψ-reduction）操作，在代数上消除标准注意力公式中的 K^T 缓冲区；同时利用 ONF（Operational Normal Form）步长算术实现硬件合并内存访问，利用 MoA 连接操作实现 O(d) 级 KV 缓存追加，利用 ψ-选择（ψ-selection）实现 GQA/MQA 的流量缩减。
- **关键技术细节**：
  - **单查询解码 DNF**：将 Q 退化为单个向量 ⃗q，通过 ψ-归约将评分计算改写为 ⃗s = scale * (K @ ⃗q)（即 K 逐行读取的矩阵-向量乘法），完全避免 K^T 的物化。软最大值仅作用于向量 ⃗s，无需 n×n 分数矩阵。加权和同理。内存流量为 (d_k + n d_k + n d_v + d_v)×4 B。
  - **C/OpenACC GPU 内核**：ONF 步长算术直接映射为 C 中 `K[l*dk+j]` 等索引表达式。通过维度提升（dimension lifting）将特征维度 d 内化为向量线程轴，使得相邻线程访问相邻内存地址（γ 差为 1），实现完美合并访问。代码使用 OpenACC 的 gang/vector 指令并行，并利用 atomic 保证加权和阶段无竞争。
  - **KV 缓存累积**：使用 MoA 的 # 运算符向已预分配的缓存中追加一行，写入位置由 γ 偏移量 t×d_k 确定，无需复制已有数据，每步追加流量恒为 (d_k+d_v)×4 B。
  - **GQA/MQA**：通过 ψ-选择 ⟨g_kv⟩ψ K 直接索引对应的 KV 头部切片，避免 `repeat_interleave` 广播。为每个查询头复用同一 KV 块，KV 流量由 h_q 降低为 h_kv 倍（即 h_q/h_kv）。
- **算法流程**（文字说明）：
  1. 评分向量 ⃗s = scale * (K @ ⃗q)
  2. 符号稳定 Softmax：m = max(⃗s)，⃗e = exp(⃗s - m)，Z = sum(⃗e)，⃗a = ⃗e / Z
  3. 加权和 ⃗out = ⃗a @ V
