## 摘要
动态稀疏注意力通过仅选择一部分 token 来减少长上下文注意力计算，但仍需访问完整的 KV 缓存，使服务受限于内存。将 KV 缓存卸载到主机内存可降低设备内存压力，但会将 H2D 传输置于解码关键路径上。在 DSA 中，不同解码步骤所选的 KV 条目存在大量重叠，这为设备驻留复用创造了机会。然而，高效利用这种复用面临三个关键挑战：将所选 token 与 HBM 缓冲区中保留的条目进行匹配的开销高昂、剩余 H2D 传输在加速器核心之间分布不均，以及在有限的 HBM 容量内保留频繁访问的 KV 条目。我们提出 AVSG，一种在保持 DSA 精确 token 选择的同时解决这些挑战的算子。AVSG 使用向量化哈希匹配来识别可复用的 HBM 缓冲区槽位，并为需要传输的条目预留槽位，然后将这些 H2D 传输均匀划分到各加速器核心上。基于生命周期的缓冲区管理在解码步骤之间将频繁访问的 KV 条目保留在设备缓冲区中，而共享槽位预留则在一次多 token 预测迭代内跨 token 扩展复用。在单个 NPU 上，向量化哈希匹配比标量双指针匹配快 2.80 倍；仅未命中项传输相较于请求级分配将有效 H2D 带宽提升最多 34.44 倍；8K 条目缓冲区在真实请求上达到 94.83% 的命中率。这些收益转化为端到端改进：在处理真实世界生产数据集的服务栈上，相对于没有 HBM 缓冲区复用的相同 KV 卸载布局，AVSG 将每输出 token 时间减少 39%，并将输出吞吐量提高 1.27 倍，证明了高效匹配、均衡传输和有效 HBM 驻留在生产规模服务中的优势。

## Abstract
Dynamic sparse attention reduces long-context attention computation by selecting only a subset of tokens, but still requires access to the full KV cache, leaving serving memory-bound. Offloading the KV cache to host memory reduces device memory pressure but places H2D transfers on the decoding critical path. In DSA, substantial overlap in selected KV entries across decoding steps creates an opportunity for device-resident reuse. Exploiting this reuse efficiently, however, presents three critical challenges: costly matching of selected tokens against entries retained in the HBM buffer, uneven distribution of the remaining H2D transfers across accelerator cores, and retaining frequently accessed KV entries within limited HBM capacity. We present AVSG, an operator that addresses these challenges for DSA while preserving its exact token selections. AVSG uses vectorized hash matching to identify reusable HBM-buffer slots and reserve slots for entries requiring transfer, then evenly partitions these H2D transfers across accelerator cores. Lifetime-based buffer management retains frequently accessed KV entries in the device buffer across decoding steps, and shared slot reservations extend reuse across tokens within a multi-token prediction iteration. On a single NPU, vectorized hash matching is 2.80x faster than scalar dual-pointer matching, miss-only transfer raises effective H2D bandwidth by up to 34.44x over request-level assignment, and an 8K-entry buffer reaches a 94.83% hit rate on real requests. These gains translate into end-to-end improvement: on a serving stack processing a real-world production dataset, AVSG reduces time per output token by 39% and increases output throughput by 1.27x relative to the same KV offload layout without HBM-buffer reuse, demonstrating the benefit of efficient matching, balanced transfer, and effective HBM residency in production-scale serving.

## 1. 核心问题与整体含义

- **背景**：长上下文 LLM 服务（如 agentic tool use、RAG）上下文可达百万 token，KV cache 随上下文线性增长，常超出单设备 HBM 容量。动态稀疏注意力（DSA）虽只选 top-K token 参与计算，但仍需访问完整历史 KV 与 indexer-key，存储瓶颈未消除。
- **KV 卸载的矛盾**：将完整 KV cache 卸载到主机内存可释放 HBM、提高并发，但 host-to-device（H2D）传输进入解码关键路径。若每步传输全部被选 KV，解码延迟高、吞吐受限。
- **复用机会**：DSA 在不同解码步所选 KV 条目高度重叠，可将频繁访问条目保留在 HBM 缓冲区，仅传输未命中项。
- **三大挑战**：
  - 将当前 top-K token 与 HBM 缓冲区中保留条目高效匹配，避免匹配开销抵消复用收益。
  - 过滤命中后，剩余 H2D 传输分散且请求/步骤间分布不均，导致核心负载不平衡、有效带宽下降。
  - 在有限 HBM 容量内保留高频 KV，合理淘汰冷条目。
- **整体含义**：AVSG 在不修改 DSA indexer 和精确 token 选择的前提下，把“跨解码步的 KV 选择重叠”作为一等资源，通过向量化匹配、均衡 miss-only 传输和生命周期驻留，降低卸载式稀疏注意力服务的解码延迟并提升吞吐。

## 2. 方法论

- **核心思想**：AVSG 是一个后选择 gather 算子。每个解码步 DSA 给出 K 个 top-K token 索引，AVSG 维护一个 HBM 设备缓冲区（S 个槽位），把索引分类为 hit/miss：hit 复用已有槽位，miss 分配新槽位并仅从主机内存传输这些未命中 KV。
- **Hash-State 表**：
  - 每请求一个 S 槽位哈希表，表项为 64-bit：32-bit 选中索引 `c_j` + 32-bit 元数据 `q_j`。
  - `q_j` 打包：8-bit lifetime、1-bit invalid、`(23-m)`-bit id footprint、`m`-bit slot；容量 `S=2^m`，例如 `m=13` 对应 8192 槽位。
  - 表常驻片上 UB，支持 SIMD 向量化探测、比较、更新。
- **Stage One：三遍向量化匹配**：
  - **Refresh pass**：每请求首 token 全局衰减 lifetime 一次；对当前 token 调用 `Probe`，命中槽位 lifetime 恢复为 `L`。
  - **Classify pass**：输出命中槽位向量 `o`、每 token miss 数 `n_g`，为 Stage Two 负载均衡提供输入。
  - **Allocate pass**：回收 dead 槽位；若不足则继续衰减直到够用；将 miss 安装进哈希表并链接桶。
  - **Probe 原语**：初始桶 `h=(a1*x) mod S`，奇数步长 `d=((a2*x) mod S)|1`；最多重试 `R` 次，默认 `R=3`，即每 token 最多检查 `R+1` 个桶。命中判定比较完整 32-bit 索引，避免假命中。
  - **惰性回收**：无反向索引，桶复用时检查 invalid、槽位是否 active、fingerprint 是否匹配，决定是否可覆盖陈旧映射。
- **Stage Two：细粒度多核 H2D 传输**：
  - 只对 miss 构造传输列表，按 token 排序后连续均分到 `C` 个 AI-Core。
  - 每核获得 `⌊N_miss/C⌋` 或 `⌈N_miss/C⌉` 个 miss，任意两核工作量差 ≤1。
  - 与请求级绑定（并行度受 batch size 限制）和等 top-K 位置划分（hit 位置产生 no-op 传输）相比，AVSG 避免无效传输并均衡负载。
- **设备缓存与生命周期管理**：
  - lifetime 为 8-bit 计数器，范围 0–L；命中刷新为 L，未命中旧槽逐步衰减，过期后可回收。
  - 容量约束：`S ≥ N_q K = (N_mtp+1)K`，保证当前请求工作集即使全部 miss 也不会驱逐仍需条目。
  - 默认 `L=16`，通过消融选择；实现类 LRU 老化，而非精确 LRU。
- **MTP 共享缓冲复用**：
  - 同一请求的初始 token 与 `N_mtp` 个投机 token 顺序共享一个缓冲区。
  - 后续 token 可复用前面 token 已预留槽位，即使 KV 数据尚未到达，也只做一次 H2D 拷贝。
  - 投机条目失效：若缓存索引 `c_j ≥ N`（超出已验证上下文长度），步骤末将其标记为空，防止下步基于陈旧设备 KV 产生假命中，保证正确性。

## 6. 主要结论与发现

- **匹配加速**：在 `S=K=2048` 时，向量化哈希匹配比标量双指针匹配快 **2.80×**，延迟从 150.0 μs 降至 53.7 μs；固定 S=4096 时 K 增 8× 仅增 1.27× 延迟；固定 K=512 时 S 增 16× 仅增 1.60×，说明匹配成本与 K、S 近似解耦。
- **H2D 带宽提升**：miss-only 均衡传输相比请求级分配最高 **34.44×** 有效带宽，相比等 top-K 位置划分最高 **3.48×**；在 batch 小、复用高时优势最明显。
- **缓存命中率**：真实请求相邻步复用率 81.61%；4K 缓冲命中率 88.72%，8K 缓冲命中率 **94.83%**，比相邻步复用高 13.22 个百分点。合成低局部性场景下 8K 缓冲增益可达 +44.
