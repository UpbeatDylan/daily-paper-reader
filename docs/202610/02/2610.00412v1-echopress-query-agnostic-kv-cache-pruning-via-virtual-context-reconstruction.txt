# EchoPress: Query-Agnostic KV Cache Pruning via Virtual Context Reconstruction 

Jiawei Lin Saibo Geng Thomas Bourgeat EPFL 

{jiawei.lin,saibo.geng,thomas.bourgeat }@epfl.ch 

Abstract 

KV cache pruning reduces long-context inference memory usage by evicting less important key– value pairs. KVzip estimates importance through context reconstruction: prompting a model to repeat the context chunk by chunk. This achieves strong compression quality at the cost of additional for-ward passes. Learned approximations reduce this cost but require model-specific training. We analyze how KVzip identifies important cached information and show how to approximate its reconstruction scores using information already computed during prefill. These findings motivate EchoPress, a training-free method that approximates reconstruction attention using queries and keys from standard prefill. For each request, it reconstructs only the first chunk to calibrate importance scores for the remaining context. Experiments on LongBench and RULER with Qwen3-8B and Llama-3.1-8B-Instruct show that EchoPress matches KVzip in task accuracy across eviction ratios from 50% to 90%, while reduc-ing compression overhead by 1.7–19.6 × and total prefill time by up to 2.9 ×. Code is available at 

https://github.com/ljwljwljwljw/kvpress .

# 1 Introduction 

The key–value (KV) cache grows linearly with sequence length, increasing memory use during long-context inference (Kwon et al., 2023). KV eviction reduces this cost by discarding less important KV pairs. Query-aware methods use attention from a question or recent observation window to choose what to retain (Li et al., 2024; Cai et al., 2024), but one compressed cache may not serve a different question reliably (Li et al., 2025). Query-agnostic compression uses only the context, allowing the result to be reused across questions, conversation turns, and shared prefixes (Gim et al., 2024; Zheng et al., 2024). Existing query-agnostic methods trade scoring quality for cost. Prefill-based methods use key norms (Devoto et al., 2024), key geometry (Park et al., 2025; Godey et al., 2025), or expected attention (Devoto et al., 2025) without another model forward pass. Reconstruction methods such as KVzip (Kim et al., 2025) instead prompt the model to repeat the context chunk by chunk after prefill. Each KV pair’s importance is scored by the maximum attention it receives during this repetition. A global threshold then evicts the least important pairs across all layers and KV heads. Reconstruction achieves state-of-the-art compression quality but requires expensive additional forward passes over the entire context. In our 4K–128K experiments, KVzip’s compression overhead is 2.1–2.2 × the matching plain-prefill time (Section 3.3). Training-based methods replace reconstruction with model-specific score predictors or eviction gates (J´ egou and Jeblick, 2026; Kim et al., 2026a), reducing inference cost but requiring a separate training stage. We ask whether prefill states can approximate reconstruction scores without training a predictor. Through these hidden states, context keys outside the target chunk can influence reconstruction queries even when excluded from KVzip’s scoring softmax. Our experiments show that exposing all cached keys in the original chunk (difference 1) modestly improves agreement between our prefill-based scores and KVzip’s reconstruction scores, while correcting the positional shift (difference 2) gives the largest gain. Together, these two corrections raise the mean per-request median Spearman correlation from 0.208 to 0.678 on Qwen3-8B and from 0.237 to 0.740 on Llama-3.1-8B-Instruct (Section 3.4). These findings motivate EchoPress’s virtual context reconstruction (Figure 2). It reuses prefill queries and cached keys, corrects the queries’ RoPE positions, and adds a causal virtual-copy branch. Virtual scores preserve useful within-head rankings, but their scales differ across layers and KV heads, complicating global eviction. First-chunk prefill queries also differ most from reconstruction queries because they have seen the least preceding context. EchoPress therefore reconstructs the first chunk exactly and pairs its exact and virtual scores to construct a per-layer, per-KV-head quantile map. The map places later virtual scores on the exact scale, so each request self-calibrates without training. To compute virtual scores efficiently for all later chunks, we implement the scoring operation with fused Triton kernels (Tillet et al., 2019). EchoPress approximates KVzip’s reconstruction scores from queries and keys computed during prefill. It scores every chunk virtually, reconstructs the first chunk exactly, and uses the paired first-chunk scores to calibrate later virtual scores. Figure 2 summarizes the method. 

2.1 Reconstruction scoring in KVzip 

Consider a decoder with L layers, H query heads, and Hkv KV heads of dimension d, with G = H/H kv 

query heads sharing each KV head (Ainslie et al., 2023). The prefilled cache contains n tokens, partitioned into chunks Ct = [ at, b t) of length mt ≤ C. For each chunk, KVzip (Kim et al., 2025) runs a teacher-forced forward pass using the full cache as a prefix. Its input contains a repeat prompt pt of length Pt (e.g., “Repeat the part of the previous context exactly”), followed by the original chunk. The temporary reconstruction cache is discarded after each chunk. Although this forward pass uses the full original cache, KVzip forms its importance softmax from only the initial sink keys, the target cached chunk, and the causal prefix of the repeated chunk. Other context keys affect the reconstruction hidden states but do not enter the scoring softmax. We use the scoring rule implemented in KVPress (J´ egou et al., 2024). 2.2 Virtual reconstruction from prefill states 

At a high level, virtual reconstruction replaces a KVzip reconstruction pass with an attention calculation over states already produced during prefill. For each virtually scored chunk, EchoPress retains the causal prefill representations, shifts them to the RoPE positions where the repeated tokens would appear, and evaluates two key blocks jointly: the original cached chunk and a causal virtual copy. Let qgj , kj denote the unadorned prefill vectors at original context position j ∈ C t. These vectors are conditioned only on the causal prefix through j, unlike the full-context-conditioned ˜q, ˜k in Section 2.1. They also use a different RoPE position: reconstruction shifts token j by ∆t = n + Pt − at. EchoPress retains the causal prefill states and reproduces this positional shift exactly. 3.1 Setup 

We evaluate Qwen3-8B (Yang et al., 2025) and Llama-3.1-8B-Instruct (Grattafiori et al., 2024), abbreviated Llama-3.1-8B in tables and figures. Accuracy experiments use KVPress (J´ egou et al., 2024; Devoto et al., 2025) with bf16, SDPA attention, and batch size one. We compare the uncompressed cache, KVzip, and the EchoPress configuration from Section 2: a 2,048-token reconstruction-input budget, exact first-chunk reconstruction, a separate virtual-to-exact quantile map for each request, layer, and KV head, and global eviction of the lowest-scoring KV pairs. The eviction ratio r is the fraction of KV pairs removed; we test 

r ∈ { 0.5, 0.75 , 0.9} on LongBench and RULER-4K. We evaluate 12 English LongBench tasks (Bai et al., 2024) using KVPress, truncating contexts to 32K tokens. RULER-4K (Hsieh et al., 2024) contains 13 tasks with 500 examples each and uses reference-string matching. Both benchmarks use greedy decoding and per-task output limits. We report equally weighted task averages from one run with seed 42. The evaluator compresses each distinct context once without its questions, then answers its questions independently from that shared cache. We additionally evaluate RULER at 32K and 64K with 20 examples per task across all 13 tasks, using identical inputs across methods within each model and length. These runs compare the uncompressed cache and both compression methods at r ∈ { 0.75 , 0.9}. The task budgets are 32,768 and 65,536 tokens, including the generator’s output allowance. Appendix A.2 details data generation and model settings. For the latency evaluation, we use KVzip’s official CUDA implementation and an EchoPress adapter built on the same codebase, using bf16, FlashAttention-2 (Dao, 2024), batch size one, 2,000-token context chunks, and one 80 GB A100 GPU. Appendix B describes the prefill configurations. Table 10 (Appendix B) summarizes the experimental settings used to evaluate accuracy and timing for KVzip and EchoPress.

# 4 Related work 

KV eviction uses attention scores (Zhang et al., 2023; Oren et al., 2024; Li et al., 2024; Liu et al., 2023a; Chen et al., 2024), layer/head budgets (Cai et al., 2024; Feng et al., 2025; Yang et al., 2024a), or initial and recent tokens (Xiao et al., 2024). FastGen profiles prompts to select head policies; DuoAttention optimizes which heads need full context (Ge et al., 2024; Xiao et al., 2025). FINCH conditions eviction on a prompt; task-aware compression uses task descriptions or examples (Corallo and Papotti, 2024; Corallo et al., 2025). Query-agnostic scores use key geometry or expected attention (Devoto et al., 2024; Park et al., 2025; Godey et al., 2025; Devoto et al., 2025). Compactor combines non-causal attention and leverage scores (Chari and Van Durme, 2025). InfiniPot uses auxiliary prompts and novelty scores; EpiCache compresses conversational episodes (Kim et al., 2024b; 2026b). LU-KV uses offline head utilities (Tang et al., 2026). Learned retention includes Locret, DMS, and TRIM-KV (Huang et al., 2024; Ła´ ncucki et al., 2025; Bui et al., 2025). KVzap and Fast KVzip replace KVzip’s reconstruction scoring with learned predictors or gates (J´ egou and Jeblick, 2026; Kim et al., 2026a). RestoreKV learns cache augmentation before eviction (Baek et al., 2026). EchoPress approximates reconstruction from prefill states and calibrates per request without training. CacheBlend and EPIC inspired our reuse of states under changed context (Yao et al., 2025; Hu et al., 2025). Other approaches prune key channels (Xu et al., 2025), quantize KV entries (Liu et al., 2024b; Yang et al., 2024b; He et al., 2024), sparsify attention computation (Tang et al., 2024; Jiang et al., 2024; Gao et al., 2024; Lu et al., 2025), or selectively access offloaded caches (Lee et al., 2024; Liu et al., 2024a; Chen et al., 2025). These change entry size or cache access; EchoPress permanently removes entries. Deja Vu studies contextual sparsity; LLM-Microscope examines information held by individual tokens (Liu et al., 2023b; Razzhigaev et al., 2025). Our analysis examines which reconstruction computations can be approximated from prefill states. 

# 5 Discussion and limitations 

EchoPress compresses the prefilled context but performs no further eviction during decoding, so the cache grows with generated tokens. Prior work manages this growth through eviction (Zhang et al., 2023; Oren et al., 2024; Anagnostidis et al., 2023; Cai et al., 2025; Du et al., 2025) or learned compressed memory (Kim et al., 2024a). Extending our scorer to completed generation chunks would require buffering query states and choosing a scoring frequency that balances buffering cost, cache savings, and latency. We leave this extension and its evaluation to future work. 10 Benchmark averages also hide task-level regressions: at r ≥ 0.75 , EchoPress trails KVzip on LongBench code completion on both models, and at r = 0 .9 on RULER common-word extraction for Qwen (Tables 4–7). 

# 6 Conclusion 

We introduced EchoPress, a training-free method for query-agnostic KV cache compression. It reuses prefill states to approximate reconstruction scores and calibrates later scores per layer and KV head using one exact first-chunk reconstruction. On LongBench and RULER-4K with Qwen3-8B and Llama-3.1-8B-Instruct, it closely matches KVzip at moderate eviction and exceeds it at 90%. RULER-32K/64K means stay within 2.8 points of KVzip. At 128K tokens, it reduces compression overhead by 19.1–19.6 × on an 80 GB A100 GPU across both models.
