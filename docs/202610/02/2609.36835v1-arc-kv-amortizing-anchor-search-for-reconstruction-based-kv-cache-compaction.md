## 摘要
长上下文大语言模型推理受到随序列长度线性增长的 KV 缓存的瓶颈制约。对于长且可复用的上下文前缀，这一负担尤为严重，因为其缓存必须服务许多下游查询。诸如 Attention Matching 等基于重建的方法能够以紧凑的 KV 缓存实现强劲的下游任务性能。然而，迭代式锚点搜索主导了基于 OMP 的 Attention Matching 的压缩成本。这促使我们提出选择性摊销原则：跨上下文学习一种可复用的锚点选择策略，同时保留上下文特定的重建。在本工作中，我们提出 ARC-KV，一种遵循该原则的新型基于重建的 KV 缓存压缩方法。为此，我们首先训练一个值感知索引器，在单次评分过程中选择真实键锚点。然后，ARC-KV 应用凸包约束的键合并，并针对完整缓存拟合注意力质量偏置与紧凑值。在推理时，ARC-KV 使用冻结的索引器为每个上下文构建一次紧凑缓存，并将其复用于所有后续查询。大量实验表明，在 Llama-3.1-8B-Instruct 上，ARC-KV 在 QuALITY、RULER 和 LongBench 的大多数设置中优于已报道的压缩方法。特别地，在 QuALITY 上以 10% 的 KV 保留率下，ARC-KV 相比 Attention Matching 将准确率从 0.6409 提升至 0.6474，同时将压缩时间从 959.8 秒降至 37.3 秒，缩短为原来的 1/25.73。

## Abstract
Long-context large language model inference is bottlenecked by KV caches that grow linearly with sequence length. This burden is especially severe for long, reusable context prefixes, whose cache must serve many downstream queries. Reconstruction-based methods such as Attention Matching achieve strong downstream task performance with compact KV caches. However, iterative anchor search dominates the compaction cost of OMP-based Attention Matching. This motivates our selective amortization principle of learning a reusable anchor-selection policy across contexts while retaining context-specific reconstruction. In this work, we propose ARC-KV, a novel reconstruction-based KV cache compaction method that follows this principle. To this end, we first train a value-aware indexer to select real-key anchors in a single scoring pass. ARC-KV then applies convex-hull-constrained key merging and fits an attention-mass bias and compact values against the full cache. At inference time, ARC-KV builds the compact cache once per context using the frozen indexer and reuses it for all subsequent queries. Extensive experiments demonstrate that ARC-KV outperforms reported compaction methods in most settings across QuALITY, RULER, and LongBench on Llama-3.1-8B-Instruct. In particular, at 10% KV retention on QuALITY, ARC-KV improves accuracy from 0.6409 to 0.6474 over Attention Matching while reducing compaction time by a factor of 25.73, from 959.8 s to 37.3 s.

## 1. 核心问题与研究动机

- **背景**：长上下文 LLM 推理的主要瓶颈是随序列长度线性增长的 KV 缓存。对 LLaMA-65B，128K token 序列的 FP16 KV 缓存就需约 320GB 显存，既压低服务吞吐，也抬高延迟。
- **关键场景**：长且**可复用**的上下文前缀（如整份代码库、系统日志、长文档），其缓存需服务大量下游查询，压缩收益被反复放大。
- **现有方法谱系**：
  - 规则式 token 驱逐（StreamingLLM、H2O、SnapKV 等）：按位置或重要性分数直接丢弃；
  - 学习式驱逐（KVP、LKV 等）：训练轻量选择器保留子集；
  - 两者共同缺陷：永久驱逐、不可逆信息损失，且保留的 KV 对原样不动，未对丢弃的 softmax 质量与值贡献做补偿。
  - 缓存重建（Cartridges、Attention Matching/AM、Still）：把缓存重建成紧凑形式，AM 在高压缩比（20×–100×）下持续优于驱逐类方法。
- **核心痛点**：OMP 版 AM 将「锚点发现」与「缓存重建」都当作逐上下文的优化问题。实测其加速版 OMP-fast 在 20% 保留率下单是锚点搜索就需 4K 时 3.70 分钟、64K 时 **15.36 小时**，而其余各阶段在 64K 下最多 1.17 分钟——**迭代锚点搜索主导了压缩总成本**。
- **核心洞察（选择性摊销原则）**：锚点选择可跨上下文学习一个可复用先验（同一冻结基座模型内），而重建必须针对当前上下文直接拟合。因此**只摊销选择策略，保留上下文特定的重建**。

## 2. 方法论

### 2.1 问题形式化

- 完整缓存 $K,V\in\mathbb{R}^{T\times d}$，查询 $Q$，全缓存注意力 $P(Q;K)=\mathrm{softmax}(QK^\top)$，$O=P V$。
- 给定预算 $t\ll T$、保留率 $\rho=t/T$，求锚点集 $S=\{s_r\}_{r=1}^t$ 与紧凑表示 $(C_k\in\mathbb{R}^{t\times d},\ \beta\in\mathbb{R}^t,\ C_v\in\mathbb{R}^{t\times d})$，紧凑算子为
  $\hat O(Q;C_k,\beta,C_v)=\mathrm{softmax}(QC_k^\top+\mathbf{1}_n\beta^\top)C_v$。
- 同时需保持**注意力质量**（与非压缩块共存时的竞争强度）：令 $Z_K(q)=\sum_j\exp(qk_j^\top)$、$Z_C(q;\beta)=\sum_r\exp(qc_{k,r}^\top+\beta_r)$，要求 $Z_C\approx Z_K$。

### 2.2 四个上下文特定阶段

1. **完整缓存与参考查询池**：借鉴 KVzip / AM 的 repeat-prefill——先做原始 prefill 得到 $(K,V)$，再让模型「逐字重复上文」，保留每个重复位置的投影前激活 $x_i$ 与 post-RoPE 查询 $q_i$，形成 $D_{\text{ref}}=\{(x_i,q_i)\}$。被压缩的 KV 全部来自原始 prefill。
2. **值感知索引器打分 + Top-t 选择**（唯一被摊销的部分）。
3. **凸包约束键合并**。
4. **闭式拟合 $\beta$ 与 $C_v$**。

### 2.3 值感知索引器（关键技术细节）

- 动机来自 §2.3 的实证：值影响排序（VI，基于 leave-one-out 归一化输出误差）在匹配预算、不相交留出查询下，比纯注意力排序（HA）在四个 layer–KV-head 对上降低截断输出误差 1.05–6.23%。
- 架构：在 DeepSeek Sparse Attention 索引器的低维 query–key 打分器基础上，**增加一个辅助值注意力头**，把每个位置同时用 $k_j$ 与 $v_j$ 表示。
  - 值通路先算一个 query 条件下的值缓存摘要 $c_i=\sum_j \mathrm{AV}_{i,j}U_v v_j$（单一辅助头，所有索引头共享）；
  - 查询嵌入被值摘要增强：$\bar q_{i,a}=\mathcal{N}((L_q q_i+L_c c_i)_a)$；键嵌入被同位置值增强：$\bar k_{j,a}=\mathcal{N}((L_k k_j+L_v v_j)_a)$；
  - 由 $x_i$ 生成权重 $w_{i,a}$，logit 为 $I_{i,j}=\sum_a w_{i,a}\,\mathrm{LeakyReLU}_{0.1}(\bar q_{i,a}^\top \bar k_{j,a}/\sqrt{d_I})$。
  - $L_c,L_v$ 零初始化，故加载纯 query–key 检查点时初始输出完全一致，随后再学值相关修正。
- **聚合与选择**：对 $n_{\text{score}}$ 个参考对，先按 key 做 softmax 得 $\pi_{i,j}$，再跨行做**均方根池化** $s_j=\big(\frac{1}{n_{\text{score}}}\sum_i \pi_{i,j}^2\big)^{1/2}$（RMS 会给「只对少数查询重要」的位置额外权重），取 $s_j$ 最大的 $t$ 个位置为真实键锚点 $S=\mathrm{TopK}(s,t)$。集合每上下文、每 layer–KV-head 只选一次，供所有未来查询复用。

### 2.4 凸包约束键合并

- 用全部参考查询定义每个 key 的**归一化注意力响应画像**：$\ell_{i,j}=q_i^\top k_j$，$z_{\text{merge}}=\max_{i,j}\ell_{i,j}$，$u_j=[\exp(\ell_{i,j}-z_{\text{merge}})]_i$ 再 L2 归一化。
- 每个非锚点键硬分配到响应画像最相似的锚点（按 $u_j^\top u_{s_r}$ 取 argmax），每组含自身锚点且非空。
- 组内权重由查询平均的未归一化注意力质量给出：$\phi_j=\frac{1}{n_{\text{ref}}}\sum_i \exp(\ell_{i,j}-z_{\text{merge}})$，加权质心 $\mu_r=\sum_{j\in G_r}\phi_j k_j/\sum_{j\in G_r}\phi_j$。
- 锚点向质心插值：$c_{k,r}=(1-\lambda_m)k_{s_r}+\lambda_m\mu_r$，$0\le\lambda_m\le1$。因 $s_r\in G_r$，故 $c_{k,r}\in\mathrm{conv}\{k_j:j\in G_r\}$，任意查询下其 key 侧 logit 落在该组真实键 logit 的极值之间，**不外推**。$\lambda_m=0$ 退化为 $C_k=K_S$，$\lambda_m=1$ 即用质心替换锚点。
- 注意：合并只用 $Q_{\text{merge}}$ 与 $K$，值不参与组内平均——值仅通过索引器影响锚点选择、并进入后续 $C_v$ 拟合。

### 2.5 闭式拟合（沿用 AM 的标定）

- 给定合并后的 $C_k$ 与 $Q_{\text{fit}}$：先做投影最小二乘求非负 $w^\star$，使 $\exp(Q_{\text{fit}}C_k^\top)w^\star\approx\exp(Q_{\text{fit}}K^\top)\mathbf{1}_T$，再取 $\beta^\star=\log w^\star$（带裁剪与 $\epsilon_w$ 数值保护）。
- 用 $\hat P=\mathrm{softmax}(Q_{\text{fit}}C_k^\top+\mathbf{1}\beta^{\star\top})$，对 $C_v$ 做带岭项 $\lambda_v$ 的回归：$C_v^\star=\arg\min_C\|\hat P C-Y\|_F^2+\lambda_v\|C\|_F^2$。两个拟合均**不引入可学习参数**。

### 2.6 索引器训练

- **自监督、无 OMP 锚点标签**：以基座模型的全注意力行为为监督。每个训练上下文把 $D_{\text{ref}}$ 无放回划成三个互斥子集 $D_{\text{score}}$、$D_{\text{fit}}$、$D_{\text{holdout}}$，分别在「选择、拟合、评估」三处使用，每个 epoch 确定性重采样。
- **硬分支（前向，无梯度）**：$t=\max(1,\lceil\rho T\rceil)$，$C_k^h=K_S$，由闭式拟合得 $\beta^h,C_v^h$，在 $Q_{\text{holdout}}$ 上算均方相对误差 $L_{\text{out}}^h$。
- **软代理分支（反向）**：Top-t 不可导，故在候选集 $C=\mathrm{TopK}(s,\min\{T,2t\})$ 上放松——对每个候选按其与 Top-t 阈值的分数间隔施加 sigmoid 门 $g_j$（温度从 1.0 线性退火到 0.1），把 $\log g$ 加到注意力偏置上，$C_v^s$ 用可微岭回归求得，得 $L_{\text{out}}^s$。
- **直通估计**：$L_{\text{out}}^{\text{STE}}=\mathrm{sg}(L_{\text{out}}^h)+L_{\text{out}}^s-\mathrm{sg}(L_{\text{out}}^s)$，前向值等于硬分支损失，梯度来自软代理。
- **KL 预热 + 联合目标**：先以 $L_{\text{KL}}=\overline{\mathrm{KL}(p(q)\,\|\,\mathrm{softmax}(I_\theta))}$ 做 KL-only 预热，再联合优化 $L=\lambda_{\text{out}}L_{\text{out}}^{\text{STE}}+\lambda_{\text{KL}}L_{\text{KL}}$。基座模型全程冻结，仅更新索引器参数 $\theta$。
- **推理**：不再划分查询池，同一批参考对同时用于打分、合并与拟合；预算按模型特定的固定权重分配到各 layer–KV-head（超长上下文在连续 chunk 内分别选锚点后取并集）；$(C_k,\beta,C_v)$ 每上下文构建一次并复用。
