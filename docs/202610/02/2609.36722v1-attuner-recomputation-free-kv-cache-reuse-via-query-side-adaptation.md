## 摘要
大型语言模型（LLM）智能体会将可复用内容（如技能、文档和记忆条目）反复加载到当前上下文中。为每个请求重新编码这些内容会浪费计算。位置无关缓存（PIC）通过独立编码每个制品并在任意位置复用其键值（KV）状态来缓解这一问题，但与全上下文预填充相比会带来质量损失。现有方法通过恢复全局位置 ID 或重新计算选定的 token 来修复这一损失。在本工作中，我们分离出该损失的来源，发现位置不匹配的影响较小，且独立缓存的制品仍保留忠实的表示：读取给定制品时基本保持准确，只有当模型必须在多个制品之间进行选择时性能才会下降。此外，将 PIC 的注意力分数替换为全预填充分数后，在缓存 KV 不变的情况下恢复了性能，从而将故障定位到注意力而非 KV 重计算。受此启发，我们提出 Attuner，一种学习读取冻结制品缓存的查询侧适配方法。Attuner 将低秩适配器插入查询投影中，并通过将全预填充分布蒸馏到学生模型中进行训练。它训练的参数量少于模型参数的 0.05%，且在推理时既不需要缓存重计算，也不需要全上下文参考。在 Qwen3-4B 和 Qwen3-8B 上，涵盖技能、文档、记忆和代码的七个基准中，Attuner 在域内和域外设置下均显著优于先前的 PIC 基线，在提供高达 3.73 倍加速的同时达到与全上下文预填充相当的质量。

## Abstract
Large language model (LLM) agents repeatedly load reusable content, such as skills, documents, and memory entries, into the current context. Re-encoding this content for every request wastes computation. Position-independent caching (PIC) alleviates this by encoding each artifact independently and reusing its key-value (KV) states at arbitrary positions, but it incurs a quality loss relative to full-context prefill. Existing methods repair this loss by restoring global position IDs or recomputing selected tokens. In this work, we isolate the source of the loss, finding that the positional mismatch has minor effect, and independently cached artifacts retain faithful representations: reading a provided artifact stays largely accurate, and performance degrades only when the model must select among multiple artifacts. Moreover, replacing PIC's attention scores with full-prefill scores recovers performance with the cached KV unchanged, localizing the failure to the attention rather than KV recomputation. Motivated by this, we propose \textsc{Attuner}, a query-side adaptation method that learns to read a frozen artifact cache. \textsc{Attuner} inserts low-rank adapters into the query projections and is trained by distilling full-prefill distribution into the student. It trains fewer than 0.05\% of the model parameters and, at inference, requires neither cache recomputation nor a full-context reference. On Qwen3-4B and Qwen3-8B across seven benchmarks covering skills, documents, memory, and code, \textsc{Attuner} substantially outperforms prior PIC baselines in both in-domain and out-of-domain settings, matches full-context prefill quality while providing up to $3.73\times$ speedup.

# ATTUNER 论文中文总结

## 1. 核心问题与研究背景

- **研究动机**：LLM 智能体在每次请求中反复加载可复用内容（技能描述、文档、记忆条目），论文将其统称为 **artifact**。为每个请求重新编码这些 artifact 会浪费大量计算，并显著抬高首 token 时延（TTFT）。
- **现有方案及其局限**：
  - 传统**前缀缓存**（如 RadixAttention）假设可复用内容在每次请求中占据相同前缀位置；但 agentic 工作负载中 artifact 的选取、顺序与位置由检索、路由、规划在运行时动态决定，该假设难以成立。
  - **位置无关缓存（PIC）** 通过独立编码每个 artifact 并复用其 KV 状态来支持任意位置加载，但相对全上下文预填充（Full prefill）存在明显质量损失。
  - 已有修复方法主要在推理时进行：恢复全局位置 ID，或重算部分 token（CacheBlend、EPIC 等），开销较高。
- **核心洞察**：论文通过受控实验分离质量损失来源，发现：
  - 位置错配影响**较小**；
  - 独立缓存的 artifact **表示仍然忠实**，单 artifact 读取基本准确；
  - 性能下降主要出现在**多 artifact 选择/注意力分配**场景；
  - 在保持缓存 KV 不变的前提下，用全预填充注意力分数替换 PIC 分数即可恢复性能——**故障定位于注意力读取方式，而非 KV 重计算**。

## 2. 方法论：ATTUNER

- **核心思想**：不重写缓存，而是"学习读取冻结的 artifact 缓存"。由于查询（query）只对在线 token 计算、键值（KV）可直接复用，**在查询侧做适配可在不改变缓存的前提下修正注意力路由**。
- **关键技术细节**：
  - 在每个 Transformer 层的查询投影 `W_Q` 上插入低秩适配器（LoRA 风格）：
    - `ẽq_{ℓ,t} = W_Q^ℓ h_{ℓ,t} + (α/r) B_ℓ A_ℓ h_{ℓ,t}`
    - 其中 `A_ℓ ∈ R^{r×d_model}`、`B_ℓ ∈ R^{d_q×r}` 可训练，`r` 为秩，`α` 控制缩放。
  - `B_ℓ` 零初始化，使初始更新为零；仅训练 `A_ℓ, B_ℓ`，**基座模型全部冻结**。
  - 适配后的查询仍经过原有 query normalization 与 RoPE 再进入注意力。
  - 适配器**仅对未缓存的 prompt token 与生成 token 启用**；artifact KV 保持原样，在线状态与新产生的 KV 在适配后的计算下演化。
- **训练流程（全上下文蒸馏）**：
  - 冻结的全上下文教师生成响应 `Y`，形成训练集 `D_T`；教师与学生接收相同输入、条件于相同响应前缀。
  - 最小化响应位置的输出分布 KL 散度：`L(ϕ) = E[ (1/|Y|) Σ D_KL( sg[p_full] ‖ p_PIC ) ]`，其中 `sg` 阻断教师梯度。
  - 直接监督**输出分布**而非注意力权重，使模型学得适合固定缓存的读取策略。
  - 训练参数量 **< 0.05%**；部署时适配器可合并进查询投影（`W_Q ← W_Q + (α/r)B A`），**无需教师、无需缓存重建**。

## 6. 主要结论与发现

- **问题定位**：PIC 的质量损失主要来自**注意力路由**而非缓存 KV 表示；位置对齐不能一致地恢复性能。
- **恢复路径**：保持 artifact KV 不变、仅恢复全预填充注意力行，即可在表示层（输出余弦相似度提升至 ~0.98）与任务层（MuSiQue EM 34.84→47.91 vs Full 47.79；BigCodeBench pass@1 38.98→44.53 vs Full 43.63）大幅恢复。
- **ATTUNER 效果**：
  - 域内平均分较 PIC 提升 **5.13（4B）与 7.77（8B）** 分，与 Full 的差距缩小至 1.61 与 0.51 分。
  - 域外 TheoremQA、CHAMP 平均提升 **3.02 与 3.51** 分（二者未参与训练）。
  - 达到接近 Full 的质量，同时保持 **1.79× / 2.45×** 的域内几何平均加速；TTFT 仅比 PIC 高 1.8% / 0.5%，最高加速达 **3.73×**。
- **数据规模**：1,024 条训练样本即可显著恢复（MuSiQue F1 48.70→56.40），8,192 条可达 61.15，追平 Full 的 61.01。
- **对齐分析**：适配后中间层注意力输出与 Full 的余弦相似度提升（答案阶段 MuSiQue 0.903→0.927，BigCodeBench 0.932→0.949），但最后一层对齐变差；说明恢复不必逐层复现 Full 计算。
- **增益来源**：同一适配器在 PIC 下平均增益（+5.13）远大于在 Full 下（+0.17），且每个任务上 PIC 增益都更大，支持"适配独立缓存读取"是主要来源。

## 7. 优点

- **诊断深入且有力**：通过 routing oracle、组件替换（K/V/routing）、位置控制等受控实验，清晰地将失败定位到注意力读取而非 KV 表示，论证链条完整。
- **方法极轻量**：仅查询投影低秩更新，训练参数 < 0.05%，不修改基座、不重建缓存、不重算 token。
- **部署友好**：适配器可合并进权重，推理时无需教师或全上下文参考；缓存构建仍用原始未适配模型，兼容现有 PIC 流程。
- **泛化性**：单个共享适配器跨技能、文档、记忆三类 artifact，且能迁移到未见任务（TheoremQA、CHAMP）。
- **实验协议规范**：明确 TTFT 计时边界、匹配 cohort 与硬件、合并请求级时延后再取中位数，并公开基线实现细节与变体差异。

## 8. 不足与局限

- **覆盖范围有限**：未测试三类 artifact 混合的请求；仅针对全注意力模型，其他注意力架构的适用性未知。
- **定位边界**：工作聚焦"缓存读取"而非缓存存储、放置、驱逐与通信优化；效率测量为 batch size 1、无并发、warm-cache 场景，非端到端服务延迟。
- **域外恢复不完整**：TheoremQA、CHAMP 上仍与 Full 有差距；CHAMP 在 Qwen3-4B 上部分基线（如 CacheBlend）表现优于 ATTUNER。
- **基线与实现风险**：AgentKVShift 为无官方代码的重实现；CacheBlend/APE 为 Qwen3 移植变体；COMB 结果异常差，可能低估其真实能力，影响方法排序的公平性。
- **训练数据细节**：部分教师轨迹为 legacy 固定前缀（Qwen3-4B MuSiQue 全部 4,000 条），PersonaMem 中大量轨迹在 256 token 处截断，可能限制蒸馏信号质量。
- **算力信息缺失**：未报告 GPU 型号、数量与训练时长，难以评估训练成本与可复现性。
- **质量与效率权衡**：KVLink 平均质量略高但 TTFT 超过 ATTUNER 两倍以上；ATTUNER 仍需在质量与延迟之间取舍。
