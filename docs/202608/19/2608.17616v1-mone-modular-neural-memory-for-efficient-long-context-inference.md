## 摘要
我们提出了MoNe，一种轻量级模块化神经记忆，可附加到任何冻结的预训练Transformer上，无需重新训练即可实现长上下文推理。MoNe通过测试时学习快速权重神经记忆网络，并使用分层局部梯度更新，以固定大小的段读取上下文；在推理时，记忆仅从查询令牌生成键和值，无需重新读取上下文令牌。这种两阶段设计将推理成本与上下文长度解耦，实现了$O(N)$预处理和$O(1)$查询成本，峰值GPU内存不随$N$增长。在128K令牌时，与ICL相比，MoNe将计算和峰值GPU内存均减少约80%，且仅增加6.4%的参数开销。MoNe可泛化到远超骨干网络原生窗口的上下文长度，在RULER的针包检索和词语提取基准上表现强劲，而ICL在这些基准上性能急剧下降。

## Abstract
We present MoNe, a lightweight modular neural memory that attaches to any frozen pretrained Transformer to enable long-context inference without retraining. MoNe reads context in fixed-size segments via test-time learning of fast-weight neural memory networks with layer-localized gradient updates; at inference, the memory generates keys and values from the query tokens alone, with no context tokens re-read. This two-phase design decouples inference cost from context length, achieving $O(N)$ preprocessing and $O(1)$ query cost with peak GPU memory that does not grow with $N$. At 128K tokens, MoNe reduces both compute and peak GPU memory by approximately 80% compared to ICL with only 6.4% parameter overhead. MoNe generalizes to context lengths far beyond the backbone's native window, achieving strong performance on needle-in-a-haystack and word extraction benchmarks from RULER, where ICL degrades sharply.

## 2. 论文提出的方法论

**总体框架**：MoNe 是一个附带在冻结预训练 Transformer 每一层上的快速权重神经记忆模块，采用**两阶段设计**——测试时学习（test-time learning）和推理（inference）。

**关键技术细节**：

- **记忆模块结构**：每层使用 SwiGLU MLP 作为记忆模块，参数为 \(W^{(l)} = \{W_{in}, W_{gate}, W_{out}\}\)，各矩阵均为 \(\mathbb{R}^{d_h \times d_h}\)，比单一线性映射具备更强表达能力。

- **分段顺序处理**：将上下文 \(C = (t_1, \ldots, t_N)\) 划分为 S 个不重叠的固定大小段（默认 T=512），逐段处理并在线更新快速权重。

- **层局部梯度更新（Layer-localized gradient updates）**：通过关联记忆损失（Associative Memory Loss）计算每个段内 token 的梯度，梯度完全不跨层传播（\(\partial \ell^{(l)}_{s,j}/\partial W^{(l')}_{s-1} = 0, \forall l' \neq l\)），使更新高效且真正模块化。公式：
  - 损失：\(\ell^{(l)}_{s,j}(W^{(l)}) = -v^{(l)\top}_{s,j} M(k^{(l)}_{s,j}; W^{(l)})\)
  - 权重更新：\(W^{(l)}_s = W^{(l)}_{s-1} - \mu^{(l)}_s\)

- **记忆注入注意力**：推理时，查询 token 仅经过 \(W_q\) 投影后读取最终快速权重 \(W^{(l)}_S\)，生成固定大小（T 个）的记忆 token，再经 \(W_k\)、\(W_v\) 投影为 KV 对并与查询自身的标准注意力 KV 拼接：\(\text{Attention}(Q, [K \| W_k h], [V \| W_v h])\)。

- **分段局部 RoPE**：上下文 token 使用段内位置 \(p_{local}^j = j \bmod T\)，使位置索引始终落在 \([0, T)\) 区间，与总上下文长度无关。推理时 query 长度 \(Q \ll T\)，无需位置插值即可泛化到任意长上下文。

- **元训练**：LoRA 适配器（rank 128）及元参数（学习率、动量衰减、输出缩放）通过离线生成损失训练，在部署时冻结，快速权重更新为固定的"预学习算法"。

- **额外设计**：key 经 SiLU 激活和 per-token L2 归一化，value 经 SiLU 激活；输出经 RMSNorm 和 SiLU 门控后注入注意力；权重在每次更新后逐通道 L2 重新归一化；使用逐 token 学习率（softplus 激活）和数据依赖动量衰减（sigmoid 激活）。

## 3. 实验设计

**骨干模型**：Qwen2.5-0.5B-Instruct（24 层解码器，隐藏维度 768，\(d_h=224\)，H=4 头），所有基线使用同一冻结骨干。

**数据集与基准**：来自 RULER benchmark 的三个任务：
- **S-NIAH（Single Needle-in-a-Haystack）**：单键值对检索，指标为子串精确匹配（Sub-EM）。
- **MK-NIAH（Multi-Key Needle-in-a-Haystack）**：四组键值对散布于 Paul Graham 散文片段中，需在干扰项中检索特定值，Sub-EM 指标。
- **FWE（Frequent Word Extraction）**：从 Zipfian 分布采样的合成 6 字符单词中提取 top-3 高频词，指标为变量召回率。

**评估长度**：覆盖骨干原生窗口内（4K、8K、16K、32K）和超出原生窗口（48K、64K、96K、128K）共 8 种上下文长度。

**对比方法**：
- **ICL（In-Context Learning）**：完整上下文作为提示，受限于 32K 原生窗口。
- **RAG（Retrieval-Augmented Generation）**：128 token 分块 + BGE-Large 嵌入，评估 K ∈ {1, 4, 8} 取最佳。
- **MoNe（Ours）**：两阶段方案。

**训练/评估数据规模**（附录 A.1）：训练 30K 样本覆盖 1K–4K 上下文，评估每长度 100 个样本覆盖 4K–128K。

## 6. 论文的主要结论与发现

1. **性能优势**：MoNe 在窗口内（4K–32K）所有任务上达到近完美分数（0.99–1.00），显著超越 ICL（0.41–0.98）和 RAG（0.58–0.93）。
2. **长度外推能力**：MoNe 仅用 4K 上下文训练，即泛化到 128K（32×外推），在 S-NIAH、MK-NIAH、FWE 上分别保持 0.96、0.94、0.96 的优异成绩，而 ICL 在超出 32K 窗口后急剧退化（MK-NIAH 128K 降至 0.00）。
3. **效率优势**：128K 时 MoNe 相比 ICL 总 FLOPs 减少 81%（786.33 T → 149.61 T），峰值 GPU 内存减少 80%（7.07 GB → 1.41 GB），且峰值内存不随上下文长度增长（恒定 1.41 GB）。
4. **参数开销小**：仅增加约 6.4% 参数（所有层附加时）。
5. **消融结论**：全部 24 层覆盖最优，缩减层数严重损害长上下文性能；分段大小 T=512 性能最佳且效率损失微小。
6. **附加功能**：最终快速权重状态可跨多个查询复用，并支持增量扩展（新上下文到来时无需重新处理旧内容）。

## 7. 优点

- **真正的即插即用**：无需修改或重训练任何骨干权重，可直接附加到任意预训练 Transformer，兼容性极强。
- **成本解耦设计**：两阶段设计从根本上将推理成本从上下文长度中解耦——测试时学习 \(O(N)\)，查询 \(O(1)\)，峰值内存恒定。
- **层局部梯度更新**：避免了跨层反向传播，使更新高效且模块化，是设计上的关键创新。
- **卓越的长度外推**：通过分段局部 RoPE 实现无需位置插值的超长上下文泛化（32×外推），意义重大。
- **实用特性**：支持多查询复用和增量上下文扩展，适合对延迟和成本敏感的移动端场景。
- **参数效率**：SwiGLU MLP + LoRA + 逐 token 学习率 + 数据依赖动量衰减的组合在极小开销下获得强表达能力。
- **实验报告透明**：表 2 分离了测试时学习和推理阶段的成本，使读者能清晰了解各阶段开销分布。

## 8. 不足与局限

- **骨干规模有限**：仅在 Qwen2.5-0.5B 上验证，未报告在更大模型（如 7B、70B）上的表现，通用性尚待证明。
- **任务类型局限**：仅覆盖 RULER 的合成检索/提取任务，这些任务的模式相对简单、事实密度可控；未评估复杂多跳推理、数学推理、指令遵循等更具挑战性的场景，也未使用自然语言长文档（如 HotpotQA、SQuAD、ZeroSCROLLS）。
- **RAG 基线配置**：RAG 的 top-K 在不同长度下取最优值报告（"报告最佳分数"），可能高估了 RAG 的实际表现；同时未报告 RAG 的计算开销作为对照。
- **硬件细节缺失**：未提供 GPU 型号、训练时间、推理延迟等对工程部署十分关键的指标。
- **元训练依赖**：虽然骨干冻结，但 LoRA 适配器和元参数需要离线训练（基于 4K 以内数据），对于没有足够离线数据/算力的用户来说，开箱即用性受限。
- **记忆容量上限未知**：恒定大小的记忆 token（每层 T=512 个）在极长上下文（如 1M+）下是否会饱和、性能如何衰减，未做探讨。
- **与 ICL 的性能差距在超长上下文的语义复杂性上未验证**：在真实世界复杂长文档中，压缩式记忆是否仍能保持优势，有待进一步研究。
