## 摘要
长上下文LLM解码在每一步都要读取键值（KV）缓存。加载缓存的时间比计算注意力所需的时间更长，因此吞吐量受带宽限制。因此，减小缓存大小可以提高解码速度和服务器容量。挑战在于在保持注意力乘积的同时减小缓存大小，保持重建成本低廉，并使用固定的每标记比特数。在每元素两比特的情况下，最具竞争力的方法依赖于正交变换。然而，现有技术要么是数据无关的，要么在未从失真准则推导变换的情况下使用查询统计信息。此外，它们依赖基于随机或哈达玛旋转构建的变换，这些变换均衡各条目间的方差而非压缩能量，并且使用固定宽度的标量量化器，这在低比特率下并非最优。在本文中，我们将KV缓存量化表述为一个变换编码问题，其中失真为注意力乘积中的误差。我们在高分辨率模型下，从校准统计中推导出键和值的闭式最优变换。我们表明，最优键变换不是正交的，并满足广义帕塞瓦尔关系：注意力感知失真在变换域中变为均方误差（MSE）。因此，我们可以将MSE最优向量量化器直接应用于变换后的键系数。为满足固定宽度布局要求，我们表明将系数分组为等体积分区可使等大小码本在高分辨率模型下达到变比特率最优。在每元素两比特的情况下，我们的方法NOVA-KV在可比吞吐量下，恢复了因标量量化方法而损失的大部分长上下文检索精度。

## Abstract
Long-context LLM decoding reads the key-value (KV) cache at every step. Loading it takes longer than computing attention over it, so throughput is bandwidth-bound. Hence, reducing the cache size can raise both decoding speed and serving capacity. The challenge is to reduce cache size while preserving the attention products, keeping reconstruction cheap, and using a fixed per-token bit count. At two bits per element, the most competitive methods rely on orthogonal transforms. However, existing techniques are either data-oblivious or use the query statistics without deriving the transform from a distortion criterion. Moreover, they rely on transforms built on top of random or Hadamard rotations, which equalize variances across entries rather than compacting energy, and fixed-width scalar quantizers, which are suboptimal at low rates. In this paper, we formulate KV cache quantization as a transform coding problem in which distortion is the error in the attention products. We derive closed-form optimal transforms for keys and values from calibration statistics, under a high-resolution model. We show that the optimal key transform is not orthogonal and satisfies a generalized Parseval relation: the attention-aware distortion becomes mean-squared error (MSE) in the transform domain. Thus, we can use MSE-optimal vector quantizers applied directly to the transformed key coefficients. To meet the fixed-width layout requirement, we show that grouping coefficients into equal-volume partitions makes equal-size codebooks attain the variable-rate optimum under the same high-resolution model. At two bits per element, our method, termed NOVA-KV, recovers most of the long-context retrieval accuracy lost by scalar quantization methods at comparable throughput.

## 1. 论文的核心问题与整体含义

- **背景**：长上下文 LLM 解码时，每一步都需要读取完整的 KV 缓存。KV 缓存加载耗时已超过注意力计算本身，因此解码吞吐量受限于内存带宽而非算力。
- **核心问题**：如何在保持注意力输出精度的前提下，用尽量少的比特数压缩 KV 缓存，同时满足：
  1. **固定宽度布局**（每个 token 占固定比特数，便于服务引擎并行读取）；
  2. **低读取路径复杂度**（解码时不能有逐元素/逐系数的重解码开销）；
  3. **注意力感知的失真**（不能只优化普通 MSE，应最小化量化对注意力分数/输出的影响）。
- **整体贡献**：针对 2 bits/元素（低比特率）场景，论文提出 **NOVA-KV**（Non-Orthogonal Vector-quantized Attention for KV cache），将 KV 缓存量化重新建模为**变换编码**问题，并显式以注意力乘积误差为失真准则设计变换和量化器，最终在兼容服务引擎固定宽度布局的同时显著优于既有 2-bit 方法。

## 2. 方法论

### 2.1 核心思想

- 将 KV 压缩目标分解为**键（key）项**和**值（value）项**两部分：
  - 键项控制 softmax 分数误差（即 logits 误差）；
  - 值项控制分数加权下的值重建误差。
- 在高分辨率量化模型下，输出误差可由这两项之和上界约束，从而可以分别设计键变换与值变换。

### 2.2 键变换：非正交变换

- 键相关失真是如下的**查询加权二次失真**：
  
  \[
  \sum_j \|k_j - \hat{k}_j\|^2_{M_q}, \quad M_q = Q^\top Q
  \]
  
  其中 \(M_q\) 为校准查询的二阶矩。
- 通过**压缩扩展（companding）**理论，最优线性压缩矩阵 \(R\) 应满足：
  
  \[
  R R^\top = c M_q
  \]
  
  因此，**正交变换在一般情况下不是最优的**（除非 \(M_q \propto I\)）。
- 论文进一步利用加权低秩重构优化确定剩余正交因子，得到闭式解：
  
  \[
  R_K^\star = M_q^{1/2} E_{1:p}
  \]
  
  其中 \(E\Lambda E^\top\) 是 \(M_q^{1/2}\tilde{S}_K M_q^{1/2}\) 的特征分解，\(\tilde{S}_K\) 是中心化键的散度矩阵。
- 该变换满足**广义帕塞瓦尔关系**：
  
  \[
  \|r - \hat{r}\|^2_2 = \|k - \hat{k}\|^2_{M_q}
  \]
  
  从而将“注意力感知失真”转换为变换域中的普通 MSE，后续可直接使用任意 MSE 最优量化器。
- 由于键的平均值在 softmax 中抵消，可先对键做中心化，不增加比特开销。

### 2.3 值变换：正交变换

- 值项失真为：
  
  \[
  \|S V - S \hat{V}\|^2_F
  \]
  
  其最优低秩基为 \(M_o = V^\top S^\top S V\) 的特征向量，即输出协方差的主成分。
- 该值为**正交变换** \(R_V = E_{1:p}\)，与现有工作（如 OSCAR）中启发式使用的协方差一致，但论文从率失真准则中推导得出。

### 2.4 向量量化与等体积分组

- 在固定宽度布局下，每组系数使用**相同大小、相同比特数**的码本。
- 在高分辨率模型下，每组失真满足：
  
  \[
  D_\ell(b_\ell) = C_g 2^{-2b_\ell} \left(\prod_{i\in G_\ell}\sigma_i^2\right)^{1/g}
  \]
  
  其中组体积 \(v_\ell = \prod_{i\in G_\ell}\sigma_i^2\) 是唯一影响分组效果的量。
- **定理 2** 表明：若允许可变比特分配，任意分组都能达到相同的总失真；但若要求固定速率（固定宽度）\(b_\ell \equiv b\)，则只有当各组体积相等时才最优。因此论文设计**等体积分组**：按方差大小排序后，将系数依次轮流分配到 \(L\) 组中（即 \(i \bmod L\) 分组），使每组体积近似均衡。
- 键使用向量量化（VQ，组大小 \(g=4\)，码本 256 个中心，平均 2 bits/坐标）；值仍使用标量量化（INT2 + 缩放/零点），原因是实验发现值侧 VQ 相对 SQ 提升很小，而 SQ 读取路径更简单。

### 2.5 推理路径

- **写路径**（每个 token 只写一次）：键做中心化、变换、分组、最近邻编码；值做仿射 INT2 编码。
- **读路径**（每一步都要执行）：仅做码本查表 + 缩放/偏移，不乘变换矩阵；键变换的逆被折叠到查询中（每个解码步只做一次 \(q R_K^{-\top}\) 或等价处理），值变换逆被吸收到输出投影中。

## 6. 主要结论与发现

- **非正交键变换**是提升 2-bit KV 压缩精度的关键：正交变换（OSCAR、QuaRot）即使搭配 VQ 也达不到 NOVA-KV 在注意力保真上的表现。
- **注意力感知失真比普通 MSE 更贴近真实任务**：KLT 在 MSE 上最优，但在 top-1 注意力一致性上不如 NOVA-KV 变换；NOVA-KV 以略高的 MSE 换取更好的注意力保留。
- **等体积分组让固定宽度 VQ 逼近变速率最优**：实验显示方差排序（体积不平衡）性能最差，随机分组其次，等体积分组最佳，与定理 2 预测一致。
- **长上下文检索恢复显著**：
  - Qwen3-8B 128K：NOVA-KV 75.4 vs OSCAR 25.3，QuaRot 0.0；提升超过 50 个百分点。
  - GPT-OSS-20B：OSCAR/QuaRot 完全失效（0 分），NOVA-KV 保持 54.0（BF16 为 80.4）。
  - Llama-3.1-8B：64K 时 92.4 vs OSCAR 76.9。
- **常规任务精度损失很小**：
  - 在 Qwen3 两个模型上，NOVA-KV 与 BF16 之间无显著差异（McNemar p > 0.1）；
  - GPT-OSS-20B 上平均仅下降 4.1 分，而 OSCAR 下降 62.6 分。
- **吞吐与标量基线相当**：在长上下文、大批次下，NOVA-KV 的 decode 速度与 OSCAR 接近，且能支持更大的批大小（BF16 OOM 时仍可服务）。
- **GPT-OSS 上标量方法的失败不是实现问题**：通过 HuggingFace 模拟、重建 SNR、logit 误差分析，确认是 2-bit 标量量化对该架构的“注意力信息密度”过高所致；提高速率后标量方法恢复。

## 7. 优点

- **理论驱动且形式优美**：从率失真/变换编码理论出发，推导出闭式非正交键变换，并给出广义帕塞瓦尔关系，使得后续量化器设计可以回归标准 MSE 框架。
- **同时解决“固定宽度”和“能量压缩”的矛盾**：通过等体积分组 + 等大小码本，在不需要熵编码/可变长度码的前提下达到接近变速率最优的效果。
- **读路径开销极低**：解码时只有查表和缩放，逆变换被折叠到查询或输出投影中，符合服务引擎对固定宽度和并行读的要求。
- **实验充分且有深度**：不仅报告主指标，还对失败案例（GPT-OSS）、高分辨率模型假设、分区效果、校准域敏感性、chunked-prefill 泄漏做了详细分析，提升结论可信度。
- **生产级整合**：实现了 SGLang 中的 fused decode kernel，给出了逐 kernel 耗时剖析（GEMM/Attention/Quant/Other），证明方法在实际服务栈中可用。

## 8. 不足与局限

- **高分辨率假设在 2-bit 下不严格成立**：论文多次强调理论是渐进结果，只在 2 bits 时作为设计指导；经验测试显示速率指数 α 约 1.8 而非理论值 2，低速率时预测偏差明显。
- **值量化仍为标量**：值侧 VQ 虽有微小提升，但作者选择保留 SQ 以简化读取路径；这意味着值侧的压缩能力可能没有完全发挥。
- **校准依赖域内数据**：虽然附录显示 GPQA/MMLU 校准差异不大，但实际部署时校准集的收集和计算仍是额外成本；论文只用 198 条 prompt，泛化到未见任务域的效果仍需验证。
- **GPT-OSS 实验只量化部分层**：该模型有 12 个滑窗层保持 BF16，因此其 2-bit 平均 BPE 低于名义值（2.41 vs 2.22），相对收益的公平性受架构影响。
- **基线设置可能不完全公平**：
  - TurboQuant 报告在 3.25 BPE 而非 2.2 BPE，精度对比中比特率不一致；
  - OSCAR 的报告取“refit 版本与官方版本中较好者”，这降低了对比的严格性；
  - 所有方法都使用 chunked prefill，可能导致基线得分低于原论文报道，但作者已明确指出。
- **LongBench 上差异较小**：在短上下文/标准长度基准上，NOVA-KV 与 OSCAR 的差距不总是统计显著（如 Qwen3-8B 全保护带下平均差 +0.70，CI 包含 0）。
- **计算开销未充分公开**：校准、k-means、服务端写路径（编码）的具体时间开销没有单独报告；只在吞吐中显示了写路径的 kernel 时间，且在批大小大时写路径成本占比升至 8–10%。
- **可扩展性问题**：码本和变换按 (layer, KV head) 存储，附录中给出的每模型额外存储约 0.30 Gbit；虽然摊销后很小，但超长上下文/超大 KV head 数量下是否仍可忽略未做压力测试。
