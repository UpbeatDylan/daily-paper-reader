## 摘要
学习型KV缓存驱逐常常面临软到硬的不匹配：在训练期间，可微分门控通常减弱token的贡献，而推理仅在KV条目被物理移除时才节省内存。我们询问注意力基础是否影响这种软到硬的转换。使用在OpenWebText上训练的GPT-2规模Transformer，我们对注意力类型、学习门控和位置编码进行了受控的2×2×2比较。尽管sigmoid注意力作为密集语言模型表现较差，但学习型硬驱逐改变了有用的操作点：sigmoid门控模型删除KV条目时，相对于其自身的无驱逐参考，困惑度变化可忽略不计。在相同密集骨干网络上的匹配实时缓存协议下，学习型sigmoid门控获得的困惑度低于我们的H₂O和KeyDiff实现，而softmax门控并不统一优于这些事后方法。结果表明，注意力归一化可以显著影响训练时软门控是否干净地迁移到硬KV删除。

## Abstract
Learned KV-cache eviction often faces a soft-to-hard mismatch: during training, differentiable gates typically attenuate token contributions, whereas inference saves memory only when KV entries are physically removed. We ask whether the attention substrate affects this soft-to-hard transition. Using GPT-2-scale Transformers trained on OpenWebText, we run a controlled $2\times2\times2$ comparison over attention type, learned gating, and positional encoding. Although sigmoid attention is worse as a dense language model, learned hard eviction changes the useful operating points: sigmoid-gated models delete KV entries with negligible PPL change relative to their own no-eviction references. Under a matched live-cache protocol on the same dense backbones, learned sigmoid gates obtain lower PPL than our H$_2$O and KeyDiff implementations, whereas softmax gates do not uniformly beat these post-hoc methods. The results suggest that attention normalization can substantially affect whether a training-time soft gate transfers cleanly to hard KV deletion.

## 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想：** 采用2×2×2因子化实验设计，将"注意力归一化方式"作为影响软→硬迁移的主要变量进行系统比较。核心假设是：sigmoid注意力不具备行归一化约束，因此软门控对单个token的衰减更接近硬删除的极限行为。

**技术细节：**

- **2×2×2因子设计：**
  - 注意力类型：softmax vs. sigmoid
  - 门控：稠密（无门控） vs. 学习型门控
  - 位置编码：RoPE vs. NoPE

- **Sigmoid注意力定义：**
  - 先进行per-head QK-RMSNorm，然后计算注意力分数
  - A_ij = σ(q̄_i^⊤ k̄_j / √d_h + b(i))，其中 b(i) = -log(i+1)
  - 负偏置项用于稳定不同位置的行和（row mass），因为因果注意力的query i只attend到i+1个key

- **学习型门控机制（两通道注入）：**
  - 每个层（除最后一层）产生token级门控：g_j^(ℓ) = σ(w_ℓ^⊤ x_j^(ℓ) + b_ℓ) ∈ (0,1)
  - **Logits通道：** z_ij ← z_ij + log(g_j + ε)
  - **Values通道：** v_j ← g_j · v_j
  - 初始化：w=0, b=5（σ(5)≈0.993，初期接近无门控行为）
  - 训练目标：L = L_CE + λ·ḡ，其中λ=0.03，ḡ为所有门控的平均值

- **推理期硬驱逐：**
  - 选择阈值τ⋆，删除g < τ的KV条目
  - 阈值选择规则：在验证集上扫描阈值网格，选满足ΔPPL < 0.1的最大压缩率对应的τ⋆
  - 保留的条目继续使用学习到的logit和value缩放

## 6. 论文的主要结论与发现

**结论一：软到硬迁移具有底物特异性。** 在稠密无驱逐场景下，softmax优于sigmoid（RoPE下PPL低0.361，NoPE下低1.205）；但在学习型硬驱逐场景下，sigmoid门控模型表现更好。

**结论二：sigmoid门控可实现无明显PPL损失的物理删除。**

- Sig+G RoPE：删除19.8% KV条目，PPL从22.440降至22.424
- Sig+G NoPE：删除32.2% KV条目，PPL仅从24.603增至24.637

**结论三：在匹配活跃缓存大小下，sigmoid门控优于后处理方法。** Sig+G RoPE的PPL为22.424，低于H₂O（22.480）和KeyDiff（22.474）；而softmax门控模型的PPL（22.514）劣于H₂O（22.145）。

**结论四：优势并非来自sigmoid对任意删除的鲁棒性。** 随机支持移除探针显示，在高删除率（50%）下sigmoid的注意力输出扰动（3.666）远大于softmax（1.131）。

**结论五：机制归结为行归一化差异。** Sigmoid注意力的行和可变（CV≈0.44-0.48），软门控可以局部衰减单个token的贡献而不强制其他token重新归一化；softmax的行和恒为1，抑制一个token会将注意力质量重新分配给其他token。

**结论六：门控具有token选择性。** 门控并非均匀压缩缓存：停用词和换行符获得最低门控值（更易被删除），空白符保留最多；停用词（如the, a, an, of）在硬驱逐排名中常被优先删除。

## 8. 不足与局限

### 实验覆盖方面

- **规模有限**：仅使用123M参数的GPT-2-scale模型，单一种子，上下文长度512。结论是否适用于更大模型（如7B/70B）、更长上下文或多种随机种子尚不清楚。
- **训练数据单一**：仅在OpenWebText上训练，未覆盖代码、数学、多语言等不同分布。
- **未做消融实验**：门控设计（logits+values双通道）未拆分为logits-only和values-only；未比较不同λ值、per-head门控或per-layer阈值。
- **后处理基线未充分调优**：H₂O的heavy-hitter/recent比例固定，未在验证集上调整；后处理方法的超参数未系统优化。

### 偏差风险

- **单阈值全局选择**：每个模型仅选择一个全局τ⋆，未考虑per-layer或per-head差异化阈值。
- **PPL作为唯一质量指标**：未报告下游任务（如长上下文理解、问答）性能，也未报告墙钟速度或实际推理加速。
- **后处理基线版本局限**：仅使用H₂O和KeyDiff，未涵盖更多SOTA方法（如DuoAttention、KV-Distill等）。
- **"匹配缓存大小"协议偏好**：直接控制内存而非匹配PPL，sigmoid阈值扫描存在陡峭悬崖，可能使匹配PPL对比不稳定。

### 应用限制

- **缺乏生产级实现**：未实现gated sigmoid注意力的融合内核，无法验证端到端推理速度收益。
- **系统层面影响未评估**：物理删除对实际推理系统（如分页注意力、预填充/解码调度）的影响未讨论。
- **NoPE条件的实际意义存疑**：NoPE设置移除了RoPE且不使用任何位置编码，这与实践中的GPT-2式绝对位置编码或现代长上下文模型有差距。
