## 摘要
检索增强生成（RAG）会跨查询重复预填充相同的文本块，导致冗余计算。位置无关缓存（PIC）通过跨位置重用预计算的关键-值（KV）对来缓解这一问题，但其效率受到大量文本标记的限制。将文本块渲染为图像可以将文本压缩为更少的视觉标记，但渲染图像的PIC比文本PIC遭受更严重的质量下降。这种表示特定的差距主要源于独立编译的缓存之间的上下文不匹配，以及在视觉压缩过程中细粒度文本证据的丢失。现有的PIC修复方法主要通过选择性重计算来解决前者，但它们会引入在线计算，并且无法恢复丢失的文本细节。我们提出了QV-PIC，一种由模型原生模板引导的查询感知双分辨率PIC重用框架。在离线阶段，QV-PIC在模型原生的聊天模板前缀下编译视觉缓存，无需在线重计算即可提高PIC质量。在线阶段，它通过累积查询相关性分数在低分辨率下保留全局上下文，并在高分辨率预算内恢复细粒度的文本证据，从而保留视觉压缩的效率优势。在六个任务中，QV-PIC相对于原始渲染图像PIC将平均F1提高了21.6个百分点，缩小了与原始文本PIC的差距，并比优化的文本PIC高出2.58个F1，同时将首令牌时间（TTFT）降低了17.2%。相对于完全预填充，它将TTFT降低了83.8%。

## Abstract
Retrieval-Augmented Generation (RAG) repeatedly prefills identical text chunks across queries, incurring redundant computations. Position-Independent Caching (PIC) mitigates it by reusing precomputed Key-Value (KV) across positions, but its efficiency is constrained by the large volume of text tokens. Rendering text chunks as images can compress the text into fewer visual tokens, but the rendered-image PIC suffers more severe quality degradation than the text PIC. This representation-specific gap primarily arises from contextual mismatches across independently compiled caches and the loss of fine-grained textual evidence during visual compression. Existing PIC repair methods mainly address the former through selective recomputation, but they incur online computation and cannot recover lost textual details. We propose QV-PIC, a query-aware dual-resolution PIC reuse framework guided by model-native templates. Offline, QV-PIC compiles visual caches under the model's native chat-template prefix, improving PIC quality without online recomputation. Online, it preserves global context with low resolution and restores fine-grained textual evidence within a high-resolution budget by cumulative query relevance scores, retaining the efficiency benefit of visual compression. Across six tasks, QV-PIC improves average F1 by 21.6 points over vanilla rendered-image PIC, closes the gap to vanilla text PIC, and surpasses optimized text PIC by 2.58 F1 while reducing TTFT by 17.2\%. Relative to full prefill, it cuts TTFT by 83.8%.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：检索增强生成（RAG）在长文档问答中会多次预填充相同的文本块，产生大量冗余计算。位置无关缓存（PIC）允许将文本块独立编译为 KV 缓存并在不同位置复用，但文本 token 数量大，导致 KV 传输和计算开销仍然很高。
- **关键观察**：将文本渲染为图像可显著减少 token 数（视觉 token 密度更高），但论文发现“渲染图像 PIC”相比“文本 PIC”存在更严重的质量退化：在相同条件下，渲染图像 PIC 较全预填充的质量下降幅度更大（例如 Glyph 在六项 QA 任务上，72 DPI 下 F1 比文本 PIC 低 12.2 点）。
- **原因分析**：退化主要来自两个耦合问题：
  1. **编译上下文不匹配**：独立编译的缓存缺少完整预填充时的上文条件，组合后 KV 状态与模型预期不一致；
  2. **细粒度证据丢失**：视觉编码将字符、数字、标点等压缩为视觉 token，可能模糊或遗漏对答案关键的文本细节。
- **现有方法不足**：已有的 PIC 修复（如选择性重计算、前缀修正）仅在在线路径引入额外计算，且无法恢复已丢失的视觉文本细节。
- **研究意义**：旨在让渲染图像 PIC 在保持视觉压缩高效性的同时，达到甚至超越文本 PIC 的复用质量，从而实现低延迟、高质量的长文档 RAG 服务。

### 2. 方法论：核心思想、技术细节与流程

论文提出 **QV-PIC**（Query-Aware Visual Position-Independent Caching），一个“模型原生模板条件化 + 查询感知双分辨率”的视觉 PIC 框架，分为离线准备和在线组装两阶段。

#### 核心思想
- **离线**：在模型原生聊天模板前缀下编译渲染图像的 KV 缓存，消除编译上下文不匹配；同时预编译低分辨率和高分辨率两种缓存版本，并存储源文本嵌入向量。
- **在线**：根据查询与各渲染图像的相关性，将有限的高分辨率预算分配给最相关的图像，其余保持低分辨率，从而在不牺牲全局上下文覆盖的前提下恢复查询所需的细粒度文本证据。

#### 关键技术细节

1. **模型原生模板条件化编译（Template-Conditioned Compilation）**
   - 对每个渲染图像 \(x_i^r\)，在模型原生聊天模板前缀 \(h\) 下执行前向计算，得到 KV：
     \[
     C_i^r = \text{Strip}_h \big( \text{KV}_M([h; x_i^r]) \big)
     \]
   - 存储前丢弃前缀对应的 KV 条目，但保留经模板条件化的图像 KV 条目。
   - 在线组装时仅需添加一次共享前缀缓存 \(C_h = \text{KV}_M(h)\)，避免任意 dummy prefix 带来的长度和 token 身份敏感性。

2. **M-RoPE 位置重锚定**
   - 独立编译的 KV 以未旋转键存储，在线时根据当前上下文顺序和位置 \(P_i(q)\) 应用旋转：
     \[
     K_{\ell,i} = R_\ell \big( \bar{K}_{\ell,i}, P_i(q) \big)
     \]
   - 值向量与位置无关，直接按当前顺序拼接。

3. **查询感知双分辨率分配（Query-Aware Dual-Resolution Allocation）**
   - 对每个渲染图像 i 预编译低分辨率缓存 \(C_i^L\) 和高分辨率缓存 \(C_i^H\)。
   - 使用冻结的 BGE-M3 编码器计算查询 \(q\) 与每个源文本嵌入的余弦相似度：
     \[
     \tilde{s}_i = e_q^\top e_i, \quad s_i = \max(\tilde{s}_i, 0)
     \]
   - 按相关性降序排序，选择满足“累计正相关性比例 ≥ α（0.65）”的最小集合，并受高分辨率预算 B（4 张图）限制：
     \[
     k^* = \min \left( B, \min \{ k : \frac{\sum_{j=1}^k s_{\pi_j}}{\sum_{i=1}^n s_i} \ge \alpha \} \right)
     \]
   - 若所有相关性非正，则选择最高分图像作为确定性回退。
   - 最终激活的渲染图像前缀长度为：
     \[
     N(q) = \sum_{i=1}^n n_i^L + \sum_{i \in S(q)} (n_i^H - n_i^L), \quad |S(q)| \le B
     \]
   - 在线路由开销仅包括查询编码、相似度排序，复杂度为 \(O(nd) + O(n\log n)\)；渲染、视觉编码和 KV 编译全部位于离线路径。

#### 整体流程
- **Phase I（离线）**：对可复用文本块渲染低/高分辨率图像，在模板前缀下独立编译两种分辨率的 KV 缓存，剥离前缀 KV 后存入缓存库；同时保存 token 数、来源顺序元数据和源文本嵌入。
- **Phase II（在线）**：对检索到的块进行查询相关性打分，决定哪些图像使用高分辨率缓存；按当前上下文顺序组装激活缓存，进行 M-RoPE 重锚定，最后仅对查询后缀做预填充和解码。

### 3. 实验设计：数据集、基准与对比方法

- **数据集**：LongBench 中的六个长上下文 QA 任务（总计 1150 个示例）：
  - MultiFieldQA-en（150 例）
  - 2WikiMQA、HotpotQA、MuSiQue、TriviaQA、NarrativeQA（各 200 例）
  - 覆盖单文档/多文档、证据局部化/分布式、直接检索/多跳推理等不同场景。
- **模型**：
  - 主模型：Glyph 9B（专门做过渲染文本适配的 VLM）。
  - 泛化测试模型：GLM-4.1V-9B-Thinking（同源家族）和 LLaVA-OneVision-2-8B-Instruct（跨家族，不同视觉编码器/语言骨干/训练方式）。
- **对比方法**：
  - 全预填充（full prefill）：文本全预填充、渲染图像全预填充。
  - 文本 PIC：前缀自由的文本 PIC、模板条件化文本 PIC。
  - 渲染图像 PIC：前缀自由、dummy prefix（k=2/4/8/16）、模板条件化、EPIC-2/4（在线重计算前 2/4 个 token）。
  - 双分辨率/消融：QV-PIC、QV-PIC 去掉模板条件化、统一 72 DPI、统一 120 DPI、统一 144/168 DPI（部分任务）。
- **指标**：LongBench 官方 token 重叠 F1（每个示例一次确定性运行）；TTFT（三次平均，含不同方法的在线开销定义）。
- **DPI 配置**：固定画布、边距、字体、行间距，只改变 DPI；Glyph 的 72/96/120 扩展至 144/168；NarrativeQA 因算力限制仅评估 72/96/120。

### 4. 资源与算力

- 论文明确提到实验服务器配备 **8 张 NVIDIA A800 80 GB GPU**。
- 所有方法均在同一的 Hugging Face–PyTorch 推理框架中实现，使用相同配置。
- **未明确说明**：模型预训练/微调时长、具体运行小时数、训练总耗时、GPU 与数据集处理的详细能耗等。只提到了 NarrativeQA 因“compute budget”限制而降低 DPI 扫描范围，但未给出具体算力量化。

### 5. 实验数量与充分性

- **实验组数较多**，共 4 个研究问题（Q1–Q4）：
  - Q1：比较 5 种编译/修复方式 × 2 分辨率（72/120 DPI），加上 EPIC-2/4，共 12+ 组。
  - Q2：比较文本/图像的全预填充和模板条件化 PIC，跨 72–168 DPI，分任务展示 F1-TTFT 曲线。
  - Q3：QV-PIC 与多种基线对比，并做组件消融（去掉模板条件化、去掉双分辨率），含跨任务细分结果。
  - Q4：跨模型泛化测试（两个额外 VLM）的同类对比。
- **覆盖充分性**：数据集多样、任务类型互补；主模型实验覆盖 6 个任务、5 个 DPI 档位；消融实验清晰验证了每个组件的贡献。
- **客观性与公平性**：所有方法在统一框架下实现，共享相同配置；使用相同的渲染协议；推理为确定性单次运行，TTFT 取三次平均。整体设计较严谨。
- **潜在不足**：NarrativeQA 的 DPI 扫描不完整；实验中未报告标准方差或显著性检验；未涉及多轮对话、流式输出等复杂 RAG 场景；对网络传输开销、缓存存储开销未做详细分析。

### 6. 主要结论与发现

- **模型原生模板条件化编译显著优于前缀自由或任意 dummy prefix**：
  - 120 DPI 下，渲染图像 PIC 从 32.9 F1 提升至 52.1 F1，将原本相对文本 PIC 的 12.0 点差距转为 0.4 点优势。
  - 长度匹配的 dummy prefix（k=4）仅得 46.9，说明收益来自模板与模型输入接口的对齐，而非单纯添加前缀。
- **统一提高 DPI 的效果不稳定**：从 72 到 120 DPI 有平均提升，但进一步升至 144/168 DPI 并未带来一致增益，反而 TTFT 线性增长；因此需要选择性分配高分辨率。
- **QV-PIC 的联合收益**：
  - 较原始渲染图像 PIC：平均 F1 提升 21.6 点。
  - 较优化文本 PIC：平均 F1 高 2.58，TTFT 降低 17.2%。
  - 较全预填充：TTFT 降低 83.8%。
  - 在四项任务上同时提高 F1 并降低 TTFT（相对统一 120 DPI 图像 PIC）。
- **组件协同**：仅双分辨率分配而缺少模板条件化时，F1 只有 32.5；两者结合后为 54.3，证明模板条件化建立可靠 KV 基础，双分辨率分配提供查询相关细节。
- **跨模型泛化成立**：在 GLM-4.1V 和 LLaVA-OneVision-2 上，QV-PIC 均能提升渲染图像 PIC 质量，并保持较低 TTFT，说明方法不依赖于 Glyph 的渲染文本专用训练。

### 7. 优点

- **问题定位准确**：清晰区分了“编译上下文不匹配”和“细粒度证据丢失”两类退化，并给出针对性方案。
- **创新的双分辨率缓存设计**：将分辨率作为可分配资源，以查询为导向动态选择，兼顾效率和质量。
- **离线优先设计**：所有高开销操作（渲染、视觉编码、KV 编译）都在离线完成，在线路径仅需轻量路由与缓存组装，实际部署友好。
- **模型无关性较强**：通过跨家族模型验证提升了结论的普适性。
- **实验设置规范**：统一框架、统一渲染协议、多任务多指标，性能对比清晰，消融完整。

### 8. 不足与局限

- **计算资源论述不透明**：仅提到 GPU 型号和数量，未披露训练/推理总时长、能耗、存储开销等关键量化数据。
- **覆盖范围有限**：仅使用 LongBench 的 QA 任务，未覆盖摘要、分类、代码生成等 RAG 场景；也未考虑多轮交互、流式输出、并发请求下的缓存替换策略。
- **质量评估单一**：主要依赖 F1 和 TTFT，缺乏人工评测、忠实度评测以及用户感知层面的质量分析。
- **参数敏感性未充分探索**：α 和 B 仅在固定值（0.65 和 4）下测试，未分析不同查询类型、上下文长度下的最优配置。
- **依赖额外编码器**：在线查询相关性打分依赖 BGE-M3 嵌入，若查询与文本存在领域偏移，打分准确性可能受影响；论文未对比其他路由方法（如使用 KV 注意力分数）。
- **高分辨率收益具有模型相关性**：跨模型实验中，LLaVA-OneVision-2 上 QV-PIC 仅“接近”而非超越最高 F1，说明增益幅度依赖底层 VLM 的视觉编码能力。
- **位置无关缓存安全性**：论文未讨论跨用户缓存隔离、提示注入或隐私风险。
