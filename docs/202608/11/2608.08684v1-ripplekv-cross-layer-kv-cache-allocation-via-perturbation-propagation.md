## 摘要
长上下文LLM推理受到KV缓存内存的瓶颈限制，然而在层之间分配有限的缓存预算仍然具有挑战性。现有方法依赖于层深度、注意力统计或表示变化等代理指标。这些代理指标并未衡量每层扰动如何传播到输出，因此可能导致敏感层分配不足，而容忍层分配过度。为解决此问题，我们提出RippleKV，通过估计每层值缓存扰动对最终预测分布的影响来跨层分配缓存。RippleKV独立地向每层的值缓存注入范数自适应扰动，并在小规模校准集上测量模型输出处引起的KL散度。对这些响应取平均，得到特定于模型的敏感性分布，该分布不必随深度单调变化。随后，RippleKV通过归一化敏感性得分并应用指数映射，将敏感性分布转换为层预算乘数。一个比率参数控制敏感层与容忍层之间的分配差异，而最终归一化则保持KV缓存预算不变。在LongBench上的实验表明，在匹配的缓存预算下，RippleKV在所评估的KV缓存压缩方法中取得了最高的平均性能。

## Abstract
Long-context LLM inference is bottlenecked by KV cache memory, yet distributing a limited cache budget across layers remains challenging. Existing methods rely on proxies such as layer depth, attention statistics, or representation change. These proxies do not measure how perturbations at each layer propagate to the output and may therefore cause sensitive layers to be underallocated while tolerant layers are overallocated. To address this issue, we propose RippleKV, which allocates cache across layers by estimating how perturbations to each layer's value cache affect the final predictive distribution. RippleKV independently injects norm-adaptive perturbations into each layer's value cache and measures the induced KL divergence at the model output over a small calibration set. Averaging these responses yields a sensitivity profile specific to the model that need not vary monotonically with depth. RippleKV then converts the sensitivity profile into layer budget multipliers by normalizing the sensitivity scores and applying an exponential mapping. A ratio parameter controls the allocation disparity between sensitive and tolerant layers, while a final normalization preserves the KV cache budget. Experiments on LongBench demonstrate that RippleKV achieves the highest average performance among the evaluated KV cache compression methods under matched cache budgets.

### 一、论文核心问题与整体含义

- **研究背景**：长上下文大语言模型（LLM）推理中，KV缓存随序列长度和层数线性增长，导致显著的内存与带宽压力，KV缓存压缩成为必要的优化手段。
- **核心问题**：在给定全局缓存预算下，如何在 Transformer 各层之间**合理分配缓存预算**。现有方法（如 PyramidKV）多依赖层深度、注意力统计、表示变化等**代理指标**来决定各层预算，但这些代理指标无法直接反映“某一层缓存被压缩后，最终预测分布会受多大影响”，容易导致敏感性强的层分配不足、容忍性强的层分配过度。
- **核心洞察（论文的核心动机）**：
  - 各层面对压缩的损伤并非随深度单调变化，而是高度异构，最大损伤往往出现在中间层；
  - 通过对某层 Value cache 施加受控扰动，并测量最终输出的 KL 散度，可以更好地反映该层对压缩的真实敏感程度。
- **整体含义**：RippleKV 提出了一种**不依赖层深度等先验代理指标**的分配框架，而是通过“扰动传播”直接度量层对输出的影响，从根本上提升跨层缓存分配的合理性和模型端到端性能。

### 二、方法论：核心思想、技术细节与算法流程

#### 1. 核心思想

RippleKV 的核心思想是：**用“扰动—输出响应”来表征层的缓存敏感度**。具体而言，对某一层的 Value cache 注入受控扰动，在**不改变 Key cache 和其他层**的前提下，观察最终输出预测分布的变化（KL 散度），以此作为该层的敏感性得分。

#### 2. 关键技术细节（公式与流程）

- **压缩损伤定义**：对层 ℓ 仅压缩其 KV cache，以全缓存输出 P_full 与压缩输出 P_comp 之间的平均 KL 散度 D_ℓ 定义该层压缩损伤。
- **扰动响应定义**：对层 ℓ 的 Value cache 施加范数自适应扰动，测量输出分布变化：

  **扰动构造**：  
  \(\tilde{v}_{i,\ell,h,u} = v_{i,\ell,h,u} + \alpha \|v_{i,\ell,h,u}\|_2 \cdot \epsilon_{i,\ell,h,u}\)，  
  其中 ε ~ N(0, I)，α 为扰动强度。缩放噪声到向量 L2 范数，自适应不同层/ token 的激活尺度；同时，受保护位置（如注意力汇聚 token）不被扰动。

  **响应计算**：  
  \(d_{i,\ell} = \frac{1}{|W_i|} \sum_{t\in W_i} D_{KL}(P_{i,t} \| Q_{i,\ell,t})\)，  
  其中 W_i 为评估窗口，Q 为扰动后的输出分布；跨校准集平均后得到层敏感性 \(s_\ell\)。

- **敏感度到预算的映射**：
  - 归一化：\(\hat{s}_\ell = (s_\ell - s_{min}) / (s_{max} - s_{min})\)；
  - 指数映射：\(\tilde{w}_\ell = r^{\hat{s}_\ell}\)，其中 r ≥ 1 为分配比率（控制敏感/容忍层差异，r = 1 即均匀分配）；
  - 裁剪与归一化：\(w = ClipNormalize(\tilde{w}, γ)\)，限定乘子在 [1/γ, γ] 区间内并保持均值为 1；
  - 最终预算：\(b_\ell = round(B/|A| \cdot w_\ell)\)，保证 ∑b_ℓ = B。

- **离线一次性 Profiling**：敏感性分布只在校准集上计算一次，可复用在不同全局预算下；推理阶段只应用预计算的预算，不引入额外在线计算。

#### 3. 与现有方法的集成方式

RippleKV 只改变各层预算分配，不改变 token 选择策略，在实现中以 SnapKV 的 token 评分规则为基础，仅替换其均匀层预算为敏感度引导分配，从而隔离层预算分配的影响。

### 六、主要结论与发现

1. **压缩损伤高度异构且非单调**：测试中 Llama-3.1-8B-Instruct 各层孤立压缩损伤跨度达 0.0030–0.0524（约 17.7 倍差异），最大损伤发生在中间层；层索引与压缩损伤的平均 Spearman 相关性仅 |ρ| = 0.359，说明深度无法作为可靠的分配依据。
2. **扰动响应能有效预测压缩敏感度**：RippleKV 的扰动响应与真实压缩损伤的平均相关性达到 |ρ| = 0.799（范围 0.723–0.857），远高于层索引，为分配提供了更可靠的信号。
3. **RippleKV 在 LongBench 上取得最佳平均性能**：在 Llama-3.1-8B-Instruct 上，10%/20%/30% 预算下分别比最强基线高 0.83/0.42/0.71 分；在 Qwen2.5 和 Mistral 的 10% 预算下也优于所有基线，证明跨模型家族的一般适用性。
4. **运行效率与内存占用持平或略优**：推理延迟和吞吐不劣于甚至略优于现有压缩方法；峰值内存与现有压缩方法相当，相比 Full Cache 在 128K 减少 31.6%、256K 减少 37.8%。
5. **超参数鲁棒**：分配比率 R 在 1.25–1.75 之间变化时，平均性能波动仅 0.41 分。

### 七、优点：方法与实验设计亮点

- **方法层面**：
  - 提出了一种新的、端到端的敏感度度量方式（“扰动—输出响应”），直接衡量各层缓存对最终预测的影响，突破了传统“层局部统计”或结构先验的局限；
  - **离线 profiling + 一次性计算**，推理阶段零额外开销，且敏感性分布与预算无关，可自由复用；
  - **即插即用**，与任何现有 token 选择策略兼容，正交于现有压缩方法；
  - 归一化 + 指数映射 + 裁剪 + 平均归一化的预算转换方案，兼顾了尺度不变性、可调节差异性和极端值抑制。
- **实验设计层面**：
  - 用 Spearman 相关性将“扰动响应”与真实压缩损伤对齐，验证了代理信号的可靠性；
  - 消融实验分离了“是否非均匀分配”和“是否用下游信号”两个因素，清晰展示了各自的贡献；
  - 效率实验覆盖了 8K 与 128K 的典型场景，内存实验覆盖到 256K，较全面。

### 八、不足与局限

- **验证范围有限**：
  - 仅采用 LongBench 单一基准，缺乏更广泛的长上下文评测（如 RULER、∞Bench、L-Eval 等），结论的泛化性受限；
  - 只在 7B–8B 规模的指令微调模型上验证，未覆盖更大尺度模型（如 70B、MoE 架构）和非指令微调模型。
- **敏感度度量中的简化假设**：
  - 通过独立扰动单层 Value cache 来测量层敏感性，忽视了**层间相互依赖和扰动协同效应**；某些层对压缩的敏感性可能只在其他层也被压缩时才显现；

  - 分配比率 R = 1.50 的选择基于 LongBench 上的表现，可能存在对特定基准过拟合的风险（不过 1.25–1.75 范围内的稳定性缓解了该担忧）。
- **未报告详细资源开销**：离线 profiling 的具体时间和计算成本未被量化，实际部署时其一次性成本需要评估。
- **实验可重复性**：校准集的构成、大小和采样方式未详细描述，难以完全复现其结果。
