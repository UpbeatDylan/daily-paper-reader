## 摘要
生产部署中通常会在同一模型家族内不同规模的模型之间进行切换，以实现成本与质量的级联、对话中途切换和路由，而每次切换都迫使接收方从头重新进行预填充。我们提出跨模型KV缓存迁移，即接收方复用源模型的KV缓存，跳过预填充。我们发现，在匹配的KV对中，跨模型KV具有显著的线性结构，其中源模型和目标模型共享KV头数和每头维度。在Qwen3 14B->32B上，单个源层可以解释目标键中56%的方差和值中32%的方差，使用多个源层时这一比例分别上升到79%和65%。基于此，我们设计了一个逐头操作的闭合形式岭映射器，其过程分为三步。首先，对于每个目标层，我们选择预测能力最强的前k个源层，并将其KV拼接作为输入。其次，在映射之前从键中剥离RoPE，从而使拟合与位置无关，并可跨上下文长度复用。第三，我们在一个包含500条FineWeb-Edu序列（每条1024个token）的小型校准集上拟合岭回归。令人惊讶的是，在三个家族中的六对模型上，这一线性映射器在四对上保留了接收方独立预填充准确率的73-98%，而两对则急剧下降。一个非线性MLP在失败案例上将HellaSwag保留率最多提升了37个百分点。该映射器的运行速度比重预填充快2.7-25倍，并且在多轮切换中保持稳定，这使得跨模型KV缓存迁移变得实用。

## Abstract
Production deployments often swap between different-sized models in a family for cost-quality cascading, mid-conversation switching, and routing, and each swap forces the receiver to repay the prefill from scratch. We propose cross-model KV cache transfer, where the receiver reuses the source's KV cache, skipping prefill. We find that cross-model KV has substantial linear structure across matched-KV pairs, where source and target share KV head count and per-head dimension. On Qwen3 14B->32B, one source layer explains 56% of variance in the target's keys and 32% in values, rising to 79% and 65% with multiple source layers. Building on this, we design a closed-form ridge mapper that operates per head and proceeds in three steps. First, for each target layer we select the top-k most predictive source layers and concatenate their KV as input. Second, we strip RoPE from the keys before mapping, so the fit is position-free and reusable across context lengths. Third, we fit ridge regression on a small calibration set of 500 FineWeb-Edu sequences of 1,024 tokens each. Surprisingly, across six pairs in three families, this linear mapper retains 73-98% of the receiver's standalone-prefill accuracy on four pairs, while two degrade sharply. A nonlinear MLP recovers up to +37 pp HellaSwag retention on the failures. The mapper runs 2.7-25x faster than re-prefill and remains stable across multi-turn handoff, making cross-model KV cache transfer practical.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：生产级 LLM 推理中，一个模型家族（如 Qwen3、Llama 3.1、Ministral 3）内部经常按成本-质量级联、对话中途切换、路由等策略，在不同大小的模型之间动态切换。每次切换后，接收方模型都必须对已累积的长上下文**从头重新执行预填充（prefill）**，即重新计算 KV cache。
- **问题**：预填充成本随模型规模和提示长度线性增长，在长会话、多轮 agent 场景中开销尤其显著。现有前缀缓存（prefix caching）只能在同一模型内复用，无法跨模型复用 KV。
- **核心思路**：若能把源模型已算好的 KV cache 映射为接收方模型期望的格式，接收方就能跳过预填充直接解码。本文将这一任务定义为**跨模型 KV cache 迁移（Cross-Model KV Cache Transfer）**，并限定于同一家族内不同规模模型之间的迁移。
- **关键观察**：跨模型 KV 之间存在显著的**线性结构**。在 Qwen3 14B→32B 上，单个源层能解释目标键方差的 56%、值方差的 32%；使用多个源层后上升到 79% 和 65%。这为无梯度、闭合形式的线性映射提供了依据。
- **整体意义**：将 KV 复用从"同模型内"扩展到"跨模型规模"，可直接降低模型切换场景下的服务成本、能耗和尾延迟，对长会话多模型编排场景有实际价值。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想
- 将跨模型 KV 迁移视为**表示转换问题**：学习逐头（per-head）线性映射，将源模型的 K/V cache 投影到目标模型的 K/V 空间，使目标模型能用转换后的 KV 直接解码。
- 映射器采用**闭合形式岭回归**，无需梯度训练，只用小型校准集即可拟合。

### 2.2 三大关键组件

1. **逐头岭回归（Per-Head Ridge Regression）**
   - 对每个目标（层 l，头 h）独立拟合线性映射：
     - ˆK(l,h) = X_k^K · W(l,h)^K + b(l,h)^K
     - ˆV(l,h) = X_k^V · W(l,h)^V + b(l,h)^V
   - 其中 X 为来自 top-k 个源层的 KV 特征拼接，W 为权重矩阵，W∈R^{(k·n_kv^s·d_h^s)×d_h^t}。
   - 使用岭回归（λ=0.01）而非纯 OLS，以稳定特征矩阵可能近奇异的求逆。
   - 闭合解：W* = (X^T X + λI)^{-1} X^T Y
   - 校准数据：500 条 FineWeb-Edu 序列，每条 1024 token，stride-4 子采样后约 12.8 万 token 观测/头。

2. **跨层源层选择（Cross-Layer Source Selection）**
   - 源模型与目标模型层数不同，需确定每个目标层应由哪些源层来映射。
   - 采用按头平均 R²（在剥离 RoPE 后的键与值上平均）作为预测力指标，为每个目标层选取 top-k 个源层，拼接其 K/V 特征。
   - 同一目标层内所有头共享所选源层，允许跨头信息流动。
   - k 为超参数，按配对在 {1,2,4,6,8,10,12,16,20,24,all} 中扫描选取。

3. **内容空间映射（RoPE Factoring）**
   - RoPE 将位置相关的旋转施加在键/查询上，直接拟合会引入位置分布耦合。
   - 做法：先在源侧剥离 RoPE（通过旋转矩阵的逆 R⁻¹），在位置无关空间拟合 W，再施加目标 RoPE 重新编码：
     - ˆK_t = (K_s · R^{-1}_{Θs}(t) · W_K + b_K) · R_{Θt}(t)
   - 由于 RΘ 是正交矩阵，逆变换精确且开销可忽略；值不含位置编码，直接映射。
   - 这使得映射器与上下文长度无关，可跨 RoPE 配置与长上下文泛化。

### 2.3 算法流程（文字说明）
1. 用校准序列分别运行源模型和目标模型，收集各自的 KV cache。
2. 对 K 剥离 RoPE，得到内容空间表示。
3. 对每个目标层，按单源层 R² 选出 top-k 源层。
4. 拼接所选源层的 KV 作为特征，目标层对应 K/V 作为响应。
5. 逐头求解岭回归闭合解（中心化后求 W*，再恢复偏置 b）。
6. 推理时：取源 KV → 剥离 RoPE → 拼接映射 → 施加目标 RoPE → 送入目标解码。

## 6. 主要结论与发现

1. **跨模型 KV 存在强线性结构**：单个源层即可解释目标 K 的 56% 方差和 V 的 32%；多个源层可将 R² 提升到 0.79（K）和 0.65（V）。
2. **闭合形式岭回归可行**：在 Qwen3 14B→32B、Qwen3 8B→32B、Llama 3.1 8B→70B、Ministral 3B→8B 四对（Tier 1）上，Avg 保留率达 73–98%；Ministral 3B→14B 和 8B→14B（Tier 2）则退化到 42–44%（floor-normalized 仅 11–15%）。
3. **组件贡献排序**：跨层源层选择贡献最大（k=1 时 ARC-C 从 61.60 暴跌到 27.65）；推理期 RoPE 处理对 MMLU/GSM8K 至关重要（不处理则掉到随机水平）；校准对 λ 和 N 稳健，但对校准域敏感。
4. **非线性 MLP 可恢复失败配对**：在 Tier 2 配对上将 HellaSwag 保留率提升 +24.3 ~ +36.8 pp，全部拉到 90% 以上；在 Tier 1 配对不如 ridge，说明线性足够的地方不需要非线性。
5. **保留率由误差落点而非大小决定**：attention-output cosine 与 HellaSwag 保留率的相关性 r=+0.57，而 R² 几乎无相关性（r=-0.20）。MLP 的增益来自将残差误差重新分配到注意力不读取的方向（降低 K-concentration）。
6. **多轮切换稳定**：CoQA 上小→大漂移 10 轮内仅扩大 1.7 pp，大→小以 0.33 pp/轮线性增长但 10 轮内无级联失败。
7. **延迟优势显著**：映射器比 re-prefill 快 2.7–25×（小→大）和 3–7×（大→小），在 32K 上下文上优势最大。

## 7. 优点

- **方法新颖且实用**：首次系统研究跨模型 KV 的线性结构，并提出梯度免费、闭合形式的映射方案，绕开了此前方法的训练依赖。
- **设计简洁有效**：三个组件（per-head ridge、top-k 源层选择、RoPE 剥离）各自有清晰动机与独立实验支撑，消融透彻。
- **评估严谨**：
  - 双指标（retention + floor-normalized retention）避免基准随机基线造成的误导；
  - 留一基准验证 k 选择偏差；
  - held-out 基准（PIQA/BoolQ/ARC-Easy）验证泛化；
  - 对失败配对不回避，并深入解释了失败机制。
- **诊断指标有洞见**：attention-output cosine 优于 R² 的发现，将评估维度从"平均重建精度"转向"注意力敏感子空间"，为该方向后续研究提供了更好的度量标准。
- **部署考量细致**：映射器大小与序列长度无关、可 CPU 驻留、延迟按 10 个序列长度全扫描、多轮切换做了实测，贴近生产实际。
- **多家族验证**：在 Qwen3、Llama 3.1、Ministral 三个不同后训练配方（post-trained/base/reasoning-tuned）的家族上验证，增加了结论的广泛性。

## 8. 不足与局限

- **matched-KV 约束**：所有配对都要求源/目标共享 KV 头数和每头维度，该条件在文中的六个配对上是经验性满足，未测试头数或维度不匹配的情况，限制了方法的适用范围。
- **校准域单一与语域混淆**：仅用 FineWeb-Edu 校准；域替换实验（Wikipedia/CodeAlpaca）无法区分"主题差异"与"语域差异"，也未覆盖医学、法律等专业领域，实际部署可能需要领域适配。
- **k 选择的同组偏差**：k 在报告基准的子集上选择，尽管留一验证显示影响 ≤2.49 pp，但选择标准与评估基准仍有重叠，非完全样本外选择。
- **失败案例的机制解释相对单一**：Tier 2 配对为何线性关系弱（R²_K 深负）的根源（架构深度差 vs 训练配方 vs 数据重叠）未系统分离。
- **MLP 分析不完整**：MLP 只对比了 4 对、只用 HellaSwag，未在全 6 对×5 基准上完整对比，无法评估 MLP 在其它基准上的表现及引入延迟的成本。
- **多轮实验单薄**：仅 Qwen3 14B↔32B 一对；大→小漂移呈线性增长（0.33 pp/轮），极长会话中是否会级联失败未验证。
- **延迟测量有边界**：延迟测试使用合成输入，未包含端到端"映射后缓存传输到目标进程"的开销；Mapper 运行在 eager mode，未用 CUDA graphs/torch.compile，实际部署中延迟优势可能进一步扩大，但论文未给出优化后数字。
- **跨家族迁移未解决**：Qwen3→Llama 3.1 这类跨家族迁移是否仍存在线性结构是开放问题，本文完全未覆盖。
- **只覆盖密集全注意力架构**：对混合注意力（sliding-window/local）、状态空间混合架构（如 Nemotron 3）不适用。
