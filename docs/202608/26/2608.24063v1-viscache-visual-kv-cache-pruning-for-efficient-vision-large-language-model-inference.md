## 摘要
尽管视觉大语言模型（VLLMs）在多模态推理中取得了显著成功，但其长上下文推理仍因视觉键值（KV）缓存带来的巨大计算和内存开销而代价高昂。现有的KV压缩方法通常对视觉token和层进行均匀剪枝，导致大量信息丢失和性能下降。为应对这一挑战，我们提出了VisCache，一种即插即用的免训练粗到细视觉KV缓存剪枝框架，由两个协同阶段组成。首先，一个轻量级VLM通过选择性地转发语义上有信息量的关键帧来过滤时间冗余。其次，我们引入PruneKV，一种针对VLLM注意力动态量身定制的外科手术式KV压缩算法。与刚性剪枝策略不同，PruneKV采用抛物线式逐层预算分配以及非对称更新机制，选择性剪枝键同时融合值，从而保留关键上下文信息。大量实验表明，VisCache显著提升了推理效率，实现了高达2.35倍加速和显著的内存减少，同时在仅保留19%–28% KV缓存的情况下保持了有竞争力的性能。VisCache持续优于现有基线，为长上下文VLLM推理建立了效率与性能之间的新帕累托前沿。代码可在https://github.com/Wlklk/VisCache获取。

## Abstract
While Vision Large Language Models (VLLMs) have achieved remarkable success in multimodal reasoning, their long-context inference remains prohibitively expensive due to the massive computation and memory overhead of visual Key-Value (KV) caches. Existing KV compression methods often apply uniform pruning across visual tokens and layers, leading to substantial information loss and degraded performance.To address this challenge, we propose \textbf{VisCache}, a plug-and-play framework for coarse-to-fine \textbf{Vis}ual KV \textbf{Cache} pruning without training, which consists of two synergistic stages. First, a lightweight VLM filters temporal redundancy by selectively forwarding semantically informative keyframes. Second, we introduce {PruneKV}, a surgical KV compression algorithm tailored to the attention dynamics of VLLMs. Unlike rigid pruning strategies, PruneKV adopts a parabolic layer-wise budget allocation together with an asymmetric update mechanism that selectively prunes keys while fusing values, thereby preserving critical contextual information. Extensive experiments demonstrate that VisCache substantially improves inference efficiency, achieving up to {2.35$\times$ speedup} and significant memory reduction while maintaining competitive performance with only {19--28\%} KV cache retention. VisCache consistently outperforms existing baselines, establishing a new Pareto frontier between efficiency and performance for long-context VLLM inference. Code is available at https://github.com/Wlklk/VisCache

# VisCache 论文要点总结

## 1. 核心问题与研究动机

- **背景问题**：视觉大语言模型（VLLMs）在多模态推理中表现出色，但长上下文推理时的视觉 Key-Value（KV）缓存会带来巨大的计算和内存开销，严重制约推理效率。
- **现有方法的缺陷**：已有的 KV 压缩方法（如均匀剪枝、量化、低秩分解等）通常对视觉 token 和层进行“一刀切”式处理，忽略了视觉信息在时间维度、层间分布以及键/值角色上的结构性差异，导致信息丢失和性能下降。
- **核心目标**：设计一种既能大幅压缩视觉 KV 缓存，又能保持甚至提升推理性能的免训练方法，实现效率与性能的更优权衡。

## 2. 方法论：VisCache 框架

- **总体思想**：提出“由粗到细”的双阶段、免训练、即插即用框架，分别从输入级（时间冗余）和模型级（结构冗余）压缩视觉 KV 缓存。

### 阶段一：Prompt-Aware Scout 时间冗余过滤

- 使用轻量级 VLM（如 CLIP）作为“侦察模型”，提取文本 prompt 和视频帧的跨模态表示。
- 利用**最大边际相关性（MMR）** 准则迭代选择关键帧：
  - MMR(f) = λ·sim(h_f, h_t) − (1−λ)·max_{f'∈Ω} sim(h_f, h_f')
  - 同时兼顾与查询的相关性（sim 与 prompt 嵌入）和帧间多样性（对已选帧的冗余惩罚）。
- 直到达到目标保留比例 p，形成紧凑且语义覆盖良好的关键帧序列，减少后续进入 VLLM 的视觉 token 数量。

### 阶段二：PruneKV 层感知视觉 KV 压缩

- **Token 重要性打分**：对所有层所有查询的注意力权重进行聚合，得到每个视觉 token 的全局重要性分数 s_v，保留 top-q 的 token。
- **抛物线式层间预算分配**：
  - 设定截断层 h（默认 3/4 层深），h 层之后的视觉 KV 全部丢弃。
  - 对 h 层之前各层按抛物线衰减分配预算：
    - b_l = 1 − (l−1)² / (2(h−1)²)，满足 b_1=1, b_h=0.5。
  - 归一化满足总保留比例 m。
  - 相比线性或几何衰减，抛物线分配在浅层保留更多细粒度 token，在深层更积极压缩。
- **非对称键值更新**：
  - 视觉 token 分为保留集 Ck 和丢弃集 Cd。
  - 丢弃集的 key 直接移除（因为它们对注意力权重贡献小）。
  - 丢弃集的 value 不直接删除，而是通过相似度加权重分配融合到保留集的 value 中：
    - 重分配矩阵 Φ = Softmax(V_k V_d^T / τ)
    - 新 value：V_new_k = μ V_k + (1−μ) Φ V_d
  - 这种“剪键保值”策略保留了被丢弃 token 携带的上下文信息。

## 6. 主要结论与发现

- **效率提升显著**：VisCache 在仅保留 19–28% KV 缓存时，可实现最高 2.35× 端到端加速；FLOPs 降至全缓存的 6–15% 不等。
- **性能优势稳定**：在 3B 和 32B 模型上，VisCache 在 28% RR 下平均准确率（45.64% 和 56.86%）超过全缓存和所有基线；在 MVBench 上也取得最优平均成绩（52.6% 和 55.4%）。
- **关键设计有效**：
  - 抛物线预算分配优于算术、几何和固定分配；
  - 非对称“剪键融值”能保留被丢弃 token 的上下文信息，进一步提升性能；
  - 两阶段设计互补，Scout 降低时间冗余，PruneKV 进一步压缩 token/层冗余；
  - 全局共享 token 重要性排序优于逐层独立排序。
- **泛化与兼容性好**：可迁移到其他 VLLM 架构，并可与 KV 量化方法叠加使用。

## 7. 优点

- **免训练、即插即用**：无需额外训练，易于部署到现有 VLLM 中。
- **设计新颖**：显式区分“键”和“值”的注意力功能，引入非对称压缩策略；抛物线预算分配更贴合视觉信息在层间的分布规律。
- **系统级效率验证充分**：不仅报告 FLOPs，还给出真实 GPU 上的内存、延迟、吞吐量等指标。
- **通用性强**：覆盖多种视频理解任务、模型规模和架构，并通过与量化结合展示正交兼容性。
- **消融实验全面**：对每个核心组件（Scout、预算策略、值融合、全局排序、融合强度等）均进行了分析，结论可靠。

## 8. 不足与局限

- **Scout 对齐风险**：依赖 CLIP 等轻量级 VLM 进行关键帧选择，若其视觉表示与主模型差异较大，所选帧可能不是下游模型最优的，导致性能偏差。
- **额外内存开销**：PruneKV 至少在预填充阶段需要存储全层注意力分数，虽为压缩服务，但本身会引入一定内存负担。
- **实验范围限制**：主要针对视频理解任务，未涉及更长文本、图像级或多模态交互等场景；部分附录实验仅在一个 backbone 上进行。
- **潜在偏差传播**：依赖预训练模型学到的注意力模式进行压缩，可能继承基础模型中的偏见，需结合具体场景进行公平性评估。
- **超参数敏感性**：融合强度 μ、截断层 h、λ 等超参数需要调优，虽然默认值表现良好，但在不同任务/模型上未必最优。
