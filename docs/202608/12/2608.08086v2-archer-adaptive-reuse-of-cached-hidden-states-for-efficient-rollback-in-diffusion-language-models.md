## 摘要
扩散语言模型（DLMs）迭代地细化序列，使得早期预测能够随着上下文演变而被修正。这种回滚能力使它们区别于不可逆的自回归生成，但也使推理成本高昂。每次去噪更新都会改变全局上下文，迫使提示和响应状态都被重新计算，即便只有响应标记是可修订的。键值（KV）缓存可以降低这种成本，但传统缓存假设历史状态不可变，因此难以与回滚协调。在本文中，我们介绍了用于高效回滚的缓存隐藏状态自适应重用（Archer），一种面向支持回滚的DLMs的免训练KV缓存方法。Archer非对称地将可变的响应与当前假设保持同步，同时在有界状态邻域内重用提示的K/V。尽管提示表示在双向注意力下也会变化，但它们的标记身份保持不变；因此，有界重用可以在不缓存可变响应状态的情况下分摊重复的提示计算。它还延迟了来自暂定标记的反馈，减少了对瞬时高置信度错误的过早强化，并给回滚更多机会来纠正它们。我们的分析将提示重用刻画为一种与可逆性对齐的缓存边界，界定了其状态相关的近似误差，并给出了保持全刷新决策的解码器边际条件。现有的DLM加速常常以质量为代价换取速度。Archer改变了这一权衡前沿，在主测试套件上实现了33.63%的最佳平均性能以及2.57倍的平均加速。在评估的各种设置中，它将Pass@1提高了最多3.05个百分点，并达到最高2.95倍的加速。受控分析将质量提升与延迟提示反馈联系起来，并验证了状态感知的刷新机制。我们的代码可在 https://github.com/Hxnng/Archer 获取。

## Abstract
Diffusion language models (DLMs) iteratively refine a sequence, allowing earlier predictions to be revised as context evolves. This rollback capability distinguishes them from irreversible autoregressive generation, but makes inference costly. Every denoising update alters the global context, forcing both prompt and response states to be recomputed even though only response tokens are revisable. Key-value (KV) caching could reduce this cost, yet conventional caching assumes immutable historical states and is therefore difficult to reconcile with rollback. In this paper, we introduce Adaptive Reuse of Cached Hidden States for Efficient Rollback (Archer), a training-free KV caching method for rollback-capable DLMs. Archer asymmetrically keeps the mutable response synchronized with the current hypothesis while reusing prompt K/V within a bounded state neighborhood. Although prompt representations also change under bidirectional attention, their token identities remain fixed; bounded reuse therefore amortizes repeated prompt computation without caching mutable response states. It also delays feedback from tentative tokens, reducing premature reinforcement of transient high-confidence errors and giving rollback more opportunity to correct them. Our analysis characterizes prompt reuse as a reversibility-aligned cache boundary, bounds its state-dependent approximation error, and gives a decoder-margin condition for preserving full-refresh decisions. Existing DLM acceleration often trades quality for speed. Archer shifts this frontier, attaining the best mean performance of 33.63% together with a 2.57x mean speedup on the main suite. Across evaluated settings, it improves Pass@1 by up to 3.05 points and reaches up to 2.95x speedup. Controlled analyses connect the quality gain to delayed prompt feedback and validate state-aware refresh. Our code is available at https://github.com/Hxnng/Archer.

## 1. 核心问题与整体含义

**研究动机与背景：**
- 扩散语言模型（DLM）通过迭代式双向去噪生成序列，其关键优势在于**回滚（Rollback）能力**：早期预测可在后续上下文演变中被重新修正，这与不可逆的自回归生成截然不同。
- 然而，回滚能力带来高昂的推理成本：每次去噪更新都会改变全局上下文，即使只有响应 token 可修订，提示（prompt）和响应（response）状态都需被重新计算。
- 传统 KV 缓存假设历史状态不可变（适用于因果注意力的自回归解码），在支持回滚的双向注意力 DLM 中难以直接复用——一个被修订的 token 会使依赖它的所有缓存状态失效。
- 现有方法存在割裂：token 级回滚解码器（如 Saber）提升质量但反复执行全序列前向；DLM 加速方法（如 Fast-dLLM、dKV-Cache）提升效率但未考虑 token 级回滚，二者无法兼顾。
- 核心矛盾是：**如何在保留不受限回滚能力的前提下引入 KV 缓存，避免重复计算不变提示（prompt）的开销。**

## 2. 方法论：核心思想、关键技术细节

**核心思想：**
- 缓存边界应遵循回滚语义，而非实现便利性。生成状态是可能被修订的部分，不应被缓存；提示 token 身份固定，是有界重用的正确边界。
- Archer 采取**非对称状态复用**：完整重算可变响应（generation），仅复用提示 K/V；当响应状态偏离缓存锚点超过阈值时触发全量刷新。

**关键技术细节：**

1. **非对称状态复用（Asymmetric State Reuse）**
   - 设提示 p、当前响应 gt、回滚解码器 D。eager 解码为 z⋆t = Φθ(gt; Cp(gt))；Archer 使用锚点 gr 处的提示缓存：ẑt = Φθ(gt; Cp(gr))。
   - 每层注意力中，响应 query 同时注意锚定的提示 K/V 与全新计算的响应 K/V，保证响应嵌入、隐状态、logit 均反映当前 gt。

2. **状态锚定刷新（State-Anchored Refresh）**
   - 用锚点相对汉明距离 Dt = dH(gt, gr) 衡量缓存有效性；当 Dt ≥ K 时执行全量前向并更新缓存锚点 gr ← gt。
   - 刷新由**响应状态净变化**驱动，而非单纯迭代次数；一次大的回滚可立即触发同步，多次微小更新则可继续复用。

3. **算法流程（Algorithm 1）**：初始化响应和锚点 → 全量前向获得初始 logits 与缓存 → 解码器更新响应 → 若未终止：检查 dH ≥ K，是则全量刷新，否则缓存前向 → 循环直至终止。

4. **理论分析要点**
   - **命题 1（回滚兼容缓存边界）**：任意响应修订下，精确的生成状态复用需重算其完整双向依赖闭包；Archer 不缓存任何生成状态，因此保留原始解码器全部替换/重掩码动作。
   - **效率分析**：全量步成本 Cfull = Σ(αℓN + βℓN²)，缓存步成本 Ccache = Σ(αℓG + βℓGN) + H；忽略开销时缓存步约为全量步的 G/(P+G)，加速比 S ≈ [qK + (1−qK)·G/(P+G)]⁻¹。
   - **误差界**：在 Lipschitz 假设下，logit 误差满足 ‖z⋆t − ẑt‖∞ ≤ Γ√Dt < Γ√K，即 K 界定了状态扰动而非时间间隔。
   - **决策保真条件**：当 Γ√Dt < mD(gt, z⋆t)（决策边际）时，Archer 与 eager 解码选择相同转移。
   - **反馈控制视角**：锚定暂时抑制了响应→提示→响应的交叉区域反馈项 ∂CΦθ·∂gCp，构成"时间锚定"而非冻结，可减少瞬时错误的自强化。

## 8. 不足与局限
